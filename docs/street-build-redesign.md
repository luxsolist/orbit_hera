# 공통 가로공간 빌드 재설계 검토

상태: 아래는 최초 설계 검토다. 종로–청계천 시범구역의 새 면 배분/공유 메시 빌더를 구현했다. 실제 적용 범위와 남은 수직 설계·도시 전체 확대 과제는 [구역 빌더 구현](street-region-builder.md)을 참고한다.
검토일: 2026-09-27. 제보 좌표: 37.570261, 126.982142.

## 관찰과 한계

도시 뷰어에서 길게 갈라진 아스팔트와 뾰족한 보도 조각을 확인했다. 해당 84_46 타일 원본에는 평행한 폭 13.8m 도로들과 사이를 지나는 폭 7m 선, 폭 4.2m 등의 연결선이 있다. 이것들이 모두 잘못된 원본이라는 뜻은 아니다. 중간 선의 실제 의미는 원본 태그를 복원하기 전에는 확정할 수 없다.

streetSection.mjs는 각 원본 도로를 독립적으로, 대칭 단면으로 축소한다. RoadNetwork.ts는 정확히 일치하는 끝점과 제한된 직선 연속 구간만 연결하며, 평행 차도를 하나의 가로로 묶지 않는다. StreetGeometry.ts는 선마다 차도·연석·보도 면을 중첩 생성한다. StreetEnvelope.ts의 장애물 차집합은 침범을 없애지만 통행 연결성을 보장하지 않는다. 폭 축소 후 이전 중첩으로 가려졌던 틈/보도 조각이 드러날 수 있다.

build-world.mjs의 도로 청크 저장은 p/w/bridge/tunnel/layer/widthSource/streetSection 위주이며 원본 ID, highway 종류, 방향, 연결 의미를 보존하지 않는다. MapCorrections에서 일반 폭 조정, 청계천 배치, 단면 조정, 높이 보정이 순차 적용되고 렌더러가 다시 면을 만든다. 하나의 최종 설계 산출물이 모든 소비자의 기준이 되는 구조가 아니다.

V1은 국소 침범 방지이며 완성된 top-down 가로 설계가 아니다. 기존 통과 검사는 건물 침범·시설 배치·일부 높이/연결을 검증했지만 가로 전체의 분할, 잘못 생긴 중앙 섬, 보도 연결망을 충분히 검증하지 못한다.

## 설계 목표와 우선순위

실측값 복제보다 지도에서 이동할 때 자연스러운 거리, 안정된 연결, 침범 없는 배치를 목표로 한다. 원본 수치는 신뢰도를 가진 입력이다. 확인된 건물/수역/중앙분리대/교량과 추정 경계는 구분한다. 모순된 원본을 무조건 불변 장애물로 확정하지 않는다.

우선순위: 높이 층과 보호 영역 보존 → 실제 통행 연결 보존 → 건물·차도·보도 공간 충돌 해소 → 폭/곡률 연속성 → 차선/식재/장식. 불가능한 조건은 명시적으로 실패시키거나 해당 구역의 이전 정상 산출물을 유지한다. 통과 판정을 위해 도로를 삭제하거나 잘라 단절시키지 않는다.

## 단일 빌드 파이프라인

1. 입력 정규화: 원본 ID, 노드/교차 관계, highway, oneway, lanes, layer, bridge/tunnel, 출처와 신뢰도를 보존한다. 차도·보도·계단·진입로·연결로를 구별한다. 태그를 잃은 기존 타일만으로 의미를 추정하지 말고 원본 캐시에서 복원한다. 없으면 필요한 지역만 다시 수집한다.
2. 거리 연결망 설계: 전체 도시의 가벼운 연결 그래프를 먼저 만들고, 평행한 왕복 차도는 하나의 가로 묶음으로 관리한다. 방향별 차도와 실제 분리대는 보존한다. 평행하다는 이유만으로 하천 양안 도로, 고가/지상, 서비스 도로를 합치지 않는다. 가까운 끝점도 같은 높이/역할이며 연결 근거가 있을 때만 결합한다. 교차로는 각 선 끝의 둥근 덧댐 대신 독립된 하나의 영역으로 설계한다.
3. 가로공간 공동 배분: 건물 사이 사용 가능한 전체 공간에서 양쪽 보도·식재·차도·분리대 폭을 함께 풀고, 필요하면 좌우 비대칭 단면이나 제한된 축 이동을 허용한다. 원본 추정 폭은 희망값이다. 구간 하나의 모서리 때문에 긴 도로 전체를 좁히지 않고 연속 단면을 설계한다. 식재 여유와 보행 유효 폭은 별도 조건이다.
4. 수평 면 분할: 같은 높이의 한 위치에 차도/보도/수면/건물 부지가 서로 모순되게 중복되지 않는 최종 면을 만든다. 통행 그래프를 유지하며 차도와 교차로 면을 구성하고, 남는 가로공간에 연속 보도를 배정한다. 중앙 섬/분리대는 명시된 설계 요소만 생성한다. 작은 조각의 자동 제거/통합은 폭·형상 기준과 연결성 검증을 함께 만족해야 한다. 실제 교통섬이나 좁은 길을 크기만으로 삭제하지 않는다.
5. 수직 설계: 확정 면과 연결망에서 도로 종단/횡단, 보도 높이, 건물 기초, 하천 바닥/제방을 함께 결정한다. DEM은 완만한 주변 경사의 참고값으로 사용한다. 교량과 하부 수면은 별도 높이 층이며 접속부 제약으로 연결한다. 청계천 같은 인공하천 설계는 이 단계들의 입력 제약으로 제공하고, 완료된 일반 도로를 나중에 덮어쓰지 않는다.
6. 부속물 생성: 최종 차도에서 중앙선, 차도-보도 경계에서 연석/펜스, 보도 식재 구역에서 가로수/가로등을 파생한다. 기존 요청대로 일반 도로 흰 차선은 생성하지 않는다. 충돌/지지 높이도 동일한 최종 면을 사용한다.
7. 공간 분할과 저장: 설계를 완료한 뒤 청크로 잘라 저장한다. 대규모 세부 처리는 주변 완충 영역을 포함한 작업 구역에서 수행하되 교차로 ID/경계 정점/높이를 공유한다. 작업 구역 순서에 따라 결과가 달라지지 않아야 한다. 2×2 압축은 전송 단위로 유지하고 설계 단위와 혼동하지 않는다.
8. 실행 시 표시: 게임과 도시 뷰어는 빌드된 최종 가로 면/높이/시설 배치를 읽는다. 런타임에서 도로 폭을 다시 계산하거나 도시별 보정을 재적용하지 않는다. 색상·시간대·LOD·GPU 버퍼 준비는 런타임에 남길 수 있다.

## 산출물 계약 제안

- streetGraph: 가로 묶음, 방향별 통행 관계, 교차로, 높이 층, 원본 추적 ID.
- surfaceRegions: 최종 차도/보도/분리대/수역/부지 다각형, 높이, 공유 경계 ID.
- streetDetails: 중앙선/연석/시설물, 근거가 된 영역 ID.
- supportGeometry: 표시 면과 일치하는 이동 지지/충돌 데이터.
- buildMetadata: schemaVersion, compilerVersion, sourceHash, settingsHash, 진단/검증 결과.

압축된 공유 정점/인덱스 다각형을 기준으로 삼고 모든 삼각형의 중복 JSON 저장은 피한다. 실제 용량/빌드시간/런타임 효과는 시범 산출물로 측정한다. 새 빌드가 실패하면 이전 정상 버전을 유지하고 신구 산출물을 같은 구역에서 중첩하지 않는다.

## 필수 검증

- 원본에서 유지하기로 한 통행 연결이 최종 면에서도 유효 폭을 가진 경로로 이어지는가.
- 명시하지 않은 차도 분할, 가느다란 보도 섬, 고립된 면, 뒤집힌 면이 생겼는가.
- 최종 차도/보도/건물/수면 간 침범과 예상하지 않은 구멍이 있는가.
- 교차로 경계와 보행 연결, 도로 폭/곡률/높이 변화가 규칙을 만족하는가.
- 교량 층을 잘못 합치거나 실제 분리대를 제거하지 않았는가.
- 청크 이음매의 위치·높이·시설 배치가 일치하는가.
- 생성 입력 순서/작업 구역 순서/재빌드에 따라 결과가 달라지는가.
- 실제 최종 메시 위 워커/플라이어 이동 및 같은 카메라의 전후 화면에서 자연스러운가.

이번 좌표와 기존 침범 좌표는 예외 분기 대신 회귀 검증 사례로 남긴다. 합성 사례도 왕복 분리도로, 교차로, 좁은 골목, 경사지, 자연하천, 인공하천, 교량에 걸쳐 구성한다. 주요 연결 단절/차도 침범/잘못된 층 병합은 배포 차단 대상으로 분리한다.

## 이행 순서

1. 기존 지도/산출물 기준선을 보존하고 새 입력 계약과 검증 기준을 확정한다.
2. 종로-청계천의 여러 문제 지점을 포함하는 연속 구역과 외곽 완충 영역에서 새 빌더를 별도 버전으로 만든다. 정확한 구역 크기는 해당 연결망의 경계로 정한다.
3. 새 가로 연결망·면 분할을 먼저 검증한 후 높이와 부속물을 연결한다. 구역 내 기존 폭/레시피/메시 보정 경로는 대체하며 추가로 겹치지 않는다.
4. 다른 거리 유형과 최소 다른 도시의 대표 구역을 검증하여 서울 좌표에 의존하지 않음을 확인한다.
5. 서울 전체로 확대하고 동일 버전의 지도/뷰어/게임 계약을 검증한 뒤 다른 도시 및 기존 압축/Release 흐름에 연결한다.

재사용: 원본 지도, 건물/랜드마크 모델, 재질, 도시별 외형 설정, 자연/인공하천 분류, 스트리밍, 2×2 압축. 대체: 여러 단계에서 선별로 폭을 보정하고 도로/보도 면을 중첩하며 마지막에 잘라내는 도로 배치 결정 경로.
