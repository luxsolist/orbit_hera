# 에셋 스튜디오

실행: 개발 서버에서 `/tools/asset-editor.html`로 접속합니다. 게임과 별도 진입점이며 왼쪽 메뉴로 드론, 플라즈모이드, 인트로, 도시, 미션을 전환합니다.

- 드론 / 플라즈모이드: 기존 페이지를 같은 출처의 프레임으로 통합해 스킨·동작·내보내기·상태 비교 기능을 유지합니다. 공통 색상과 사이드 패널 폭을 적용합니다. 각 뷰어의 독립 주소도 유지됩니다.
- 인트로: 현재 게임 장면의 선택·일시정지·시간 탐색. 전체 재생 모드는 별도 프레임에서 실제 CinematicPlayer를 사용해 자막·사운드를 재생합니다.
- 도시: 카탈로그에 등록된 스트리밍 도시 선택, 기존 실측 랜드마크 자료 선택, 위경도 직접 이동. 보행은 1.7m 시점과 지형·건물 충돌을 사용합니다. WASD/방향키 이동, 드래그 시선, Shift 가속. 공중 탐색은 Q/E로 고도를 조절합니다. 데이터가 없는 곳의 추가 지도 다운로드/생성은 하지 않습니다.
- 미션: 공통 / 단계별 목록, 추가·복제·수정. 승리 조건·실패 조건·도시·단계·설명·플라즈모이드 종류/수량/체력·다단계 투입을 편집합니다. 기존의 선택적 고급 필드는 보존됩니다. 기본 미션 형태와 투입 방식을 변경하면 해당 구성 부분은 기본값으로 교체됩니다. 엔진 미지원 승리 조건(봉합/점수)은 새로 선택하지 못하게 합니다.

`PUT /api/editor/missions`는 검증 후 `public/missions/index.json`을 임시 파일 + rename으로 저장합니다. 직전 파일은 `build/editor-backups/missions.json`에 보관합니다. 같은 출처 요청 + 세션 토큰 + 수정본 해시로 다른 페이지의 요청 및 동시 편집 덮어쓰기를 방지합니다. 임의 파일 경로를 받지 않습니다. 저장 버튼을 눌러야 반영되며 진행 중 전투는 교체하지 않습니다. 다음 미션 로드부터 새 원본을 읽고 cityId / stage가 지정된 미션은 해당 도시 / 장에서만 선택됩니다. 미지정 항목은 기존처럼 공통 풀에 남습니다.

쓰기 API는 Vite 개발 서버 전용입니다. 정적 배포본에 파일 쓰기 권한을 노출하지 않습니다. 향후 드론/도시 편집기는 `src/editor/Studio.ts`의 분류별 mount / dispose 구조에 등록할 수 있습니다. 각 뷰어는 전환 시 렌더링과 이벤트를 정리해야 합니다.

검증: 미션 원본 보존, 잘못된 목표/수량/도시 거부, 토큰/수정본 충돌 거부, 신규 생성 및 갱신·백업을 임시 저장소에서 테스트합니다. 실제 편집 페이지에서 기존 미션의 동일 값 저장도 확인했습니다. 회귀 테스트 1,735개 통과.
