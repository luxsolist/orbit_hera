# 완성 맵의 전용 랜드마크 모델 보존

## 2026-09-29 서울타워 회귀 원인
- 남산서울타워 모델 데이터는 청크에 남아 있었지만 원본 외곽선과 전용 외곽선의 정점 개수가 달라 연결이 누락됐다. 일반 9m 건물로 표시됐다.
- 일부 궁궐·청와대 건물은 전용 모델과 shelter/canopy 분류가 공존했다. 빌드에서 structures로 이동해 전용 외형이 사라졌다.

## 공통 처리
- 정확한 외곽선 연결을 유지하고 실패하면 OSM 식별자와 공간 중첩으로 연결한다. relation 부속 번호를 정규화하지만 원거리 부분이나 모호한 후보는 연결하지 않는다.
- 전용 건축물·궁궐·랜드마크·동상은 일반 구조물보다 우선한다. structureKind를 제거하고 buildings 렌더링 경로를 사용한다.
- 신규 빌드의 공통 지역 디테일 적용 단계와 기존 완성 청크 로드 단계에서 같은 함수를 사용한다.
- 내장 디테일을 활용하므로 별도 보정 파일을 요청하지 않는다. 도로·지형·빌드 입력은 보존한다.
- 이번 변경은 렌더링 연결 복구다. 압축 파일이나 Releases는 재작성하지 않는다. 다음 표준 재빌드에는 개선된 규칙이 반영된다.
