# 서울 랜드마크 건물 외형 전수 점검

2026-09-13. 서울 스트리밍 셀(주변 수도권을 포함하는 지도 범위)의 원본 landmark 건물 862개, 기존 궁궐/동상 보정 적용 후 864개를 검사했다. 대표 명소 목록에 있는 37곳만을 뜻하지 않으며 게임 의미상 교회·도서관·극장·박물관 등이 포함된다.

## 원인과 조치

기존 일반 압출 경로는 `lm`이 있으면서 특정 상세 구역 밖이면 노란 LANDMARK_COLOR를 적용하고 facadeKind=-1로 창문/외벽 표현을 생략했다. 이 경로에 638개가 남아 있었다. 서울의 게임 의미와 외형 재질을 분리하여 해당 강조색 경로를 제거했다. 추가 지정되는 서울 landmark에도 동일한 자연 외벽 기본값을 적용한다. 다른 도시의 강조 정책은 변경하지 않았다.

- 기존 전용 외형 56개를 보존했다. 궁궐·동상·기존 서울 건축 모델이 여기에 속한다.
- 나머지 808개는 지도 외곽선을 따르는 외피에 일반 건물과 같은 외벽·창문·지붕 재질 경로를 연결했다. 유형에 맞는 창문, 원본 벽돌/유리 재질 태그 및 건물·지붕 색상 태그가 있으면 적용한다.
- 실제 height 태그 또는 층수×3.3m 출처를 구분한다. 자료 없는 높이는 기존 값을 유지하며 주변 건물 높이를 복사하지 않는다.
- gabled/hipped/pyramidal 지붕 태그가 있고 외곽선이 충분히 직사각형이면 지붕 실루엣을 추가한다. 높이 전체를 초과하지 않으며 복잡한 평면이나 중정을 임의의 사각 지붕으로 덮지 않는다. 일반 압출 외피의 내부 구멍도 보존한다.
- 외형은 기존 청크 건물 메시로 병합하고, 건물별 전투 정점 범위와 landmark 의미를 유지한다. 게임/도시 뷰어가 같은 mapLocator 경로를 사용한다.

## 근거 자료와 범위

기존 37개 상세 원본 캐시에 더해 [Geofabrik 한국 추출본](https://download.geofabrik.de/asia/south-korea-260912.osm.pbf)을 사용했다. 최신 별칭/Overpass 조회가 지연되어 날짜가 고정된 추출본으로 대체했다. OpenStreetMap contributors, ODbL. 주변 건물 29,033개를 추출해 이름이 아닌 경계 상자와 양방향 외곽선 거리 2m 이내의 유일 대응으로 연결했다.

원본 landmark 862개 중 814개는 원본 지도 외곽선에 연결됐고 48개는 정확한 대응을 찾지 못해 기존 지도 외피를 사용한다. height 태그 53개, 층수 태그 117개, 비평면 지붕 태그 16개, 재질 또는 색상으로 색을 결정할 수 있는 항목 4개가 있다. 이 수에는 기존 전용 모델도 포함되며, 모두 새로 만든 정밀 모델의 수가 아니다. 새 원본 자료의 SHA-256과 원본 OSM way 링크를 기록한다.

**864개를 사진·실측 도면과 대조한 실사 정밀 모델로 완성한 것은 아니다.** 808개는 지도 기반 자연 외피이며, 태그가 없는 재질/창문 간격/지붕 등은 도시 스타일에 맞춘 표현이다. 특히 대응 실패 48개 및 개별 건물 고유 조형 디테일은 추가 자료 검증이 필요하다. 기존 애니메이션풍 도시 미술 스타일 자체를 사실적 조명으로 변경하지 않았다.

## 재현과 지속 적용

1. `scripts/fetch-seoul-landmark-appearance.py`: 날짜 고정 PBF 다운로드 및 MD5 검증.
2. `scripts/extract-seoul-landmark-appearance.py`: pyosmium을 사용해 대상 주변 원본 추출. 시스템에 osmium이 없을 때의 이번 작업용 라이브러리는 build/osm-lib에만 두었다.
3. `scripts/build-seoul-landmark-appearance.py`: 전체 원본 landmark의 청크별 외형 패치와 출처/추정 상태를 생성. 서울 맵 빌드 후 자동 실행한다. 원본 캐시가 없으면 source-matched라고 주장하지 않고 mapped-shell-estimate로 기록한다.
4. `scripts/audit-seoul-landmark-rendering.mjs`: 실제 보정 순서 적용 후 전수 점검. 결과는 public/maps/landmark-appearance/seoul/runtime-audit.json 및 audit.json에 기록한다.

최종 분류: 기존 전용 외형 56개 / 자연 외피 808개 / 외형 처리 경로 누락 0개 / 기존 노란 강조색 경로 0개. 두 동상이 원본 지도 건물 목록에 없거나 별도 보정으로 추가되기 때문에 원본과 런타임 합계에 차이가 있다.

기존 전용 모델을 제외한 자연 외피 808개만 보면 원본 대응 770개, 기존 지도 추정 외피 38개다.

## 검증 결과

- 전체 테스트 1,799개 중 1,798개 통과. 기존 야간 창문 변경으로 달라진 셰이더 버전 기대값 1개를 수정한 뒤 해당 파일 5개 테스트 모두 통과.
- 배포 빌드 성공. 기존 난독화 플러그인 소스맵 및 큰 번들 경고는 남아 있음.
- 다운로드한 지도 원본의 공식 MD5 검증 성공.
- 도시 뷰어에서 장충체육관 주변 야간 화면을 확인: 노란 강조 외피 대신 일반 외벽·창문·지붕이 표시되고 콘솔 오류 없음. 이는 야간 표본 확인이며 모든 건물의 주간 외형·실물 일치 검증을 의미하지 않음.
- 전체 864개 런타임 랜드마크의 노란 강조 경로 0개, 외형 설정 누락 0개.
