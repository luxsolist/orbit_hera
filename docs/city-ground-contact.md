# 지형·도로·건물 접합 점검

2026-09-13. 밝은 애니메이션풍과 원본 지형을 유지한다.

## 수정
- 건물 모서리만 확인하던 바닥 계산을 벽과 지형 격자/삼각형 대각선의 모든 교점으로 확장했다. 긴 벽 중간의 골짜기에서도 지표 아래 0.6m까지 외벽이 이어진다.
- 건물 내부 지형 격자점도 확인한다. 지붕은 기존 중심 지표+건물 높이를 유지하되 지형 최고점 위 최소 min(건물 높이, 2.8m) 확보가 필요한 경우에만 올린다. 실제 건축 높이 복원이 아니라 거친 DEM 관통을 방지하는 보정이다.
- 렌더 지붕과 충돌 top에 동일한 높이를 사용한다. 건물별 정점 범위와 파괴/매몰 바인딩을 유지한다.
- 공통 스트리밍 건물 생성 경로에 적용한다. 서울 외 지도도 동일한 오류 방지 규칙을 사용한다.
- 지형 자체, 도로 표면, 플레이어 접지 높이는 변경하지 않는다.

## 서울 실제 데이터 검사
저장된 37/126 셀의 78_46, 78_47, 79_46, 79_47 청크 총 5,912개 건물을 검사했다.
기존 바닥 아래 지면이 1cm 이상 낮아지는 건물 105개, 최대 틈 3.806m가 확인됐다.
새 지붕 여유 높이 규칙 대상은 251개이며 최대 높이 보정은 13.529m다. 큰 보정은 지형/건물 데이터의 추가 검토 대상으로 남긴다.
분석 결과는 build/seoul-ground-audit.json에 기록했다. 이는 데이터 기반 분석이며 전체 건물의 육안 검증을 뜻하지 않는다.

## 도로·보도와 교량
StreetGeometry는 이미 실제 지형 삼각형에 차도와 보도를 잘라 붙인다. 관련 기존 회귀 테스트도 통과했다. 경계석 12cm는 장식이며 별도 충돌을 추가하지 않는다.
현재 Ring 데이터에는 bridge/tunnel/layer/deck elevation 정보가 없다. 실제 교량/고가도로를 지상 도로와 분리하려면 지도 수집과 높이 데이터, 렌더와 충돌 표면을 함께 확장해야 한다. 이 단계에서 임의 교량 높이는 만들지 않았다.

## 검증
- 중간 골짜기, 삼각형 대각선 극값, 내부 봉우리, 좌표 원점 이동, 평지, 렌더/충돌 높이 일치 검사 추가.
- 전체 1,742개 테스트와 타입 검사/배포 빌드 통과. 기존 난독화 소스맵/번들 크기 경고 유지.
- 스타일 비교 페이지의 서울 79/47 고정 교차로 렌더 확인. 양쪽 창 모두 새 접합 계산을 사용하므로 접합 수정 전후 비교 화면은 아니다.
- 모든 경사지의 워커 이동·플라이어 비행 성능 측정 및 교량 복원은 이번에 완료하지 않았다.
