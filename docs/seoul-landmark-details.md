# 서울 랜드마크 일대 — 지도 기반 표현 확장

2026-09-13. 대상은 기존 등록 대표 26곳 + 세부 11곳, 각 중심 반경 500m다. **전체 실측 복원이나 현실과 동일한 지형을 완성한 작업이 아니다.** 원본 지도 배치와 확인 가능한 속성을 연결하고, 부족한 건물 외형은 절차적 해석으로 보완한 1차 적용이다. 도시 뷰어와 게임이 동일한 로더를 사용한다.

## 근거와 적용 방식
- 각 지점 주변 600m 사각 추출 37개를 OpenStreetMap API에서 취득했다. 적용 후보는 중심 500m 안에서 선택하며, 선택한 폴리곤/선의 전체 외곽선은 원 바깥으로 이어질 수 있다. 중복 OSM ID를 제거했다.
- 출처 URL과 SHA-256은 `src/world/cities/seoul-detail-index.json`에 있다. OpenStreetMap contributors, ODbL. 현재 OSM 태그도 측량 인증은 아니다.
- 외곽선의 경계 상자와 양방향 선 거리 2m 이내의 단일 대응만 자동 연결한다. 변경된/모호한 평면은 기존 건물을 보존한다. 롯데월드타워는 이전에 검토한 잠실 단일 외곽선에 명시적으로 연결한다.
- 원본 height는 `osm-height`, 층수×3.3m는 `levels-estimate`, 전통 건물 등의 표현용 높이는 `type-estimate`로 구분한다. 근거 없는 일반 건물 높이를 모두 저층으로 바꾸지 않는다.
- [궁능유적본부](https://royal.khs.go.kr/ROYAL/main/intro.do)의 궁궐 분류 및 OSM 건축·지붕 태그를 참조했다. 창덕궁/창경궁/덕수궁/경희궁/종묘/사찰의 전통 건축과 박물관·학교·병원·서양식 건물을 구분한다. 한국식 처마 곡선과 팔작/우진각 구분을 사용하지만 전각별 칸수·결구·단청·치수 고증을 완료한 모델은 아니다.
- [국립중앙박물관 건축 개요](https://www.museum.go.kr/MUSEUM/contents/M0804010000.do)의 최고높이 43.08m를 참고했다. 현재 모델은 지도 평면을 따르는 외피이며 실제 열린마당의 입체적 개구부까지 복원한 것은 아니다.
- N서울타워는 [OSM way 370286010](https://www.openstreetmap.org/way/370286010)의 기둥 위치와 236.7m를 참조하고, 기단 외곽선과 분리했다. 전망대의 세부 비율은 추정이다. 롯데월드타워는 555m의 위로 가늘어지는 외피로 표현한다. 곡면·외장 상세와 꼭대기 형상은 실측 모델이 아니다.
- 명동성당의 본당 원본 높이 23m와 별도로 종탑 실루엣을 약 45m로 표현했다. 종탑 치수·방위·창호는 추가 검증 대상이다. 서울역 돔, 박물관 외피, 국립민속박물관 탑부, 청와대 청색 지붕 또한 외형을 구별하기 위한 해석이다.

## 반영 범위
- 신규 건축 외형 적용: 409개 건물(기존 경복궁 전용 모델 별도).
- 이전 런타임 대비 높이 변경: 314개. 원본 수치와 표현용 추정이 함께 포함되므로 실측 보정 수로 해석하지 않는다.
- 새 모델 안에 완전히 포함되는 중복 건물 조각 15개 제거. 숭례문 위로 현대식 건물이 솟던 중첩을 화면에서 확인하고 수정했다.
- 중복 ID 제외 지면 분류 1282개, 수역 35개, 보행 경로 2434개, 담장 271개. 수역 모두에 수평 메시가 추가된 것은 아니다. 작은 수역 중 고도를 산정할 수 있는 것만 수평 메시를 사용한다.
- 수목 3957개: 원본 수목 노드 1,261개 + 지도 숲 영역 내 보충 수목. 보충 수목의 위치·수종은 실제 개별 나무의 복원이 아니다.
- 지형 격자 변경 33개: 일부 연못 바닥의 지면 관통을 줄이는 보정이다.
- 세부 데이터는 59개 청크별 JSON으로 나누어 해당 구역에서만 불러온다. 다른 도시에는 적용하지 않는다.

## 지형과 정확도에 대한 한계
1. **남산·북촌·후원 등 일대의 실제 지형 고도는 이번에 새 실측 자료로 교체하지 않았다.** 기존 32m DEM의 산세를 유지한다. 지표·수목·건물이 섞인 원본 오차, 계단·석축·옹벽·경사로의 상세는 남아 있다. 기단을 연결한 것은 떠 보이는 문제의 시각 보정이며 실측 지형 수정이 아니다.
2. 도로 중심선/주변 포장은 기존 지도와 보행 경로를 연결했다. 도로 종단 표고, 교량/터널 층위, 실제 차선 배치와 횡단면을 전수 실측 검증하지 않았다. 서울 전역을 임의 고도로 평탄화하지 않았다.
3. 일부 연못 수위는 주변 DEM의 낮은 쪽 표본으로 추정한다. 석촌호수 등 큰 수역의 정확한 호안/수위는 미완료다. 실제와 같다는 판정은 하지 않는다.
4. 등록 지점 전부에 주변 지도 보정이 적용되지만, **37곳 모두의 고유 조형물을 새로 모델링한 것은 아니다.** 세종대왕·이순신 동상의 정밀 조각, 현충원 개별 묘역/현충탑, 사직단 제단, 탑골공원 석탑, 한양도성 전 구간, 청계천 전 구간은 추가 작업이 필요하다. 해당 명소의 한 지점 주변 500m를 처리한 것이다.
5. 기존 배포 지도와 대응되지 않은 대한문 등 일부 건물은 원본을 보존했다. 주변 높이 미상 건물도 기존 추정치가 남아 있으며, 실제 건축물대장/도면과 대조해야 한다.
6. 건물 전투 메시와 외형을 함께 교체하지만, 문·주랑 하부를 통과하는 정교한 충돌이나 새 교량 보행 충돌은 미완료다.

## 재현과 검사
1. `python3 scripts/fetch-seoul-reference.py` — 원본 캐시 취득(37곳 모두 성공해야 다음 단계 실행).
2. `python3 scripts/build-seoul-details.py` — 출처 포함 청크 패치 생성.
3. `node scripts/audit-seoul-details.mjs` — 기존 경복궁/잠실 보정을 포함한 실제 적용 수량 검사.
4. `npm test -- tests/seoulDetails.test.ts tests/palaceSite.test.ts tests/cityTileLookup.test.ts --maxWorkers=2`.

새 검사에는 전 지점 데이터 존재, 다른 도시/원본 불변, 미상 높이 유지, 단일 롯데타워, 숭례문 중복 제거, 모든 신규 건축 메시의 유효성, 청크 지형 경계 일치가 포함된다. 창덕궁 후원, 경복궁 전체 조망, 숭례문, 롯데월드타워 남쪽에서 화면을 확인했다. 모든 지점의 모든 시점을 실제 사진과 전수 비교한 검증은 아니다.

최종 검증: 타입 검사와 프로덕션 빌드 통과. 전체 테스트 1,773개 통과(`--maxWorkers=4 --testTimeout=30000`). 마지막 박물관 외피 높이 조정 뒤 서울 상세 검사 7개도 재검사 통과했다. 기존 빌드의 번들 크기·난독화 소스맵 경고는 남아 있다.
