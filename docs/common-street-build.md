# 도시 공통 가로 빌드

## 구현 원칙
도시별 코드를 복사하지 않는다. 도시/구역은 config/street-regions.json에, 단면 정책은 config/street-profiles.json에 등록한다. 기본형과 구도심형이 같은 수집·설계·메시·검증·청크 저장 코드를 사용한다. 새로운 도시는 원본 경로와 검토 범위를 등록하면 이후 공통 개선을 함께 받는다.

공통 입력(street-source.mjs)은 원본 ID, 건물/부분/시설 구역, 중정, 고가 하부 높이, 차량 도로·보행로·광장·계단, 교량·터널·실내·층위를 구분한다. 시범 구역은 기존 지형과 검토된 모델을 유지하면서 최신 원본 건물/도로를 복원한다. 모델 ID가 원본의 관광/역사 시설 구역일 뿐 건물이 아니면 건물 덩어리 대신 사이트 랜드마크로 남기고 내부 실제 건물을 유지한다. 알려지지 않은 원본 ID는 임의 삭제하지 않는다.

전역 build-maps/build-world 경로도 건물 부분, 중정 및 clearanceSource 등 수직 구조 정보를 청크까지 보존한다. 최종 사이트 정보도 resolvedSites → objects.sites로 저장되며 완성 청크에서는 중복된 중간 배열을 제거한다.

## 공통 공간 배분
- 차도/보도와 보행 광장은 같은 공간 배분 안에서 설계한다. 광장·계단 경로를 차도나 중심선으로 그리지 않는다.
- 차량 여유 폭과 보행자의 외벽 접점은 다르게 취급한다. 출입구의 짧은 말단만 외벽에 맞추고, 중간 단절은 오류로 유지한다.
- 명시된 실내/지하 보행로는 지상 표면 검사 대상에서 제외한다. 일반 외부 인도는 건물을 자르지 않고 3m 탐색 범위에서 공통 절점과 자유 공간을 따라 외벽 밖으로 배치한다.
- 지도에 명시된 비인도 보행로/계단이 건물 안쪽 2m보다 깊게 1m 이상 관통하고 건물 높이가 4m 이상이면 게임용 통행 공간을 추정한다. 상부 볼륨과 지상 지지부를 분리하며 `clearanceSource=access-route-estimate`, `passageSourceIds`로 추정 근거를 남긴다. 실제 실내 구조나 계단 높이를 확인했다는 의미는 아니다. 사용자 정의 랜드마크는 이 방식으로 절삭하지 않는다. 계단의 별도 단차 메시는 아직 미구현이다.
- 교통섬은 차량 장애물이지만 보행 금지 영역은 아니다. 보행로의 장애물 집합에서는 제외하고 차도 보호는 유지한다.
- 보도 폭·건물 여유·중앙 분리 간격·시설 간격·중심선 적용 도로 유형을 공통 프로필로 조정한다.
- 보행로 주변 구조물 공간 색인과 검증용 지역 합집합/버퍼 캐시를 재사용한다. 중간 파일은 build 아래의 로컬 작업 자료다.

## 안전한 순서와 실행

~~~sh
node scripts/build-street-regions.mjs athens historic-pilot --stage-only
node scripts/build-street-regions.mjs rome historic-pilot --stage-only
~~~

이 명령은 public 지도·압축 색인·릴리스 포인터를 변경하지 않는다. 원본 복원 → 공간 설계 → 구조 분류 검사 → 메시 생성 → 시설/메시 검사 → 실제 삼각형 높이/지지면/청크 이음새 검사 → 배포 가능 판정 순으로 실행한다. 보행 경로 단절도 판정에 포함한다.

등록되지 않은 도시/프로필, 없는 원본은 지도 수정 전에 실패한다. refreshObjects는 전체 청크 경계로 정렬된 구역만 허용한다. 전체 build:city-surfaces/build-pipeline은 coverage:manifest 등록이 있어야 하며 시범 구역 4청크를 도시 전체 완료로 간주하지 않는다.

시범 구역의 데이터 검증과 화면 검증 모두 통과한 후에 전체 도시 구역을 등록하고 재빌드한다. 이후 완성 청크·2×2 압축·Releases 경로는 기존 공통 명령을 사용한다. 청크 외에 보정 결과를 별도 배포 파일로 남기지 않는 규칙은 동일하다.

각 도시는 2,048×2,048m(4청크), 이웃 지형/구조 확인 입력 16청크다.

| 보행 연결 누락 샘플 | 0 | 0 |

로마의 기존 보행 22개 경로·184개 샘플·약 362.1m 단절을 공통 보행 경로 배치/추정 통로/교통섬 분류로 수정했다. 수정 후 로마와 아테네 모두 보행 연결 누락은 0이다. 경로 가이드의 보호 여유 폭 탐색 실패는 별도 진단으로 남기며, 실제 단절 판정은 최종 표면 전체 경로의 피복 검사로 수행한다.

바티칸 박물관 원본 way/255959482는 tourism=museum 구역으로 building 태그가 없다. 기존 복합 구역을 단일 건물로 해석하던 오류를 공통 원본 역할 판정으로 제거했고, 로마 차량 경로 조정 실패 15개가 0개가 됐다.

실제 화면 비교는 브라우저 탭 응답 지연으로 완료하지 못했다. 두 도시 모두 이번 작업에서 기존 public 지도와 릴리스를 변경하지 않았으며, 전체 확대 및 출시 완료로 간주하면 안 된다.

원본: [Geofabrik Centro](https://download.geofabrik.de/europe/italy/centro.html), [Geofabrik Greece](https://download.geofabrik.de/europe/greece.html). 내려받은 PBF는 제공 MD5와 일치했다. 경로는 build/map-sources이며 재현 입력과 감사 결과는 build/streets에 보존한다.

검증: 기본 회귀 검사 145파일 1,859개, Python 공간 설계 회귀 검사 30개 및 타입 검사 통과. 첫 동시 부하 실행의 시간 초과는 검사 기준을 바꾸지 않고 동시 작업 수를 2개로 제한한 재실행에서 해소했다. 이번 보행 수정에서는 Python 공간 설계 회귀 34개(신규 4개 포함), 원본/프로필 검사 4개를 추가 확인했다.

## 누적 개선과 전체 도시 재빌드

- 공간 컴파일 캐시는 입력 및 개별 단계 함수뿐 아니라 공통 Python 컴파일러 전체 내용으로 구분한다. 보행 면 변경 뒤 이전 연석 캐시가 남는 것을 막는다.
- map-build-version.mjs는 빌드 진입점과 간접 코드 의존성, 도시 정책을 해시한다. 생성된 가로 계획의 compilerVersion과 완성 청크의 mapBuild.buildVersion에 저장한다.
- 완성 청크 검증 및 압축 전 검증은 현재 코드와 버전이 다르거나 기록이 없는 산출물을 거부한다. 기존 결과에 새 버전만 붙여 통과시키지 않는다. 옛 서울/부산 청크도 다음 압축/배포 전에 재빌드가 필요할 수 있다.
- 로마/아테네 city-wide를 manifest 전체 범위로 등록했다. 기본 실행은 전체 범위이며 historic-pilot은 명시적으로 선택할 때만 실행한다.
- 공통 실행: node scripts/build-city-surfaces.mjs <city> → node scripts/validate-complete-chunks.mjs <city> → node scripts/build-map-bundles.mjs <city>. Releases 업로드는 별도 배포 작업이다.
- 아래 실제 전체 빌드 결과가 기록되기 전에는 등록만으로 전체 검증 완료를 의미하지 않는다.

전체 도시 확대 중 확인한 공통 분류 보강: type=building 관계의 outline이 고가 연결부이면 원본 outline의 수직 정보를 유지한다. amenity=car_wash는 차량 통과 근거를 보존해 하부 통로로 처리한다. 명시된 주거 접근로와 겹치는 100㎡ 이하 소형 건물은 기존 저층 범위 또는 기본 추정 높이 12m 이하에서 상부/지상 지지부를 분리한다. 좌표/OSM ID 예외는 추가하지 않는다.

대도시 확장 시 보행 여유 폭도 metric_buffer의 겹침 영역을 둔 분할 연산을 사용한다. 연결 검증은 차도/보도 전체를 다시 합치는 대신 각 면의 포함 여부를 먼저 검사하고, 경계를 넘는 경로만 주변 청크에서 합쳐 검사한다. 단절 허용 오차는 유지하며, 실제 틈이 있는 경우와 없는 경우를 기존 전체 합집합 판정과 비교하는 회귀 테스트로 동등성을 확인한다.

전체 도시의 최종 경로 검사 실패 시 build/streets에 상세 결과를 저장하고 장식·메시 생성 및 발행을 중단한다. 원본 점유 분류는 scripts/audit-street-walking.py <city> <region>으로 확인한다. 실제 전체 실행 결과와 미적용 사유는 [로마·아테네 전체 빌드 기록](full-city-build-2026-09-29.md)을 참조한다.

보행 후속 개선의 데이터·렌더링·검증 계약은 [공통 보행면 빌드](walking-surface-build.md)에 정리한다. 전체 재빌드 통과 여부는 개별 실행 결과로 확인하며 코드 반영만으로 성공을 간주하지 않는다.
