# 서울 도심 원본 검토 — 2026-09-13

## 적용한 변경
- N서울타워 탐색 좌표를 녹사평 쪽 전망대(37.5349513, 126.9870892)에서 타워 외곽선 중심(37.551199595, 126.988221445)으로 수정했다. 근거: [OSM way 370286010](https://www.openstreetmap.org/way/370286010). 타워 자체를 새로 모델링한 것은 아니다.
- 지도 생성 과정에서 `osmId`, `heightSource`, 원본 높이/층수 태그를 보존한다. `osm-height`, `levels-estimate`, `type-estimate`, `default-estimate`, `neighbor-estimate`를 구분한다. OSM height도 측량 인증을 의미하지 않는다.
- 새 출처 필드는 다음 지도 생성부터 적용된다. 기존 배포 타일에 출처를 소급해서 만들어 넣지 않는다. 현재 타일 높이와 도로 표고는 이번에 변경하지 않았다.

## 건물 검증
서울역·숭례문·시청/덕수궁의 3개 지도 추출 영역에서 2,107개 건물을 대응시켰다. 경계 상자와 양방향 외곽선 거리가 모두 2m 미만인 단일 후보만 채택했으며, 관계형 건물 및 모호한 대응은 제외했다. 추출 사각형은 랜드마크 반경 500m 밖도 포함하므로 아래 수치는 500m 원 전체의 인증 결과가 아니다.

| 구분 | 수량 | 판단 |
|---|---:|---|
| 원본 height 태그 | 206 | 게임 높이와 일치 |
| height 없이 층수 태그 사용 | 139 | 층수 × 3.3m 추정값과 일치 |
| 위 345개 중 불일치 | 0 | 수정 근거 없음 |
| 높이/층수 근거 없이 45m 초과 | 762 | 실제 높이 미검증, 낮은 건물이라고 확정할 수 없음 |

높이 미상 건물에 주변 중앙값을 적용하던 방식이 작은 건물을 고층으로 만드는 후보 원인이다. 이를 모두 9m로 바꾸면 실제 고층 건물을 훼손할 수 있으므로 일괄 보정하지 않았다. 다음에는 건축물대장 높이/층수와 건물 외곽선을 연결하고, 불일치 후보를 개별 확정해야 한다.

## 도로 검증
중복 OSM way를 제거한 highway 1,277개 중 교량 태그 38개, 터널 태그 69개다. 차량 도로뿐 아니라 보행로도 포함한다. `ele` 태그 1개는 계단의 `0;1` 값으로, 도로 종단 표고로 사용할 수 없다. 따라서 실제 도로와 고도 오차를 계산할 수 없다.

기존 32m 간격 DEM의 경사 이상 후보는 [500m 검사](seoul-landmark-audit.md)에 남겼다. 12% 초과 샘플은 탐지 기준일 뿐 오류 확정 기준이 아니다. 지표 도로·교량·터널을 분리하고 수치표고 또는 종단 자료를 확보한 뒤 도로를 보정해야 한다. 산지와 교량을 함께 평탄화하지 않는다. 잠실 20m 추정 평탄화도 서울 도심 전체에 확장하지 않았다.
