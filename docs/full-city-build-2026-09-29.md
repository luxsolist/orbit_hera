# 로마·아테네 전체 도시 빌드 검토

## 반영한 공통 개선
- 컴파일러 변경에 따른 공간 캐시 무효화.
- 코드·간접 의존성·하위 빌드 단계·도시 정책을 반영한 빌드 버전. 오래되거나 버전이 없는 완성 청크의 압축 차단.
- 고가 outline, 차량 통과 세차장, 추정 소형 건물 접근로 분류 보강.
- 대도시 보행 여유 폭 분할 계산, 차도/보도 국소 합집합 검사 및 퇴화 경계 자르기 예외 대응.
- 전체 도시 경로 실패 시 상세 보고서 저장 후 장식·메시 생성 중단.

## 로마
범위: 기존 manifest 전체 1,640청크. 차량 원본 101,635개, 보행 원본/면 83,270개. 차량 검사 6,975,631샘플에서 누락 0. 보행 검사 2,094,476샘플 중 1,390샘플 누락, 연속 길이 기준 2,764.374m 단절. 누락 경로는 168개다.

원본 영역과 대조한 분류: 건물 119개, 건물+소형 구조물 1개, 소형 구조물 27개, 수역 21개 경로. 이 분류는 원본 영역 대조 결과이며 최종 조정 형상이나 실제 실내 동선을 확정한 것은 아니다.

- build/streets/rome-city-wide-design-progress.json: 전체 설계 및 경로 검사 결과
- build/streets/rome-city-wide-walking-review.json: 실패 위치와 원본 구조물 ID
- build/streets/rome-city-wide-partition.pickle: 보존한 설계 중간 결과

보행 품질 게이트 실패로 완성 청크/압축/릴리스 교체를 하지 않았다. 전체 맵 적용 완료로 간주하지 않는다.

## 아테네
전체 1,640청크의 도로 높이 및 입력 재생성 후 전체 공간 설계·연결 검증까지 실행했다. 차량 원본 96,296개에 대한 최종 면 검증은 누락 0이다. 보행 검사 1,006,582샘플 중 837샘플 누락, 연속 길이 기준 1,655.083m 단절이며 누락 경로는 77개다. 보행 guide 조정 실패 79개와 최종 면 누락 경로 77개는 서로 다른 단계의 지표다.

원본 영역 대조 분류: 수역 44개, 소형 구조물 22개, 건물 11개 경로. 후속 원인 분석에서 수로 폭을 누락한 진단 후보 검색을 보정하여 기존 미분류 5개도 수역으로 확인했다.

- build/streets/athens-city-wide-design-progress.json: 최종 면 연결 검사 결과
- build/streets/athens-city-wide-walking-review.json: 실패 위치와 원본 구조물 ID
- build/athens-full-rebuild.log: 실행 기록

공통 실패 차단이 동작해 장식·메시 변환 전에 종료했다. 완성 청크/압축/릴리스는 교체하지 않았다.

## 검증과 적용 상태
관련 Python 회귀 38개 및 TypeScript 회귀 11개 통과. 타입 검사와 공백 오류 검사 통과. 전체 테스트를 다시 모두 통과했다고 주장하는 결과는 아니다. 이번 작업에서 화면 시각 검증은 하지 않았다.

두 도시 모두 전체 재빌드를 실행했으나 품질 기준을 통과하지 못했으므로 적용 완료가 아니다. 도로 높이 및 원본 청크 등 중간 파일은 갱신되었지만 게임이 사용하는 기존 압축 묶음/릴리스는 유지했다. 남은 단계는 실내·계단·수역 횡단·소형 구조물의 지상 점유 분류를 공통으로 보강하고 전체 검증을 다시 통과시키는 것이다. 허용 오차를 늘리거나 모든 장애물을 잘라내어 통과시키지 않았다.

공통 진단 명령: python3 scripts/audit-street-walking.py <city> city-wide. 전체 검사 실패 보고서와 입력이 생성된 뒤 실행하며, 원본 영역 분류는 실제 실내 경로 또는 최종 조정 형상을 확정하는 근거가 아니다. 진단 파일은 build/에만 저장한다.


후속 상세 분석: [보행경로 실패 원인](walking-route-cause-analysis-2026-09-29.md).

## 보행 연결 보완 후 최종 재빌드

로마·아테네 모두 공통 보행/층위/경사 충돌/지형 격자 보완으로 전체 1,640개 청크를 재빌드했다. 로마 실제 경로 7,500,431개·아테네 6,487,481개 샘플에서 누락/충돌 0, 청크 경계 오류 0. 각 도시 441개 2×2 로컬 스트리밍 묶음으로 압축했으며 별도 런타임 보정 파일은 없다. 이전 실패 기록은 위에 보존한다. 세부 검사와 남은 품질 검토 사항은 [보행 연결 재빌드 기록](walking-rebuild-2026-09-29.md)을 참조한다.
