# 공통 보행면 빌드 계약

모든 도시가 같은 원본 역할 분류 → 통행면 설계 → 청크 메시 생성 → 메시/충돌 검증을 사용한다. 도시 좌표나 OSM ID별 예외는 추가하지 않는다.

## 원본 갱신
street-source.mjs는 건물·도로와 함께 수역을 같은 OSM 입력에서 수집한다. 수역 ID, 폭의 출처, 물길 종류, 복개 여부를 보존하고 waterChunkPieces로 청크 경계와 반폭 여유를 처리한다. 열린 platform_edge 선을 닫힌 건물 면으로 만들지 않는다. 보행로에는 level, covered, ford, incline, location을 보존한다.

## 통행면 종류
- 지상 보도: 차량 면과 별도로 생성하며 장애물과 실내 공간을 구분한다.
- 승강장: 낮은 열린 바닥이다. 전체 외곽을 보행 장애물로 쓰지 않는다. 원본의 오목한 외곽과 구멍을 바닥·지붕에 반영하며 기둥은 빌드가 정한 위치를 사용한다.
- 관람석: building=grandstand를 공통 계단형 표면으로 만든다. 원본 외곽·높이를 유지하고 짧은 축을 따라 약 18cm 단높이로 분할한다. 일반 건물 박스 대신 이 메시가 보이는 면과 발판을 제공한다. 실제 좌석 배치를 복제하는 모델은 아니다.
- 명시된 상층 보행로: 지상과 분리된 walkdeck으로 생성한다. 단일 층은 층당 3.3m 기준과 겹치는 지붕 높이를 고려해 묻힘을 피한다. 복수 층은 경로를 따라 높이를 보간한다. 실측 층고가 아니라 게임용 추정이다.
- 명시된 보행교: 별도 통행면과 검증 경로를 생성한다. level 없이 bridge만 있는 경우도 누락하지 않는다.
- 명시된 건물 level이 모두 양수이면 하부 여유 높이를 보존한다.

지하 및 기존 indoor 경로는 지상 보도로 취급하지 않는 기존 정책을 유지한다. 음수/양수 혼합 층위와 상세 실내 접근은 전체 검증 결과에서 별도 확인이 필요하며, 구현되지 않은 부분을 통과했다고 간주하지 않는다.

## 수역과 출입구
차량과 보행은 같은 수역 횡단 분류를 사용한다. 보행의 무표기 추정 횡단은 폭에 따른 짧은 구간으로 제한한다. 길 양끝이 선형 수로의 서로 반대쪽 강변에 닿으면 최대 80m 이내의 대각선 횡단도 별도 근거로 기록한다. 긴 하천변 경로 때문에 수역을 없애지 않는다. 명시된 bridge/ford는 근거로 보존한다.

건물 안에서 끝나는 비보도 경로는 외벽까지 외부 길을 만들고 내부 꼬리 부분은 interiorWalking에 기록한다. 건물 양쪽을 관통하는 경로나 footway=sidewalk, covered=yes/arcade 경로는 이 정책으로 제외하지 않는다.

보호된 랜드마크도 covered=yes/arcade로 명시된 경로에는 passageGroundParts/passageClearance를 저장한다. 원래 외형 모델은 유지하며 지상 잔여 벽과 상부 충돌을 분리한다. 실제 모델의 아치와 통로 시각 일치는 별도 화면 검토 대상이다.

## 저장과 검증
모든 통행면은 compiledStreet의 청크 메시(layer=1, level=1 포함)로 저장하며 런타임 발판 판정도 같은 삼각형을 사용한다. 관람석은 walkableProfile을 가진 기존 박스 렌더링을 생략한다. 완성 지도에 별도 보행 사이드카를 요청하지 않는다.

설계 검증에 이어 보행로도 -routes.json 진단 입력에 포함하여 최종 삼각형 누락과 건물 충돌을 검사한다. -routes.json 및 설계 보고서는 build/ 내부 진단 파일이며 게임 배포 파일이 아니다. 겹침/누락 또는 충돌 실패 시 완성 지도 교체를 중단한다.

검증 실행: Python street_compile_test.py, TypeScript streetSource/structureTypes/streetPlatformSurface/compiledStreet/CollisionWorld/streetCrossings 테스트. 작은 통합 청크에서 관람석·상층 길 생성 → bake → 면 감사 → 런타임 충돌 감사까지 실행한다. 전체 로마·아테네 결과는 이번 재빌드 종료 뒤 별도 기록한다.

## 추가 일반화 및 검증
- 낮은 명시 높이(0.35m 이하)는 일반 건물 박스가 아닌 통행 가능한 바닥 면으로 만든다.
- 폐허 태그는 원본 외곽의 잔여 벽과 보행 출입구로 변환한다. 추정 높이만 있는 폐허 벽은 2m 이하로 제한한다. 지하 layer 구조물은 지상 점유에서 제외한다.
- 실외 태그 indoor=no를 실내로 오인하지 않는다. 보도와 양 끝이 건물 밖인 관통 보행로도 기존 면적 손실 제한 내에서 공간을 먼저 확보한다.
- 추정 수로 폭만 공통 프로필의 기본 강 12m/시내 4m 상한을 적용하고 원래 추정값을 waterInfo.sourceEstimate에 남긴다. 태그 또는 면 외곽으로 지정된 폭은 변경하지 않는다.
- 기본 보행 우회 범위는 6m이며, 실패 시 공동 노드를 유지하는 16m 범위 재설계를 시도한다. 허용 오차를 늘려 누락을 통과시키는 것이 아니다.
- 목재 표면으로 지도에 명시된 수변 길은 물 위의 별도 보행면으로 보존한다.
- 관람석의 높은 끝에는 외부 경로로 내려오는 접속 면을 만들고, 아래쪽 솔리드 충돌 공간도 supportVolumes로 같은 청크에 저장한다.
- 발판 판정은 0.1mm 반올림 산출물에 맞는 0.2mm 거리 허용치를 사용한다. 삼각형 크기에 따라 달라지는 기존 무차원 허용치를 대체하며, 실제 1cm 틈은 계속 거부한다.

기존 실패 지점 국소 재검사: 로마 168개 및 아테네 77개 모두 missing=0. 이는 전체 도시 재빌드를 대체하지 않는다. Python 51개, 전체 빠른 TypeScript 테스트 147개 파일/1,868개 통과. 타입 검사와 공백 오류 검사 통과. 통합 청크의 최종 검사 101샘플에서 누락/건물 충돌 0. 전체 재빌드는 최종 공통 코드로 재개했다.

## 빌드 성능 보완
전체 도시의 `upper_walking_surfaces`에서 접속 경사면마다 도시 전체 장애물과 차집합을 계산하는 병목을 확인했다. 공간 인덱스로 경사면과 실제 교차하는 장애물만 조회해 같은 차집합을 계산하도록 변경했다. 인접 및 원거리 장애물을 포함한 회귀 테스트로 전체 차집합과 형상 동등성을 검증했다. 전체 코드 서명이 달라지므로 기존 중간 캐시를 재표기하지 않고 양 도시의 공식 전체 빌드를 새로 실행한다.

## 강변에서 횡단으로 바뀌는 경로
로마 전체 재검사에서 차량 누락 0, 보행 2,110,748샘플 중 6샘플(1경로, 12.093m)이 남았다. 해당 경로는 약 106m의 강변 구간 끝에서 강을 건너므로 기존 짧은 수역 교차 길이 제한만으로 횡단을 인식하지 못했다. 공통 빌더에 강 중심선 교점 전후의 측면 부호 변화로 실제 횡단을 판별하고, 강의 국소 법선 방향에만 짧은 연결부를 확보하는 규칙을 추가했다. 하천을 따라 겹친 구간 전체를 지우지 않는다. 해당 잔여 구간 국소 재검사 누락 0, 강변 보존과 중심선 추종 경로의 오판 방지 회귀 검사 통과. 최종 전체 도시 검사는 다시 실행 중이다.

최종 코드의 로마 전체 설계 연결 검사: 보행 2,110,752샘플, 누락 0, 단절 길이 0m, 보행 경로 설계 실패 0. 차량 경로 누락 및 단절 길이도 0. 이는 설계 면 검사 결과이며 최종 청크 메시/충돌 검사와 완성 청크 반영은 별도 단계다.

## 최종 메시/충돌 검증 보완 (2026-09-29)

- 경사 보행면 하부의 충돌체는 전체 영역의 최대 높이를 적용하지 않는다. 렌더링된 각 삼각형의 평면식을 사용해 낮은 쪽 보행면을 가리지 않게 한다. 뷰어/게임의 이동·빔 차폐·상면 조회가 같은 평면식을 사용한다.
- 가느다란 삼각형의 경계 허용치는 무한 직선이 아닌 유한 선분까지의 실제 거리로 계산한다. 꼭짓점 밖의 높이 외삽을 방지한다.
- 청크 경계는 지상면끼리 비교하고, 상부 보행면은 실제 경계를 통과하는 경로의 같은 층끼리 비교한다. 상부 구조물 끝과 지상면의 높이가 다른 것은 단절로 판정하지 않는다.
- 면으로 지정된 광장의 외곽선은 보행 경로가 아니다. 면의 소유권/누락 검증은 유지하고 경로 중심선 검사는 선형 경로에 적용한다.
- 지붕 지지대와 담장은 보행 경로의 폭을 예약한 뒤 배치한다. 검증에서도 기둥을 무한 높이로 가정하지 않는다.
- 대규모 재빌드의 설계 중간 결과는 입력 파일·설계 함수·저장 내용의 해시가 모두 일치할 때만 재사용한다. 메시 인코딩, 충돌체 생성, 최종 검증은 다시 수행한다. 검증된 중간 결과는 build/에만 저장하며 배포 청크의 별도 의존 파일이 아니다.

로마/아테네 전체 재빌드·전수 검사·로컬 압축이 완료됐다. 최종 수치는 [재빌드 기록](walking-rebuild-2026-09-29.md)을 참조한다.

## 검증 단계와 최종 지형 격자

기존 네트워크 높이 보정과 국부 지형 보정은 최종 streetPlan을 제외한 입력에서 검증한다. 최종 계획이 높이 배열을 교체한 다음 이전 단계의 원본 일치 여부를 비교하지 않는다. 최종 계획에는 별도의 메시 소유권·경로 충돌·층위별 경계 검사를 적용한다.

MapCorrections에서 최종 지형 높이를 반영할 때 격자 크기도 최종 배열 길이에 맞춰 갱신한다. 이전 129×129 국부 보정 격자에 새 33×33 배열을 붙여 NaN 높이가 발생하지 않게 한다. 최종 도로 높이가 생략된 계획은 최종 지형 높이를 공유한다. 완료 청크 검증은 높이 배열 길이와 격자 크기, 모든 높이의 유한성을 확인한다.

현재 실행의 전체 결과와 남은 검토 사항은 [로마·아테네 보행 연결 재빌드](walking-rebuild-2026-09-29.md)에 기록한다.
