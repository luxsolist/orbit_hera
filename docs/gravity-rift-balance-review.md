# 중력이상지대 실제 화면 / 워커·플라이어 비교 실측

2026-09-19, 로컬 개발 서버의 실제 Game 화면을 인앱 브라우저에서 실행했다. 전투 수치는 변경하지 않았다.

## 결론

이상지대 출현 지연·통과 피해·내부 경고는 동작한다. 그러나 이번 근거리 혼합 편성에서는 플라이어가 정지/이동 모두 우세했다. 이상지대를 만나지 않고 전투를 끝내는 경우가 있어, 두 개의 고정 위험 구체만으로 플라이어 밸런스를 맞출 수는 없다. 워커는 정지 시 근접 정예에게 밀리지만 측면 이동만으로 결과가 크게 개선된다.

## 조건과 한계

- 서울 광화문 광장 37.5725, 126.9769, 월드 시작 방위 0. 동일 위치, 서울 정오 고정(2026-09-19 12:00 KST).
- 기본형/레벨 1. 캠페인 성장·자매 도시 난도·원격 감독·스킨 저장/XP/캠페인 적립 제외. 지형과 충돌, 무장, 자동사격, 적 AI, 중력이상지대, 3인칭 카메라는 실제 게임 클래스를 사용했다.
- 거머리 4 × HP240, 모기 4 × HP240, 정예 1 × HP900, 배치 반경 180m, 작전 반경 1200m. 보스·장기 증원·도시 방어는 이번 실측 대상이 아니다.
- EnemyManager 난수 seed 19. 전투 행동의 난수 소비는 프레임/상호작용에 따라 달라지므로 프레임까지 동일한 리플레이는 아니다.
- 가장 가까운 시야 확보 적을 향해 최대 2.1rad/s로 시점을 돌리는 동일 자동 입력 정책. 수동 사격/특수기/점프/대시 없음. 이동 시험은 적 출현 시점부터 D를 유지한다. 실제 사람의 모바일 조작 숙련도 평가가 아니다.
- 플라이어 기본 출격 고도는 지면 +100m. 고고도 시험은 적 배치 **전에** +600m로 맞추므로 적도 그 고도를 기준으로 출현한다. 통과 시험만 배치 후 이상지대 중심에서 250m 떨어진 곳으로 시작 위치를 설정하며, 5초부터 실제 전진 입력을 한다. 통과 시험의 처치 시간은 기본 출격 시험과 직접 비교하지 않는다.
- 최종 비교 화면 1280×720, DPR1.5(실제 렌더 비율은 게임의 상한 적용). 주변 스트리밍 15초 준비 후 진행. 초기 GPU 준비/잔여 스트리밍은 완전히 배제되지 않았다.
- 최대 게임 시간 45초, 전멸 또는 기체 파괴 시 조기 종료. 표의 시간은 **스폰 대기 8.2초를 포함한 게임 시간**이며 실제 벽시계 시간은 원자료에 별도 기록했다.
- 무작위 출격 위치/크기가 변했던 예비 실행은 최종 표에서 제외했다. 본 표는 각 조건 1회, 동일 seed의 소규모 벤치마크다. 평균 승률이나 전체 캠페인 난이도로 일반화하지 않는다.

## 확인한 동작

1. 모든 비교 전투에서 최초 전투 가능 적/첫 자동 사격은 약 8.21~8.23초였다. 설정된 활성화 4초 + 형성 1.2초 + 도착 예고 3초와 일치한다.
2. 전투 출현 예고의 푸른 와이어 구체와 실제 드론/도시/자동 빔이 화면에서 표시됐다. 내부에서는 ‘중력이상지대 내부 — 중심 반대 방향으로 이탈하세요’ 경고와 피격 피드백을 확인했다. 내부 시각 검증 화면에서 콘솔 오류는 없었다.
3. 정면 관통은 약 1.8초 노출, 환경 피해 12.9599/60 HP(21.60%)였다. 관통 직후 표본의 HP 감소가 이를 보여준다. 전투 종료 누적 손실 18.9599에는 이후 적 피해 6도 포함된다. 환경 피해 12%/s × 약 1.8초와 부합한다. 원자료의 노출 시간은 프레임 끝 위치를 세는 근사치이며, 실제 피해는 선분-구체 교차 구간을 적분하므로 소수점 차이가 정상이다.
4. 지상/100m/600m 비교에서는 이상지대 노출 시간이 모두 0이었다. 임무 수행에 관통이 필수가 아니어서 위험 지역 회피만으로 현재 페널티를 완전히 피할 수 있었다.

## 밸런스 해석

- 워커 정지는 정예 HP427.5가 남은 상태로 파괴됐다. 화면에서는 정예와 기체가 매우 근접해 표적이 기체에 가려졌고, 후반 사격이 처치로 연결되지 않았다. 측면 이동 시 21.87초/HP90%로 완료했다. 근접 총구 수렴·후방 발사 차단·조준 각도·카메라 가림의 상호작용을 별도 재현해야 하며, 이번 관찰만으로 특정 코드 결함을 확정하지 않는다.
- 플라이어는 정지/600m 정지/이동 모두 약 12초에 완료했고 HP95%/95%/100%였다. 이 편성에서는 고도 상승으로 교전이 사라지는 현상보다 짧은 처치 시간의 영향이 크다.
- 무기 JSON과 실제 발사 경로 기준, 근거리 배율 상한에서 자동 빔의 이론상 피해는 워커 `45 × 1.5 / 0.2 = 337.5 HP/s`, 플라이어 `15 × 4 × 2 / 0.13 ≈ 923.1 HP/s`. 두 총구가 모두 적중하고 프레임/경직/가림/위상/게이지 손실이 없는 상한이며, 실제 DPS 실측값은 아니다. ‘경주파’의 작은 단발 수치와 달리 근거리에서 약 2.74배 상한이다.
- 이동 시 플라이어의 빠른 이동과 이 근거리 화력이 함께 작용한다. 이상지대 피해를 더 올리는 것만으로는 평소 교전 차이를 해결하지 못한다.

## 시각 개선 우선순위

- 내부 경고 문구는 읽힌다. 반면 밝은 하늘과 작전구역 에너지 벽의 황색 세로 패턴 때문에 이상지대의 구형 윤곽/보라색 경계가 묻힌다. EnergyWall은 800~2600m 거리에서 페이드되므로 반경1200m의 이번 전장에서는 먼 배경까지 계속 보인다.
- 에너지 벽을 경계 접근 시 위주로 약화하고, 이상지대는 낮에도 보이는 얇은 어두운 테두리 + 보라색 가장자리 + 접근 방향 표시를 검토한다. 화면 전체 왜곡/밝기를 키우는 방법은 피한다.
- 구체 내부의 ‘중심 반대 방향’ 문구에 가장 가까운 탈출 방향 표시를 함께 주는 것이 좋다.

## 다음 수정 권장 순서

1. 워커 초근접 자동사격을 별도 재현: 표적이 총구보다 뒤/안쪽에 있을 때 조준 가능 여부와 실제 피해를 표시하고, 카메라 가림과 적 접촉 거리를 함께 점검한다. 총구가 동체를 관통해 뒤로 발사하도록 단순 제한 해제하지 않는다.
2. 플라이어 두 총구 합산·거리 배율을 기준으로 목표 처치 시간을 정하고, 여러 거리/편성/seed에서 다시 측정한다. 현재 수치만 보고 워커 HP를 올리거나 이상지대 피해를 강화하지 않는다.
3. 이상지대를 접근/전진 경로와 목표 주변에 배치하되 안전한 우회 통로를 보장한다. 구체 수/위치는 미션별로 조절하고, 고도 전체를 무조건 막지 않는다.
4. 밝은 배경의 위험 윤곽과 탈출 안내를 개선한 뒤 보스·증원·장기 임무 및 사람이 직접 조작하는 모바일 테스트로 확대한다.

## 재현

개발 서버에서 `/?controls=touch&rift-review=1&drone=walker&seed=19`에 접속해 ‘측정 시작’을 누른다. 상단 링크로 정지/이동/고고도/관통/내부 화면을 선택한다. `mode=stationary|strafe|high|cross|inside`, `drone=walker|flyer`. 직접 키/포인터 입력이나 탭 숨김 시 무효로 중단한다. 측정값 접기 버튼으로 실제 화면을 볼 수 있다. 개발 모드에서만 진입하며 일반 게임에는 측정 UI가 생기지 않는다.

로컬 화면 증거: `build/rift-balance-review/`의 walker-base.png, walker-moving.png, flyer-base.png, flyer-high.png, flyer-cross.png, rift-inside.png. 이 경로는 로컬 생성물이며 소스 배포에 포함되지 않는다.

검증: TypeScript 타입 검사 통과, gravityRifts 및 combatMetrics 회귀 테스트 11개 통과. 이번 턴에서 전체 테스트를 재실행한 것은 아니다.
