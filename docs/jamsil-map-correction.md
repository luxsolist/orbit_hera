# 잠실 타워·도로 국소 보정

## 확인된 자료와 오류
- 롯데CM 공식 자료: https://www.lottecm.com/en/build/lotte-world-tower.html — 타워 555m, 123층.
- 설계사 KPF: https://www.kpf.com/project/lotte-world-mall — 몰은 타워와 별개의 11층 복합시설. 몰의 정확한 미터 높이를 제공하지 않으므로 층수만으로 새 실측값을 만들지 않는다.
- 저장된 37/126/5_3/95_52 청크에서 타워 근처 폴리곤 23개가 모두 555m다. 작은 부분 구조와 겹치는 윤곽까지 지상부터 555m로 압출된다.
- relationPolys가 building 관계의 part를 outer와 동일하게 처리하는 경로가 있다. building 관계는 outline만 외곽으로 사용하도록 수정했다. 일반 multipolygon 처리는 유지한다.

## 적용
- mapLocator의 공통 청크 로드에서 correctJamsilChunk 적용. 원본 파일은 보존한다. 게임·도시 뷰어·스폰 지형 프리로드가 동일한 보정 데이터를 사용한다.
- 기존 잘못 구워진 데이터는 타워 중심 100m 내 555m 폴리곤 중 4,700㎡ 이상 최대 외곽이 있는 중복 묶음만 정리한다. 랜드마크 속성을 최대 외곽으로 이전한다. 주변의 다른 높이 값은 변경하지 않는다.
- 타워는 단일 외곽 압출 초안이다. 실제 층별 후퇴/곡면/min_height를 복원한 정밀 모델이 아니다.
- 주변 폭 12m 이상 도로의 기존 중심선·폭은 보존한다. 저장된 주요 도로 186개 선분을 따라 DEM 요철을 완화한다.
- 도로 목표 높이 20m는 반경 700m 안 기존 DEM 중 10~25m 표본의 중앙값이다. 범위 선정과 평면화는 국소 시각 보정이며 측량/도로 설계 고도는 아니다.
- 타워 반경 450m 안 도로 가장자리 32m까지 목표 높이, 도로에서 96m 및 반경 700m까지 부드럽게 원본에 연결한다. 전역 좌표로 계산하여 청크 경계 양쪽 높이가 같다. 도로 옆 지형에도 연결 구간이 생긴다.
- 실제 도로 종단·횡단 경사, 지하차도·교량 구분, 인접 모든 건물의 실측 높이는 아직 확보되지 않았다. 이번 결과를 실제와 동일한 복원으로 취급하지 않는다.

## 확인
타워 중복 제거/주변 높이 보존/랜드마크 이전, 다른 지역 무변경, 청크 경계 일치와 원본 불변성, building 관계 part 배제 테스트 추가. 도시 뷰어에서 타워 위치의 공중 시점으로 도로 표면 표시 확인.


## 후속 정밀 점검·수정
원본 OSM API의 건물별 태그와 대조했다(2026-09-13). 서쪽 way/1101504851은 bicycle_parking=shed, 남서쪽 way/522900260은 자전거 수리센터, 남동쪽 way/802071228은 송파나루길 206이다. 세 건물 모두 height/building:levels가 없어 실제 층수는 확인하지 못했다. 출처는 jamsil-correction.json의 heightOverrides에 기록한다.
- 서쪽 41.5㎡, 남서쪽 143.5㎡, 남동쪽 764.5㎡의 건물이 모두 555m로 저장돼 있었다. 주변 220m 중앙값도 타워 부분 구조 중복 때문에 모두 555m였다.
- 남쪽 95_53 타일에는 큰 타워 외곽이 없어서 기존 보정이 작동하지 않았다. 해당 작은 10개 타워 부분 구조를 큰 외곽의 존재 여부와 무관하게 정리한다.
- 세 건물은 좌표 폴리곤 전체와 기존 높이 555m가 일치할 때만 보정한다. 보관소 3m, 나머지는 기존 미상 건물 기본값 9m. 실측 높이가 아니며 후속 조사 대상이다. 원본에 새 높이가 들어오면 보정하지 않는다.
- 일반 높이 보간은 150m 초과 참조를 제외하고 중심 10m 격자/높이 1m 기준 중복 투표를 제외한다. 알려진 초고층 건물 자체의 높이는 바꾸지 않는다. 150m는 보간 안정성을 위한 정책값이며 실측 판정선이 아니다.
- 원본 OSM 응답은 build/jamsil-west-reference.osm, build/jamsil-east-reference.osm에 보관(미추적). 각 출처 링크는 설정에 기록.
