# 서울 밀집 지역 외관 비교

비교 대상: `public/maps/37/126/4_2/79_47.json`, 약 37.563°N / 126.922°E, 1.024km × 1.024km, 건물 2,894동. 현재 게임의 buildChunkMesh·SkyEnvironment·createComposer를 사용한 고정 카메라 검토 화면 `build/seoul-density-review.html`에서 확인했다.

참조: [Tranmautritam의 서울 전경, 2016-11-11](https://commons.wikimedia.org/wiki/File:Seoul_Buildings_city_view_366107.jpg). 사진과 동일 위치·시각·날씨의 재현은 아니므로 픽셀 일치나 정량적 사진 재현 점수는 주장하지 않는다.

## 판정

현재 결과는 참조 사진에 비해 지붕과 건물 군집이 어둡고 대기감이 부족하다. 사진에서 보이는 밝은 외벽의 비중과 지역별 재질 분포를 재현하지 못했다. 기존 16색 샘플링은 색 후보를 만드는 단계였으며 사진과 비슷하게 보이는 최종 검증까지 충족한 것은 아니다.

- 병합 메시에서 확인한 색별 동수: 181 / 202 / 190 / 186 / 163 / 146 / 179 / 201 / 162 / 189 / 172 / 179 / 194 / 173 / 194 / 183. 팔레트 16색이 모두 존재한다. 원래 배정색과 병합 후 정점색, 건물 내 정점색 간 불일치 0.
- 밝은 네 색(아이보리·밝은 콘크리트·살구 베이지·펄 화이트)은 727동, 약 25.1%. 사진에서 채취한 어두운 유리/그림자 색까지 모든 외벽에 균등 배정하고 있어 밝기 분포를 재현하지 못한다.
- 사진에서 조명/그림자가 이미 반영된 RGB를 도료색으로 사용한 뒤 게임 조명을 다시 적용한다. 이는 실제 표면 반사율 복원이 아니다.
- 지붕은 외벽색에 녹색 방수면 텍스처를 곱한다. 텍스처 기본색 #55675d의 선형 채널 값은 약 0.09~0.136으로, 특히 어두운 외벽색의 지붕이 지나치게 검어진다.
- 외벽 하단 감광, 층간 띠, 유리 감광이 추가된다. 어두운 건물이 모이면 입면의 구분이 약해진다.
- 창 크기/층 높이는 네 가지 규칙으로 반복되며, 근거리 녹색 빈 지면과 강한 그림자가 사진보다 두드러진다. 사진의 원경은 안개로 부드러워지지만 현 포그는 청크 경계 은폐용으로 멀리서 시작한다.
- 햇빛과 밝은 표본 일부는 따뜻한 색이지만, 이 청크가 황토색만으로 배정된 것은 아니다. 황토색 체감은 밝은 면의 색 편향과 어두운 다른 색의 식별 저하를 함께 고려해야 한다.

## 권장 수정 순서

1. 외벽과 지붕의 색상 배정을 분리하고, 지붕색 이중 곱셈을 제거한다.
2. 외벽용 밝은 중성색/회백색을 중심으로 가중 배정하고, 그림자·유리 표본은 해당 용도로 제한한다. 분포는 여러 사진으로 검토해야 한다.
3. 사진 RGB를 그대로 반사율로 취급하지 않고 밝기 보정한 재질값을 별도로 관리한다. 전체 노출 상승보다 어두운 면의 재질/환경광을 먼저 조정한다.
4. 동일한 밀집 청크/카메라를 유지해 전후 비교한다. 그 뒤 배경 포장과 제한적인 대기 원근을 조정하고 적·빔 시인성을 다시 검사한다.

이번 작업은 검토이며 게임 재질·조명 설정은 변경하지 않았다.

## 후속 개선 적용

검토 후 지붕 독립색·외벽 팔레트 보정·밝은 외벽 가중 배정·유리와 하단 감광 완화를 적용했다. 현재 수치는 city-appearance.md의 마지막 절을 따른다. 이 문서 앞부분의 25.1% 및 지붕 이중 곱셈은 수정 전 진단이다.
