# 04 · 조작 & 게임플레이 규칙

## 조작 — 데스크톱

| 입력 | 보행 드론 | 비행 드론 |
| :--- | :--- | :--- |
| `W A S D` | 이동 | 시선결합 이동(전후좌우) |
| `MOUSE` | 조준(Pointer Lock) | 조준 — 시선이 비행 방향 결합 |
| `좌클릭` (hold) | 주파수 빔(자동발사 보조 수동 사격) | 동일 |
| `우클릭` | 특수 무기(다중 빔 살포) 발동 | 동일 |
| `SPACE` | 점프 | 상승(호버 추력) |
| `SHIFT` (좌/우) | 회피 대시 | 하강(호버 추력) |
| `C` | — | 하강 대체키 |
| `ESC` | 링크 해제(일시정지) | 동일 |

- **동시 입력 보장** — 입력은 키 집합(`Set`)으로 추적해 여러 키를 동시에 누를 수 있다. 락(플레이) 중에는 게임 키(`W A S D`·`Space`·`Shift`(좌/우)·`C`)의 브라우저 기본동작(Space 스크롤 등)을 막아 전후좌우 + 상승/하강 동시 입력이 데스크톱에서 안정적으로 들어간다.
- **하강 대체키 `C`** — 비행 하강은 `Shift`와 `C` 둘 다 받는다. 일부 키보드에서 `Shift`+`WASD` 동시 입력이 씹히는 키 고스팅(N-key rollover)을 피하기 위한 대안.

조작 안내는 드론 스펙의 `actions[].desc`에서 동적으로 생성되므로 드론마다 자동으로 달라진다.
드론별 자동발사 사거리·방향별 이동 속도는 [전투 규칙](#전투-규칙) 참조.

## 조작 — 모바일 (가로 모드 전용)

- **좌측 절반** — 가상 조이스틱(터치 지점에 표시). 변위 크기에 비례해 이동 속도 단계화,
  데드존 밖 축만 8방향 키로 합성.
- **우측 절반** — 시선(드래그, 모바일 전용 민감도 배수 `LOOK_SCALE=9.6`; 데스크탑 포인터락 무관) + 우하단 4버튼 클러스터:
  ```
  [ FIRE ]  [ ACT1 ]      좌상=기본무기  우상=ACT1
  [  SP  ]  [ ACT2 ]      좌하=특수무기  우하=ACT2(엄지 홈)
  ```
  FIRE/SP 라벨은 무기 스펙 `abbr`에서, ACT1/ACT2는 드론 스펙 `actions`에서 채워진다.
  (보행: ACT1=점프 ACT2=대시 · 비행: ACT1=상승 ACT2=하강)
- 세로 모드에서는 "가로로 돌려 주세요" 안내가 뜨고 입력이 차단된다.

상세 구현은 [implements/02](../implements/02-input-and-player.md#모바일-컨트롤).

## 게임 흐름 (상태)

```
intro(인트로 컷씬) ─▶ menu(전장 선택) ─▶ loading ─▶ playing ⇄ paused(ESC)
                          ▲                              │
                          └────────(reload 재출격)◀── dead (미션 종료/리스폰 소진)
```

- **menu** — 세계지도에서 침공 지점(점) 클릭 → 지역 팝업에서 **드론 선택 → 즉시 출격**.
  배경에는 랜덤 인트로 장면이 페이드 전환되며 재생. "스토리" 버튼으로 인트로 컷씬 재생.
- *(차원 해석 — [05 §2.9 전역 루프](05-dimensional-cosmology.md))* 세계지도 = **중력파 전조 관측
  콘솔**(붉은 점 = 벌크 지름길로 먼저 도착한 균열 전조), 침공지가 매번 바뀜 = 브레인 파문 간섭
  무늬의 재배열, 출격 = 중첩 상태의 후보 균열을 **관측으로 확정**하는 행위, RETRY = 시간 에코
  재진입, 탐방 모드 = 잔향이 가라앉은 권역의 무관측 정찰.
- **playing** — Pointer Lock 상태에서만 시뮬레이션 진행(락 풀리면 자동 일시정지).
  기체 파괴 시 리스폰 예산이 남으면 **제자리 부활**(전투 지속), 소진 시 미션 실패로 종료.
- **dead** — 미션 성공/실패(리스폰 소진·건물 손실 초과·시간 초과 등) → 결과 패널("작전 완수/실패").
  **다시/RETRY** = 같은 전장으로 reload 재출격(새 랜덤 미션). **전장 선택** = 메뉴 reload.

## 전투 규칙

### 사격 — 자동발사 + 수동 조준 보조
- **360° 소프트 락 자동발사** — 좌클릭 유지 없이도 자동발사 사거리(`auto.range`) 안의 적을 향해 빔이 나간다.
  보행(중주파 빔) **32 m** / 비행(경주파 빔) **100 m**. **모바일은 추가 ×2(보행 64 m / 비행 200 m)** — 터치 조준 보정.
- **수동 조준 보조(에임 어시스트)** — 좌클릭 사격 시 크로스헤어 주변 콘(`manual.assistConeDeg`,
  중주파 13° / 경주파 28°, **모바일 비행 ×2 = 56°**) 안의 적으로 빔이 살짝 끌려간다. 수동 사격은 자동발사보다 데미지가 높다.
- **거리 감쇠** — 빔 데미지는 기준 거리(`falloff.refDist`)를 기준으로 가까울수록 증폭, 멀수록 감소.
  경주파 빔은 원거리 데미지 유지율이 높아(`minMult` 0.75) 카이팅 사격에 적합.

### 방향별 이동 속도
- 시선 기준 이동 방향에 따라 속도 배수 적용(`dirSpeedMult`): **전진 1.0 / 옆걸음(스트레이프) 0.85 / 후진 0.6**.
  보행·비행 모두 동일 적용. 무한 후진 백페달 카이팅을 억제한다.

### 드론 정체성 (영역 트레이드오프)
- **보행 드론(WALKER)** — 지상 근접 난투형. 내구성↑(HP 120), 근거리 고화력(중주파 빔, 짧은 자동락 32 m),
  회피 대시 보유. 후진 페널티로 물러서며 싸우기 불리 → 파고들어 싸우는 기체.
  주로 접근+접촉 흡수형(거머리/LEECH) 떼를 상대한다.
- **비행 드론(FLYER)** — 공중 카이팅형. 고속(속도 111.11 ≒ 400 km/h)·취약(HP 60), 원거리 화력 유지(경주파 빔,
  자동락 100 m). 비행 하한 고도(`minAltitude` 18 m)에 묶여 지상 안전지대로 내려갈 수 없고, 천장은 지면 대비 1 km.
  주로 도망+원거리 드레인형(모기/SKEETER)을 상대하며, 모기도 천장까지 따라 올라와 수직 도그파이트가 가능하다.

### 자원
- **체력(HP)** — 적 흡수(거머리 접촉/모기 드레인 빔)로 감소. 피격 시 0.6 s 머시 무적(이 동안의 추가
  흡수는 피해·적 회복 모두 무효). 0이면 사망. 적 처치 시 흡수당했던 만큼 HP 환수(killRefund).
  ※ 아직 패시브 자연 회복은 없다(향후 업그레이드 항목).
- **주파수(Frequency)** — 빔/특수무기 발사 자원. 초당 자동 회복(드론별 `freqRegen`).
  특수무기 발동 중에는 회복 억제.
- *(차원 해석 — [05-dimensional-cosmology](05-dimensional-cosmology.md))* HP = 기체의 영점 에너지
  비축(흡수당하면 물질이 약화), 머시 무적 = 피격 순간 전개되는 **국소 카시미르 차폐**, killRefund =
  흡수된 에너지가 아직 그 투영에 국소화되어 있어 결맞음 붕괴 시 막으로 되돌아오는 것(최근접 드론이
  회수), 주파수 = 공진기의 **결맞음 예산**(회복 = 재결맞음), 리스폰 직후 1.5 s 무적 = 얽힘 채널
  재배정 후 **재결맞음 정착 시간**.

### 적 — 플라즈모이드 (`CoreEnemy`)

> *(차원 해석 — [05-dimensional-cosmology](05-dimensional-cosmology.md) 정본)* 플라즈모이드는 개별
> 생물이 아니라 **벌크의 단일 6차원 생명체가 우리 3차원 막에 드리우는 3차원 투영들**이다. 구체 형태
> (6차원 물체의 3차원 투영), 지형 무충돌 자유 부유(막 물질과의 약한 결합), 상하 자유 3D 추적(본체가
> 벌크에서 투영 위치를 재배치), 무한 웨이브(투영 절단 ≠ 본체 타격), 아키타입 스폰 고도 밴드(씨앗 장
> 들뜸 등위면), 동료 간 분리(같은 본체의 투영끼리 융합 회피)가 전부 이 한 설정에서 나온다.
> 거머리의 접촉 흡수 = 근접장 중첩으로 **영점 에너지**를 퍼올리는 것, 모기의 드레인 빔 = 막 표면을
> 따라 여는 장 결합 채널(그래서 건물에 가로막힘 — 시선 필요), 흡수 후 성장(grow) = 본체가 그 지점에
> 더 깊이 교차하는 것.
>
> ⚠️ 이 공격 모델(접촉 흡수/드레인)은 전면 재정립이 결정됐다(낙인+심판 파문·건물 납치 등 직무
> 기반 체계 — 정본: [서사편 §6](../private/05x-narrative-truth.md) ⚠️스포일러). 아래 서술은 구현
> 교체 전까지의 현행 사양.

- **2종 아키타입** — 개체 행동은 어느 드론을 상대하든 무관하게 고유 아키타입으로 결정된다.
  - **모기(SKEETER)** — 도망형. 적정거리를 유지한 채 표적 주위 **사방·상하로 고르게 흩어져** 자유롭게 유영하며
    **원거리 드레인 빔**으로 HP를 빨고, 선회 시 위/아래 무작위 수직 회피로 빠져나간다. 주로 공중/플라이어를 상대.
  - **거머리(LEECH)** — 접근형. 표적에 달라붙어 **접촉 흡수**로 HP를 빨며 **떼**로 몰려든다.
    주로 지상/워커를 상대.
- **공중 스폰** — 플레이어(들)의 무게중심 주변 근거리 밴드(반경 55~205 m)에, 아키타입별 고도 밴드로 투입.
- **자유 부유 + 3D 추적** — 지형/물체와 충돌하지 않고 자유롭게 떠다니며, 플레이어를 향해 상하 포함 3D로 추적.
- **흡수 공격(에너지 흡수)** — 빨아들인 만큼 **플레이어 HP를 깎고 그만큼 자기 체력을 회복/성장**한다.
  거머리는 접촉 사거리 3.2 m, 모기는 원거리 드레인 빔. 피해는 `PlasmoidSpec`에서 산출(머시 무적 중 무효).
- **처치 시 HP 환수(killRefund)** — 적을 잡으면 흡수당했던 물질을 회수해 플레이어 HP가 환수된다
  (사망 지점 최근접 플레이어가 받는다 → `PlayerController.heal`).
- **고도별 가중 제거** — 예전의 고도에 따른 적 속도/접촉 피해 가중은 더 이상 적용되지 않는다.
- **소멸** — 빔 누적 피격으로 HP 0 → 쪼그라들며 디졸브 셰이더로 사라짐.
- **멀티플레이 토대** — 플레이어가 여럿이면 각 적이 최근접 표적을 고르되 어그로 분산
  (이미 표적이 된 플레이어에 부하 가산)으로 한 명에게 몰리지 않게 분배한다. 아키타입 물량도
  전장 구성(워커 수↔거머리, 플라이어 수↔모기)에 비례해 자기정렬된다.
- **매칭 완화(워커 AA)** — 워커도 모기(카이터)를 일부(`KITER_CROSS_FRAC`) 끌어온다 → 솔로 워커도
  공중 원거리 적과 교전(워커는 장거리 빔으로 격추하는 만능형). 러셔(거머리)는 워커 전용 유지(플라이어=공중 특화).
  미스매치 폴백 `KITER_CLOSE_MUL=1.0`(워커가 장거리라 모기가 keepDist 좁힐 필요 없음 → 거리 유지).

### 웨이브 (`EnemyManager`)
- 웨이브마다 아키타입별 물량(거머리·모기)을 웨이브와 전장 구성에 비례해 산정(`archetypeCount`),
  두 예산을 잔여 비율로 섞어 0.35 s 간격으로 1마리씩 점진 스폰.
- 두 예산이 모두 소진되고 화면의 적이 모두 정화되면 다음(더 큰) 웨이브 — 무한 증식.

## 미션 / 게임 인스턴스

게임에 진입하면 **게임 인스턴스**가 생성되어 그 플레이타임의 **미션 · 시간 · 리스폰 · 건물/랜드마크/적
상태 · 종료 조건**을 한곳에서 관리한다(멀티플레이도 이 인스턴스가 팀 전체를 관장하도록 설계).
출격 시 미션 풀에서 하나를 **랜덤 배정**하며, **탐방 모드**는 목표 없는 자유 정찰이다.

- **격멸 / PURGE** — 5분 내 100기 처치. **목표 달성이 최우선**(마지막 프레임에 시간 초과여도 처치 완료면 성공). 리스폰 3회.
- **도시 방어 / HOLD THE CITY** — 5분간 건물 손실 10채 미만 유지. 시간 만료 = 성공. 건물 10채 파괴·리스폰 소진 = 실패. 리스폰 3회.
- **랜드마크 사수 / GUARD** — 5분간 랜드마크 파괴 0으로 사수. 시간 만료 = 성공. 랜드마크 1개라도 파괴·리스폰 소진 = 실패. 리스폰 3회.
- **지역 사수 / SURVIVE** — 5분간 최소 기체 손실로 버팀. 시간 만료 = 성공. 리스폰 소진 = 실패. 리스폰 2회.

공통: 시작 위치 반경 5km 작전구역 + 반경 1.5km 안에 100마리 일괄 스폰(체력 총합 7만, 중간보스 1기 1만). 수치는 `public/missions/index.json`.

기체가 파괴되면 **리스폰 예산**이 남는 한 스폰 지점에서 부활(1.5s 무적)해 전투를 잇고, 예산을 소진하면
미션 실패로 종료된다. 미션이 끝나면(성공/실패) 결과 패널이 뜨고, **다시/RETRY**는 같은 전장에 재출격한다.
수치/규칙·확장 지점은 [implements/08](../implements/08-game-instance-mission.md), 데이터는
[`public/missions/index.json`](../../public/missions/index.json).
