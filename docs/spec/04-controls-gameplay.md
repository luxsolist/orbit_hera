# 04 · 조작 & 게임플레이 규칙

## 조작 — 데스크톱

| 입력 | 보행 드론 | 비행 드론 |
| :--- | :--- | :--- |
| `W A S D` | 이동 | 시선결합 이동(전후좌우) |
| `MOUSE` | 조준(Pointer Lock) | 조준 — 시선이 비행 방향 결합 |
| `좌클릭` (hold) | 주파수 빔(자동발사 보조 수동 사격) | 동일 |
| `우클릭` | 특수 무기(다중 빔 살포) 발동 | 동일 |
| `SPACE` | 점프 | 상승(호버 추력) |
| `SHIFT` (좌/우) | 회피 대시 | 하강(호버 추력) |
| `C` | — | 하강 대체키 |
| `ESC` | 링크 해제(일시정지) | 동일 |

- **동시 입력 보장** — 입력은 키 집합(`Set`)으로 추적해 여러 키를 동시에 누를 수 있다. 락(플레이) 중에는 게임 키(`W A S D`·`Space`·`Shift`(좌/우)·`C`)의 브라우저 기본동작(Space 스크롤 등)을 막아 전후좌우 + 상승/하강 동시 입력이 데스크톱에서 안정적으로 들어간다.
- **하강 대체키 `C`** — 비행 하강은 `Shift`와 `C` 둘 다 받는다. 일부 키보드에서 `Shift`+`WASD` 동시 입력이 씹히는 키 고스팅(N-key rollover)을 피하기 위한 대안.

조작 안내는 드론 스펙의 `actions[].desc`에서 동적으로 생성되므로 드론마다 자동으로 달라진다.
드론별 자동발사 사거리·방향별 이동 속도는 [전투 규칙](#전투-규칙) 참조.

## 조작 — 모바일 (가로 모드 전용)

- **좌측 절반** — 가상 조이스틱(터치 지점에 표시). 변위 크기에 비례해 이동 속도 단계화,
  데드존 밖 축만 8방향 키로 합성.
- **우측 절반** — 시선(드래그) + 우하단 4버튼 클러스터:
  ```
  [ FIRE ]  [ ACT1 ]      좌상=기본무기  우상=ACT1
  [  SP  ]  [ ACT2 ]      좌하=특수무기  우하=ACT2(엄지 홈)
  ```
  FIRE/SP 라벨은 무기 스펙 `abbr`에서, ACT1/ACT2는 드론 스펙 `actions`에서 채워진다.
  (보행: ACT1=점프 ACT2=대시 · 비행: ACT1=상승 ACT2=하강)
- 세로 모드에서는 "가로로 돌려 주세요" 안내가 뜨고 입력이 차단된다.

상세 구현은 [implements/02](../implements/02-input-and-player.md#모바일-컨트롤).

## 게임 흐름 (상태)

```
intro(인트로 컷씬) ─▶ menu(전장 선택) ─▶ loading ─▶ playing ⇄ paused(ESC)
                          ▲                              │
                          └──────────────(LINK LOST)◀── dead (HP 0)
```

- **menu** — 세계지도에서 침공 지점(점) 클릭 → 지역 팝업에서 **드론 선택 → 즉시 출격**.
  배경에는 랜덤 인트로 장면이 페이드 전환되며 재생. "스토리" 버튼으로 인트로 컷씬 재생.
- **playing** — Pointer Lock 상태에서만 시뮬레이션 진행(락 풀리면 자동 일시정지).
- **dead** — HP 0 → "LINK LOST" + 정화 수/웨이브 표시 → 재시작.

## 전투 규칙

### 사격 — 자동발사 + 수동 조준 보조
- **360° 소프트 락 자동발사** — 좌클릭 유지 없이도 자동발사 사거리(`auto.range`) 안의 적을 향해 빔이 나간다.
  보행(중주파 빔)은 근거리 **45 m**, 비행(경주파 빔)은 원거리 **120 m**로 드론 정체성을 가른다.
- **수동 조준 보조(에임 어시스트)** — 좌클릭 사격 시 크로스헤어 주변 콘(`manual.assistConeDeg`,
  중주파 20° / 경주파 33°) 안의 적으로 빔이 살짝 끌려간다. 수동 사격은 자동발사보다 데미지가 높다.
- **거리 감쇠** — 빔 데미지는 기준 거리(`falloff.refDist`)를 기준으로 가까울수록 증폭, 멀수록 감소.
  경주파 빔은 원거리 데미지 유지율이 높아(`minMult` 0.75) 카이팅 사격에 적합.

### 방향별 이동 속도
- 시선 기준 이동 방향에 따라 속도 배수 적용(`dirSpeedMult`): **전진 1.0 / 옆걸음(스트레이프) 0.85 / 후진 0.6**.
  보행·비행 모두 동일 적용. 무한 후진 백페달 카이팅을 억제한다.

### 드론 정체성 (영역 트레이드오프)
- **보행 드론(WALKER)** — 지상 근접 난투형. 내구성↑(HP 120), 근거리 고화력(중주파 빔, 짧은 자동락 45 m),
  회피 대시 보유. 후진 페널티로 물러서며 싸우기 불리 → 파고들어 싸우는 기체.
- **비행 드론(FLYER)** — 공중 카이팅형. 고속(속도 111.11 ≒ 400 km/h)·취약(HP 60), 원거리 화력 유지(경주파 빔,
  긴 자동락 120 m). 비행 하한 고도(`minAltitude` 18 m)에 묶여 지상 안전지대로 내려갈 수 없고,
  높을수록 플라즈모이드가 더 빨라지는 고도 구간에서 싸운다.

### 자원
- **체력(HP)** — 적 접촉(에너지 흡수)으로 감소. 피격 시 0.6 s 머시 무적(이 동안의 추가 접촉은 피해·적 회복
  모두 무효). 0이면 사망.
- **주파수(Frequency)** — 빔/특수무기 발사 자원. 초당 자동 회복(드론별 `freqRegen`).
  특수무기 발동 중에는 회복 억제.

### 적 — 플라즈모이드 (`SeedEnemy`)
- **공중 스폰** — 플레이어 주변 근거리 밴드(반경 55~205 m)에 지면 대비 **0~300 m 랜덤 고도**로 투입.
  지수 가중(`u^2.5`)으로 **지상에 가까울수록 빈도↑**.
- **자유 부유 + 3D 추적** — 지형/물체와 충돌하지 않고 자유롭게 떠다니며, 플레이어를 향해
  상하 포함 3D로 다가온다(지표면 지향성 없음).
- **접촉 공격(에너지 흡수)** — 사거리 3.2 m(`ATTACK_RANGE`) 안에서 개체별 1초 쿨다운으로 발동.
  플라즈모이드가 에너지를 빨아들여 **플레이어 HP를 깎고 그만큼 자기 체력을 회복**(흡수량 = 피해 = 회복).
  피해는 고정값이 아니라 `PlasmoidSpec.contact`에서 산출 — **강함(s)에 비례**해 커지고
  (`hpDamage` 9 기준 ×(1+`strengthMul` 2.0·s)), **고도가 높을수록 약해진다**
  (`altWeakRef` 250 m에서 `altWeakMin` 0.3까지 감쇠) → 저공 접촉은 묵직, 고공 공중전은 접촉당 타격이 가볍다.
  적용된 타격에는 증기·기화음("치익") 효과음이 난다(머시 무적 중 접촉은 무효).
- **고도에 따른 속도** — 지면 대비 고도가 높을수록 더 빨라진다(`altitudeSpeedMult`: airRef 220 m까지 최대 +4.52배),
  지면 아래/저고도일수록 느려진다(depthSlowMax 0.6). 높이 나는 비행 드론은 더 빠른 적을 상대하게 된다.
- **소멸** — 빔 누적 피격으로 HP 0 → 쪼그라들며 디졸브 셰이더로 사라짐.

### 웨이브 (`EnemyManager`)
- 웨이브마다 `4 + wave×2`기를 0.35 s 간격으로 점진 스폰.
- 적 속도는 웨이브에 비례 증가(`4.5 + wave×0.4 + rand`).
- 화면의 적이 모두 정화되면 다음(더 큰) 웨이브 — 무한 증식.
