## 차원 해석 — 무기는 무엇을 하는가

세계관 물리는 [05-dimensional-cosmology.md](05-dimensional-cosmology.md)(정본) 참조. 무기 체계의 요지:

- **주파수 빔 = 공명 결어긋남 유도장.** 물리 탄이 아니라, 표적 플라즈모이드(6차원 본체의 3차원 투영)의
  KK 고유 진동수에 공명하는 주파수를 조사해 **결맞음을 강제로 무너뜨리는** 장 무기. 히트스캔인 이유 —
  발사관–표적 사이에 위상 정합 유도장을 세우는 것이라 정합 즉시 작용한다.
- **데미지 = 결어긋남 유도율, 적 HP = 투영의 결맞음 저장량**(본체가 그 투영에 걸어둔 결합 깊이).
  HP 0 → 투영이 막에서 뜯겨나가는 **디졸브**(모드 소산).
- **주파수 게이지 = 드론 공진기의 결맞음 예산.** 자연 회복 = 재결맞음. 특수무기 발동 중 회복 억제 = 공진기 포화.
- **거리 감쇠(falloff) = 유도장의 기하 확산.** 중주파(장파장·저모드 결합)는 회절로 멀리 가고 완만하게
  감쇠, 경주파(단파장·고모드 결합)는 근접 결합이 강한 대신 급감 — heavy/light의 사거리 정체성이 물리에서 나온다.
- **오토파이어 360° 소프트락 = 위상 자동 정합.** 공진기가 근접 투영의 장 왜곡을 전방위로 감지해 자동
  정합한다(정면을 안 봐도 발사). **에임 어시스트 콘 = 위상 정합 허용 오차.**
- **듀얼 발사관(경주파) = 2채널 간섭 정합**, **살포(barrage) = 위상배열(phased array) 다중 로브**,
  **오버드라이브 = 유도 방출 연쇄(레이징)** — 게이지가 바닥날 때까지 공진기를 폭주시키는 모드.
- **빔이 건물에 가로막히는 이유**(관통 차단): 유도장은 우리 막(3-공간) 표면을 따라 세워져 시선이 필요하다.
  적은 벌크로 우회(벽 "통과")하지만 우리는 벽 너머를 쏠 수 없다 — 이 **비대칭이 전술의 근원**.
- 🔭 예정 — **워커 수동 중주파 빔 = 관측 펄스**(위상 이탈 개체 강제 실체화, [05 §2.2](05-dimensional-cosmology.md)),
  **결맞음 보강간섭**(연사 특수의 동일 표적 연속 명중 데미지 증가, [05 §2.6](05-dimensional-cosmology.md)).

> ⚠️ **무기 체계 재정립 예고**: 위 해석은 그대로 유효하되(결어긋남 유도 = 관측), 정본 확장은
> **관측 병기**([서사편 §7](../private/05x-narrative-truth.md) ⚠️스포일러)로 결정됐다 — 제논 고정
> (빔 유지 = 시전 인터럽트), 참조 핀(위상 봉쇄), 대역 정합(색 상성), 복구 사격(아군/건물 정화),
> 실패 각인 게이지. "죽이는 무기 → 붙들고·고정하고·되찾는 무기"로 무게중심 이동. 아래 수치
> 명세는 구현 교체 전까지의 현행 사양.

## 드론 로스터

### `walker` — 보행 드론 / WALKER (`ANDROID-01`)
지상 시가전 기체. 운동량 기반 이동 + 점프 + 회피 대시.

| 항목 | 값 |
| :--- | :--- |
| 시점 높이 / 반경 | 2.2 m / 1.2 m |
| HP / 주파수 / 회복 | 120 / 120 / 28 per s |
| 시야각 / 감도 | 80° / 0.0022 |
| 수평 속도 | 19.44 m/s (지상 가속 28, 공중 8) |
| 점프 | 초속 28, 상승중력 55, 하강중력 50, 종단 25.5, 최대상승 100 m, 코요테 0.1 s |
| 대시 | 속도 192, 지속 0.16 s, 쿨다운 2.0 s |
| 동작 버튼 | JUMP `Space`=점프 · DASH `ShiftLeft`=대시 |

점프는 **상승 시 감속 → 하강 시 가속 → 종단속도 유지** 모델(2단 점프 아님). `maxRiseHeight`는
디딘 지면 대비 소프트 게이트(초과 시 추가 점프 금지, 강제 위치 보정 없음).

### `flyer` — 비행 드론 / FLYER (`DRONE-V1`)
공중 기동 기체. 무중력 호버 + 시선결합 비행 + 뱅킹 롤. **대시 없음**(`dash` 미정의).

| 항목 | 값 |
| :--- | :--- |
| 시점 높이 / 반경 | 2.0 m / 1.0 m |
| HP / 주파수 / 회복 | 60 / 90 / 16 per s |
| 시야각 / 감도 | 88° / 0.0024 |
| 수평 속도 | 111.11 m/s (가속 9) |
| 수직 속도 | 45 m/s (상승/하강) |
| 천장 / 스폰 고도 | 지면 대비 1,000 m / 100 m |
| 비행 하한 고도 | 지면 대비 18 m (`minAltitude` — 지상 안전지대 차단) |
| 롤(뱅킹) | 좌우 이동 시 최대 16° |
| 동작 버튼 | ▲ `Space`=상승 · ▼ `ShiftLeft`=하강 |

비행 이동은 **시선 방향 결합**: 위를 보고 전진 → 상승, 아래를 보고 전진 → 하강. 추가로 Space/Shift로
순수 수직 추력(호버 상승/하강). 좌우 스트레이프 시 카메라가 뱅킹.

무장은 드론별로 다르다:
- **walker**: `primary = frequency-beam-heavy`, `special = special-barrage`.
- **flyer**: `primary = frequency-beam-light`(듀얼 발사관), `special = special-overdrive`.

## 무기

### `frequency-beam-heavy` — 중주파 빔 (walker 기본, 히트스캔)
단발(단일 발사관). **장거리 + 완만한 거리감쇠** — 지상 고정포대(AA)형: 공중 원거리 적(모기)도 격추.
*(차원 해석: 낮은 KK 모드에 결합하는 장파장 유도장 — 회절로 멀리 가고 완만히 감쇠. 수동 사격은 고에너지 집중 = "관측 장치급" 조사로, 위상 이탈 개체 강제 실체화(🔭예정)의 예약 채널.)*

| 모드 | 데미지 | 주파수 비용 | 발사간격 | 사거리 |
| :--- | :--- | :--- | :--- | :--- |
| **오토파이어** (360° 소프트락) | 45 | 4 | 0.2 s | 1000 m |
| **수동** (좌클릭, 에임 어시스트) | 150 | 14 | 0.15 s | 2000 m (어시스트 콘 13°) |

- 빔 잔상 0.1 s, 색 `0x60ffff`. `falloff`: `refDist 1000`, `maxMult 1.5`, `minMult 0.3`(3 km 사거리 재편 기준).
- **완만 falloff 의도**: 장거리에서도 유효 타격 유지 — 지상 고정포대(AA)로서 공중 원거리 적까지 격추. 근접 피크는 낮춰 사거리 이득을 지불.
- **락온 `followDist 60 / band 12`**(유지 48–72 m): 정지거리(speed/groundAccel ≈ 19.4/28 ≈ 0.7 m)가 0에 가까워 밴드는 오버슈트가 아닌 슬랙. AA답게 뒤에서 버팀.
- **관측 고정(W1)** `zeno { slowPerSec 0.4, freezeAfter 1.2 }` — 하드 고정: 같은 대상 지속 조사 1.2 s 에 동결(붙드는 무기 — 앵커 정체성).

### `frequency-beam-light` — 경주파 빔 (flyer 기본, 히트스캔)
**듀얼 발사관**(`muzzleOffsets [-0.55, 0.55]`) — 데미지는 발사관당 적용(콘 안 1발 = 좌우 2발). 가볍고 빠른 연사.
*(차원 해석: 높은 KK 모드에 결합하는 단파장 유도장 — 근접 결합이 강한 대신 급감. 듀얼 발사관 = 2채널 간섭 정합.)*

| 모드 | 데미지(발사관당) | 주파수 비용 | 발사간격 | 사거리 |
| :--- | :--- | :--- | :--- | :--- |
| **오토파이어** (360° 소프트락) | 15 | 2 | 0.13 s | 1000 m |
| **수동** (좌클릭, 에임 어시스트) | 39 | 7 | 0.085 s | 2000 m (어시스트 콘 28°) |

- 빔 잔상 0.08 s, 색 `0x90ffff`. `falloff`: `refDist 1000`, `maxMult 4.0`, `minMult 0.1`(3 km 사거리 재편 기준).
- **급감 falloff 의도**: 근접 폭딜(maxMult 4.0), 원거리 급감(minMult 0.1) → 빠른 기동(속도 111 / 수직 45)으로 파고드는 접근전 전용. 글래스캐논(HP 60).
- 락온 `followDist 24 / band 12`(유지 12–36 m — 정지거리 v/accel ≈ 12 m 흡수). 피크는 수동 다이브로 획득.
- **관측 고정(W1)** `zeno { slowPerSec 0.3, freezeAfter 2.0 }` — 소프트 고정: 연사 갱신형(추적자 정체성).

**공통 발사 모델**: 오토와 수동은 **독립 쿨다운**으로 같은 프레임에 동시 발사된다.
- **오토파이어**: `auto.range`(공통 **1000 m**) 안 **360° 최근접 적** 중 **건물에 가리지 않은** 개체를 자동
  소프트락(정면을 안 봐도 추격자 타격, 허공 발사 방지).
- **수동**: 좌클릭 시 어시스트 콘(`manual.assistConeDeg`) 안 가장 정렬된 적으로 조준 보정 후 풀데미지.
- **관측 고정(zeno, W1)**: 명중이 그레이스(0.5 s) 이내로 이어지면 대상의 "피관측 노출"이 누적 —
  노출에 비례해 감속하다 `freezeAfter` 에서 **동결**(이동·공격·낙인 장전 전부 정지). 관측이 끊기면
  2배속 감쇠로 풀린다. 수동·오토 공통 적용, 무기별 값은 위 표(정본: [서사편 §7 W1] ⚠️).
- **모바일 보정**: 모바일 출격 시 기본 빔의 `assistConeDeg` **×2**(워커 13°→26°, 플라이어 28°→56°) —
  터치 조준 난도 완화. 자동사격 사거리는 데스크탑과 동일(×1). 데스크탑은 무영향.

## 데미지 모델

빔 데미지는 거리에 따라 보정된다 ([`damageForDistance`](../../src/weapons/WeaponSpec.ts)):

```
mult = clamp(refDist / dist, minMult, maxMult)
최종 데미지 = baseDamage × mult
```

기준 `refDist`에서 1.0배, 근접일수록 `maxMult`까지 강해지고, 원거리는 `minMult`로 수렴한다.
특수무기(barrage/overdrive)의 falloff는 일반 빔보다 완만(`refDist 40`, `maxMult 1.8`, `minMult 0.75`).

적은 `applyFrequencyHit(damage)`로 HP가 깎이고, 0 이하가 되면 **디졸브 소멸**(쪼그라들며 사라짐).

## 조준(타깃 선별) 로직

무기들이 공유하는 순수 콘 조준은 [`src/weapons/targeting.ts`](../../src/weapons/targeting.ts):
- `coneTargets` — 공통 코어. 콘+사거리 안 후보 수집(등 뒤 cos ≤ 0·동일점·사거리 밖·콘 밖 제외).
- `bestAlignedDir` — 콘 안 **가장 정렬된 단일 타깃** (에임 어시스트·오버드라이브 조준).
- `nearestInCone` — 콘 안 **거리순 N개**. 살포(최대 N), 오토파이어(콘 cos −1로 360° 최근접 1개)에 사용. `index`로 `aliveEnemies` 역참조.
- 입력은 `EnemyManager.aliveWorldPositions`(평문 좌표, `aliveEnemies`와 인덱스 정합). 빔 명중 레이캐스트는 **셸 InstancedMesh**(`hitMeshes`)→`instanceId`→`enemyFromHit`로 적 역참조.

값 변경은 JSON만 고치면 되고, 조준 기하는 [`tests/targeting.test.ts`](../../tests/targeting.test.ts)가 가드한다.
