# 02 · 드론 & 무기 (현행 로스터 + 전투 수치)

스키마는 [01-data-schemas.md](01-data-schemas.md). 이 문서는 **현재 배치된 실제 값**과 전투 모델을
정리한다. 값 출처는 `public/drones/*.json`, `public/weapons/*.json`.

## 드론 로스터

### `walker` — 보행 드론 / WALKER (`ANDROID-01`)
지상 시가전 기체. 운동량 기반 이동 + 점프 + 회피 대시.

| 항목 | 값 |
| :--- | :--- |
| 시점 높이 / 반경 | 2.2 m / 1.2 m |
| HP / 주파수 / 회복 | 100 / 100 / 22 per s |
| 시야각 / 감도 | 80° / 0.0022 |
| 수평 속도 | 16.7 m/s (지상 가속 28, 공중 8) |
| 점프 | 초속 28, 상승중력 55, 하강중력 50, 종단 25.5, 최대상승 100 m, 코요테 0.1 s |
| 대시 | 속도 192, 지속 0.16 s, 쿨다운 2.0 s |
| 동작 버튼 | ▶ ACT1 `Space`=점프 · ACT2 `ShiftLeft`=대시 |

점프는 **상승 시 감속 → 하강 시 가속 → 종단속도 유지** 모델(2단 점프 아님). `maxRiseHeight`는
디딘 지면 대비 소프트 게이트(초과 시 추가 점프 금지, 강제 위치 보정 없음).

### `flyer` — 비행 드론 / FLYER (`DRONE-V1`)
공중 기동 기체. 무중력 호버 + 시선결합 비행 + 뱅킹 롤. **대시 없음**(`dash` 미정의).

| 항목 | 값 |
| :--- | :--- |
| 시점 높이 / 반경 | 2.0 m / 1.0 m |
| HP / 주파수 / 회복 | 70 / 120 / 26 per s |
| 시야각 / 감도 | 88° / 0.0024 |
| 수평 속도 | 83.3 m/s (가속 9) |
| 수직 속도 | 26 m/s (상승/하강) |
| 천장 / 스폰 고도 | 지면 대비 140 m / 100 m |
| 롤(뱅킹) | 좌우 이동 시 최대 16° |
| 동작 버튼 | ▲ ACT1 `Space`=상승 · ▼ ACT2 `ShiftLeft`=하강 |

비행 이동은 **시선 방향 결합**: 위를 보고 전진 → 상승, 아래를 보고 전진 → 하강. 추가로 Space/Shift로
순수 수직 추력(호버 상승/하강). 좌우 스트레이프 시 카메라가 뱅킹.

두 드론 모두 동일 무장: `primary = frequency-beam`, `special = special-barrage`.

## 무기

### `frequency-beam` — 주파수 빔 (기본, 히트스캔)
| 모드 | 데미지 | 주파수 비용 | 발사간격 | 사거리 | 콘 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **자동발사** (근거리 자동) | 14 | 3 | 0.16 s | 80 m | 18° |
| **수동** (좌클릭, 에임 어시스트) | 38 | 11 | 0.11 s | 400 m | 어시스트 20° |

- 사거리 400 m, 빔 잔상 0.09 s, 색 `0x60ffff`.
- **자동발사 우선**: 매 프레임 자동발사 콘+사거리(80 m/18°) 안에 적이 있으면 저비용 연사로 자동 사격.
  없을 때 좌클릭하면 수동(고데미지) 발사 — 어시스트 콘(20°) 안 가장 정렬된 적으로 조준 보정.

### `special-barrage` — 다중 빔 살포 (특수)
우클릭 1회 발동 → 전방 콘(55°)·사거리 220 m 안 적 **최대 10기**에 빔을 동시 연속 살포.

| 항목 | 값 |
| :--- | :--- |
| 동시 타깃 | 10 |
| 살포 간격 / 빔당 데미지 | 0.12 s / 16 |
| 발동 중 소모 | 60 주파수/s (게이지 0이 되면 자동 종료) |
| 쿨다운 | 60 s (발동 순간부터) |
| 색 | 빔 `0xffb648`, 글로우 `0xffd58a` |

발동 동안 자연 주파수 회복은 억제. HUD/모바일에 쿨다운 진행률·잔여초 표시.

## 데미지 모델

기본 빔 수동 데미지는 거리에 따라 보정된다 ([`damageForDistance`](../../src/weapons/WeaponSpec.ts)):

```
mult = clamp(refDist / dist, minMult, maxMult)
최종 데미지 = baseDamage × mult
```

`frequency-beam.falloff`: `refDist 26`, `maxMult 2.5`, `minMult 0.5`.
→ 기준 26 m에서 1.0배, 근접일수록 최대 2.5배, 원거리는 0.5배로 수렴.

적은 `applyFrequencyHit(damage)`로 HP가 깎이고, 0 이하가 되면 **디졸브 소멸**(쪼그라들며 사라짐).

## 조준(타깃 선별) 로직

세 경로가 공유하는 순수 콘 조준은 [`src/weapons/targeting.ts`](../../src/weapons/targeting.ts):
- `bestAlignedDir` — 콘 안 **가장 정렬된 단일 타깃** (에임 어시스트·자동발사)
- `nearestInCone` — 콘 안 **거리순 N개** (일제사격)
- 공통 필터: 등 뒤(cos ≤ 0)·사거리 밖·콘 밖 제외.

값 변경은 JSON만 고치면 되고, 조준 기하는 [`tests/targeting.test.ts`](../../tests/targeting.test.ts)가 가드한다.
