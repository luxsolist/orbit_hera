# 인트로: 우리가 살던 곳을 지키기 위해

2026-09-10 개정. 75초 실시간 Three.js 시네마틱. 사전 지식이 없는 어린이도 **무슨 일이 일어났는지, 왜 로봇을 쓰는지, 내가 무엇을 해야 하는지** 이해하도록 구성한다.

## 이야기

사람들이 살던 평범한 동네에 낯선 빛들이 나타났다. 그 빛들은 건물에서 에너지를 빨아들였고, 단단하던 벽이 약해져 무너졌다. 다른 도시에서도 같은 일이 일어나 사람들은 집을 떠나 피해야 했다.

빛 가까이에 가면 사람의 몸도 제대로 움직이지 않았다. 그래서 사람 대신 로봇을 보내기로 했다. 플레이어는 안전한 조종실에서 로봇을 움직인다. 로봇의 눈으로 현장을 보고, 무기의 빔을 빛에 계속 맞추면 움직임을 멈추게 할 수 있다.

첫 번째 빛을 막는 데 성공한다. 하지만 도시에는 아직 다른 빛들이 남아 있다. 이제 로봇을 움직여 남은 동네를 지키는 것이 플레이어의 임무다.

## 영상과 설명의 순서

| 시간 | 보여주는 것 | 알려주는 것 |
| --- | --- | --- |
| 0–9초 | 평범한 골목 → 낯선 빛이 집 앞으로 다가옴 | 이곳은 사람이 살던 동네. 어느 날 빛이 나타남 |
| 9–18초 | 빛이 커지고 집의 창살·벽이 약해져 무너짐 | 건물의 에너지를 빼앗아 무너뜨림 |
| 18–28초 | 다른 도시와 항만의 빛들 | 같은 일이 퍼졌고 사람들이 피해야 했음 |
| 28–36초 | 출입을 막은 거리 → 로봇이 그쪽으로 들어감 | 사람은 가까이 가면 몸을 제대로 움직이지 못함. 로봇을 대신 보냄 |
| 36–46초 | 조종실의 손·조종 장치 → 로봇의 눈 | 플레이어는 안전한 곳에서 이 로봇을 조종함 |
| 46–62초 | 빔 발사 → 정지 → 빗나감 → 재조준 → 소산 | 안내자가 화면의 행동을 짧고 쉬운 말로 설명함 |
| 62–71초 | 손상된 동네, 남은 빛, 아직 켜진 등불 | 아직 위험이 남음. 로봇을 움직여 동네를 지키는 것이 임무 |
| 71–75초 | CORE | 우리가 살던 곳을 지키기 위해 |

자막 원문과 표시 시간은 `src/intro/sequence.ts`가 단일 출처다. 한 번에 한 문장씩, 약 3–5초 동안 표시한다. 움직임이 멈추거나 다시 움직이는 순간에 해당 설명을 맞춘다. 모바일에서는 큰 글씨, 줄바꿈과 어두운 자막 배경을 사용한다.

## 복선과 용어

공통 박동, 직접 맞지 않은 개체의 순간 경직, 같은 방향으로 흐르는 잔류 입자는 시각적 복선으로 남긴다. 인트로에서 이 현상을 해석하거나 수수께끼 대사로 강조하지 않는다.

우주·심해 기록은 이번 인트로에서 제거한다. 기원 설명보다 현재의 위험과 플레이어 역할을 먼저 이해시키기 위해서다. '재구성 신호 열화', '광역 관측망', '원격 기체 응답', '링크 안정'은 쉬운 한국어로 바꾼다. '로봇'은 세계관의 원격 무인 기체를 설명하는 쉬운 표현이다. 뇌와 신경계의 문제는 '몸을 제대로 움직일 수 없다'로 설명하고, 빛의 정체와 캠페인의 반전은 공개하지 않는다.

## 구현

- `scenes.ts`: 8개 컷과 독립적인 메뉴 배경. `safety` 컷으로 로봇 투입의 이유를 보여준다. 붕괴 흔적은 후속 컷에도 이어진다.
- 로봇은 [ANDROID-01 공용 메카 에셋](08-walker-asset.md)을 사용한다. 안전 구역 컷에 관절 보행을 적용하고, 접속 컷에서 장갑과 센서를 보여준다.
- `cinematicAssets.ts`: 절차적 PBR 표면, 반사광, 그림자·안개. 인트로는 기존 무텍스처 규칙의 예외다. 본편 전장 렌더링은 별도다.
- `CinematicPlayer.ts`: 전용 씬·환경 반사·낮춘 블룸, 전환·리사이즈·자원 해제.
- `sequence.ts` / `CinematicOverlay.ts` / `cinematic.css`: 쉬운 자막, 한국어 로봇 연결 표시, 타이틀.
- `CinematicAudio.ts`: 배경음, 박동·신호음. 대사는 자막이며 녹음 음성은 없다.
- 자연 종료 후 2초 페이드. Esc 즉시 종료, 클릭은 0.45초 페이드 후 메뉴 복귀.

외부 영상 파일이 아닌 브라우저 실시간 3D 구현이다.
