## 0. 용어 사전 (게임 문서에서 쓰는 물리 개념)

| 용어 | 물리 개념 | 게임에서의 의미 |
| :--- | :--- | :--- |
| **막(brane)** | 고차원 벌크에 떠 있는 저차원 초곡면. 우리 우주 = 3-brane | 게임의 "현실 공간" — 드론과 인류가 사는 곳 |
| **벌크(bulk)** | 막을 담는 고차원 공간. 표준모형 입자는 막에 속박, 중력만 벌크 전파 | 플라즈모이드 본체가 사는 곳. 드론 무기가 닿지 않는 영역 |
| **KK 모드(Kaluza-Klein)** | 여분 차원 진동의 이산 준위. 높은 준위 = 높은 에너지 | 플라즈모이드의 색(적→청백)과 강함의 근원 |
| **결맞음/결어긋남** | 양자 중첩의 유지/붕괴. 결어긋남을 일으키는 것 = 관측 | 플라즈모이드의 "실체" 상태. 빔 무기의 원리(§1.6) |
| **영점 에너지** | 진공·물질의 바닥상태 에너지 | 플라즈모이드가 흡수하는 것. 빼앗기면 물질이 바스라짐 |
| **자발적 대칭 깨짐** | 장(場)이 바닥상태를 골라 입자에 성질을 부여 | 씨앗 장이 플라즈모이드에 "실체"를 부여하는 방식 |
| **카시미르 효과** | 좁은 경계 사이에서 진공 모드가 억제됨 | 좁은 지형에서 플라즈모이드가 약화되는 근거 |
| **중력자 누설** | 브레인월드에서 중력만 막에 속박되지 않고 벌크로 전파 | 벌크에 숨어도 중력 서명은 못 감춤. 인류가 벌크를 엿보는 유일한 창 |
| **벌크 지름길** | 벌크 경유 경로가 막 위보다 짧아 중력 신호가 빛보다 먼저 도착 | 조기 경보·침공 전조 탐지의 근거 |
| **중력 시간 지연** | 에너지 밀도가 높은 곳은 고유시간이 느림 | 보스 오라·씨앗 장 밀집 지대의 슬로우 필드 |
| **브레인 파문** | 막 자체의 진동 = 중력파 | 보스 광역 충격파. 침공 지점을 정하는 간섭 무늬의 매질 |

## 1. 세계관 재해석

### 1.1 코어 = 막(brane)의 균열

우리 우주는 벌크 속에 떠 있는 3차원 막이다. **아무것도 떨어지지 않았다** — 오무아무아는 물체가
아니라 태양계를 훑고 지나간 **본체의 탐침이 드리운 3차원 투영**이었고(밀도 높은 세계를 물색하는
정찰), 그 뒤 마리아나해구 최심부에서 **막이 바깥에서 뚫렸다**. 코어 = 그렇게 열린 **막의
상처(brane rupture)** 다.

- 최초 균열은 바늘구멍(~10cm)으로 열려 지름 100km로 자랐다([overview §3.1](overview.md)) —
  생물의 성장이 아니라 **균열의 확장**: 흡수한 영점 에너지가 막의 장력을 국소적으로 무너뜨려
  구멍을 넓힌다. 우리가 재는 크기는 전부 **3차원 투영 치수**일 뿐이다.
- 표적이 밀도 높은 행성(지구)·최심부(마리아나)인 이유: 균열을 여는 연료가 **물질의 영점
  에너지**이기 때문 — 탐침이 스캔한 최적의 수확처. overview §3의 "흡수와 성장" 동기는 이
  물리의 3차원 관측자 서술이다.
- **최종전 = 봉합전**: 투영(플라즈모이드)을 아무리 끊어도 본체는 벌크에 남는다(무한 웨이브).
  종착점은 본체가 막을 통과하는 지점 — **코어(균열) 봉합** 전투다. (이 목표는 서사 후반에 두 번
  재정의된다 — [서사편 §1.10](../private/05x-narrative-truth.md) ⚠️.)

### 1.2 플라즈모이드 = 6차원 존재의 3차원 투영

플라즈모이드는 개별 생물이 아니라, 코어(균열)를 통해 **단 하나의 6차원 생명체가 우리 막에
드리우는 3차원 투영들**이다 — 하나의 손이 벽에 여러 개의 분리된 그림자 조각을 드리우듯, 손가락
사이가 벌어진 존재의 투영은 우리에게 별개의 개체들로 보인다(플랫랜드 비유의 투영판).

> **차원수 표기(정본)**: 인류 관측이 추정한 본체의 차원수 = **6차원**(우리 3-공간 + 여분
> 3차원). 단, 이것은 처음부터 아는 사실이 아니라 **인식 단계 Ⅱ(1막 초중반 계시)에서 확립되는
> 공식 서술**이다 — 캠페인 개시 시점의 공식 인식은 "에너지·파동 개체군"(단계 Ⅰ). 후반부에
> 본체가 **시간축으로도 연장**되어 있음이 드러난다(§1.9·§2.8). 계시 단계의 전체 설계와 그
> 이후의 최종 재독은 [서사편 §1.10](../private/05x-narrative-truth.md) ⚠️.

이 한 문장이 구현된 "이상한 성질" 전부를 정당화한다:

| 관측되는 성질 (구현됨) | 차원 해석 | 코드 근거 |
| :--- | :--- | :--- |
| 완전한 구체 형태 | 6차원 물체(초구 꼴)의 3차원 투영은 구형에 가깝다 | `CoreEnemy` 셸/코어 구체 |
| 지형·건물 무충돌 자유 부유 | 투영은 3-공간 물체가 아니다(막 물질과 약결합 — 그림자는 벽을 밀지 못한다) | [05-enemies](../implements/05-enemies.md) |
| 벽·지면·물 "통과" | 통과가 아니라 **투영을 거두었다가 다른 지점에 다시 드리우는 것** | overview §3 |
| 상하 자유 3D 추적 | 본체가 벌크에서 투영 위치를 재배치 — 3차원 관성이 없다 | `updateMotion`/`kiterVelocity` |
| 무한 웨이브 | 투영 절단 ≠ 본체 타격 | `EnemyManager` |
| 미세 상하 흔들림(bob) | 막-벌크 결합면의 장 요동 | `BOB_AMPLITUDE` |
| 동료 간 분리(separation) | 같은 본체의 투영끼리 융합하지 않도록 결합 위상을 밀어냄 | `separationVector` |

### 1.3 색온도 = Kaluza-Klein 준위

붉은색/푸른색은 항성 비유를 넘어 **여분 차원 진동 모드(KK 모드)의 준위**다. ✅

- 푸른 개체 = 높은 준위로 "울리는" 투영. 준위↑ = 투영의 에너지↑ — 현행 온도(T) 단일 노브
  (색·체력·크기·희귀도, [PlasmoidSpec](../../src/enemies/PlasmoidSpec.ts))는 **KK 준위의 3차원
  관측 서명**이다.
- 고준위가 드문 것(`tempAlpha` 희귀도) = 높은 준위 유지 비용(볼츠만 분포 꼴). 고준위가 **느린**
  것 = 결합 에너지가 클수록 막과의 상호작용 창(결합 면적)이 커져 재배치가 무겁다("질량을 얻는다").
- 발광(블룸)·드레인 빔 색 = **준위 간 전이의 방출 복사**. 무기 거리 감쇠([02](02-drones-weapons.md#데미지-모델))는
  이 복사의 기하 확산.

### 1.4 씨앗 장(場, Seed Field)

플라즈모이드는 맵 전체에 퍼진 **씨앗 장의 국소 들뜸(quantum)** 이다(입자 = 장의 들뜸이라는
QFT 문법 그대로). 장이 강한 곳에서 스폰·위상 이탈이 자유롭고, 약한 곳에서는 **실체화가
강제**된다(자발적 대칭 깨짐 — 장이 "실체"를 부여). 현행 아키타입 스폰 고도 밴드는 장 들뜸의
**등위면** 근사다. ✅ 인트로의 집 붕괴 = 영점 에너지를 흡수당한 물질이 결합을 잃고 주저앉는
것(§3).

### 1.5 드론 · 링크 = 얽힘 업링크

- **왜 무인인가**: 씨앗 장 요동이 생체 신경계·정밀 전자계의 결맞음을 무너뜨린다 — 유인 병기는
  조종 불능. 드론 = 요동에 강한 강체 공진기 + 원격 조종.
- **링크** = 양자 얽힘 채널 업링크. **Link Swap** = 채널 재배정. 리스폰 1.5s 무적 = 새 기체와의
  **재결맞음 정착 시간**. ✅
- 피격 0.6s 머시 무적 = 외피가 전개하는 **국소 카시미르 차폐**(차폐 중 흡수가 피해·적 회복
  모두 무효인 이유). ✅

### 1.6 주파수 빔 = 공명 결어긋남 유도

주파수 빔은 탄환이 아니라, 표적 투영의 **KK 고유 진동수에 공명시켜 결맞음을 무너뜨리는(유도
결어긋남) 장 무기**다. ✅

- **히트스캔**: 발사관–표적 사이 위상 정합 유도장 — 정합 즉시 작용.
- **데미지 = 결어긋남 유도율, 적 HP = 투영의 결맞음 저장량**(결합 깊이). HP 0 → **디졸브**
  (투영이 막에서 뜯겨 모드 소산). **주파수 게이지 = 공진기의 결맞음 예산**(회복 = 재결맞음,
  특수 발동 중 억제 = 포화).
- **빔은 건물에 막히고 적은 벽을 넘는 비대칭**: 유도장은 막 표면을 따라 서므로 3차원 시선이
  필요하지만, 플라즈모이드는 벌크로 우회한다 — 전술의 근원.

무기별 해석은 [02](02-drones-weapons.md#차원-해석--무기는-무엇을-하는가). 결어긋남을 일으키는
것이 곧 **관측**이다 — 이 정의를 극한까지 밀어붙인 확장(관측 병기: 관측 고정·관측 계류·복구
사격)은 [서사편 §7](../private/05x-narrative-truth.md) ⚠️이 정본.

### 1.7 흡수 = 영점 에너지 수확

"에너지를 빨아 약화시키고 자신이 성장한다"(overview §3)의 물리 실체:

| 구현된 시스템 | 차원 해석 |
| :--- | :--- |
| 거머리 접촉 흡수(`contactDamage`) | 투영 경계와 표적의 장이 직접 중첩 — 근접장 결합 수확 *(공격 형태는 재정립 예정: 서사편 §6 ⚠️ — 해석은 승계)* |
| 모기 드레인 빔(`drainDamage`) | 막 표면을 따라 여는 장 결합 채널 — 시선 필요(건물 차단) *(동일)* |
| 흡수 = 성장(`grow`) | 수확 에너지가 결합 깊이를 늘림 — 본체가 더 깊이 교차 |
| 처치 시 HP 환수(`killRefund`) | 흡수 에너지는 투영에 국소화 — 붕괴 시 막으로 되돌아와 최근접 드론이 회수 |
| 건물 파괴 → 검정 잔해([BuildingCombat](../implements/03-world.md)) | 영점 에너지 고갈 물질의 종말 — 방출 스펙트럼 소멸 = 검은색 |

### 1.8 고도 진화 = KK 준위 상승과 막 결합 약화

보스급 "부양"(overview §3.2): 흡수가 임계를 넘어 준위가 오르면 에너지가 여분 차원 진동에 실려
**막 결합이 약해지고** 중력 속박이 풀린다 — "질량보다 에너지가 우세"의 정확한 물리 표현.
부유 요새형은 반쯤 벌크에 걸친 존재. 1km 초과 상층을 보스 전용으로 비워두는 규칙([04](04-controls-gameplay.md))의 근거.

### 1.9 중력과 시간 — 양쪽 모두의 것

**"우리는 막에 갇혀 있고, 놈들은 벌크에 산다. 그러나 중력과 시간만은 양쪽 모두의 것이다."**

- **중력 = 인류가 벌크를 엿보는 유일한 창.** 중력자만 벌크로 새어나가므로, 위상 이탈한 투영도
  미개방 균열도 **중력 서명은 감출 수 없다**. 전조 관측망(§2.9)·렌즈 탐지(§2.7.1)·특이점
  유탄(§2.7.4)이 전부 이 성질 위에 선다.
- **시간 = 본체가 인류를 앞지르는 축.** 본체는 시간축으로도 연장되어 여러 시각에서 동시에
  교차할 수 있고(§2.8.2 에코), 벌크 지름길 덕에 인류도 제한적으로 미래를 "먼저 듣는다"(§2.8.1
  예지, §2.9 전조).
- 최종 등급 **블랙홀 코어**(overview §7)는 두 축의 종착점 — 중력·시간 메커닉은 캠페인 후반으로
  갈수록 짙어진다.

### 1.10 본체의 동기와 서사 계시 구조 — ⚠️ 비공개 서사편으로 분리

인식 3단계(존재론) × 4층 진실(동기)의 계시 설계와 최종 반전은
[비공개 서사편 §1.10](../private/05x-narrative-truth.md)이 정본이다(전체 스포일러 —
공개 배포 시 `docs/private/` 디렉터리째 제외).

> ⚠️ **공격 체계 재정립 예고**: 플라즈모이드의 *공격 방식*은 전면 재정립이 결정됐다(접촉
> 흡수/드레인 빔 대체 — 정본: [서사편 §6](../private/05x-narrative-truth.md) ⚠️). 항목별 처분은
> [서사편 §6.8](../private/05x-narrative-truth.md#68-기존-시스템-승계대체-표) —
> **유지**: 2.1·2.2·2.4·2.5·2.7(2.7.3 제외)·2.8·2.9. **통합**: 2.3+2.7.3 → 심판 파문(전장
> 이벤트). **승격/흡수**: 2.6 일부.

### 2.1 위상 이탈 (벌크 여행) — 🔭 예정

강한 개체는 주기적으로 막에서 벌크로 회전해 나갔다 돌아온다.

- **대상**: `strength ≥ phase.minStrength`(제안 0.35) 개체 중 `phase.chance`(제안 70%) 확률로
  보유(스폰 롤 시 결정). **주기**: 실체 `cooldown`초 ↔ 이탈 `duration`초 — strength로 보간,
  강할수록 자주·오래.
- **이탈 중**: 반투명·발광 감소, 일반 무기 무효, 공격 불가, **자동발사·에임 어시스트 제외**
  (게이지 낭비 방지 — `targeting.ts` 필터). 이동은 계속. 미니맵은 **빈 원(확률 구름)**.
- **구현**: `PlasmoidSpec.phase{...}` 블록(JSON), `CoreEnemy` 상태기계(`DrainCycle.ts` 패턴
  재사용), `Minimap`/`TargetBrackets` 표기.

### 2.2 강제 결어긋남 (관측 펄스) — 워커의 대(對)위상 역할 — 🔭 예정

워커 **중주파 수동 빔**(단발 150) = 관측 장치급 에너지 집중 — **위상 이탈 중인 개체를 유일하게
조준·타격**할 수 있고, 명중 시 즉시 실체화(쿨타임 재시작) + 데미지.

- 드론 정체성 강화: 워커 = 장거리 AA + **대위상 앵커** / 플라이어 = 실체화 타이밍 정밀 타격.
  MP 합동(워커 실체화 → 플라이어 폭딜) = "주파수 공명 파티"(overview §9)의 첫 문법.
- **구현**: `BeamSpec.manual.decohere: true` 플래그. 서사편 §7의 W2(관측 계류)가 이 메커닉의
  **일반화 정본** — W2 도입 시 이 항목은 그 특수 사례로 흡수된다.

### 2.3 KK 준위 & 준위 하락 방출 — 🔭 (서사편 §6 심판 파문으로 통합)

연속 strength를 이산 준위 n=1..4로 계단화, HP가 경계를 내려갈 때 전방위 에너지파 방출 + 색
강등(적색 쪽) — 양자화된 준위 붕괴의 방출 스펙트럼. 고준위 개체 = n−1회의 펄스를 견디는 다단
전투. **처분**: 서사편 §6.8에 따라 심판 파문(서사편 §6.1)의 보스/전장 이벤트 버전으로 **통합** — 준위
계단화(`kkLevels`)와 색 강등은 서사편 §6.7의 기반으로 유지.

### 2.4 균열(rift) 스폰 — 🔭 예정

스폰을 "맵 주변 랜덤 출현"에서 **지형에 열리는 균열 오브젝트**(코어의 위성 미세균열)로 교체.
빛나며 예고 → 밀려나옴. 균열에 HP를 부여해 **"스폰 차단"** 목표 성립 — 초반부터 봉합 전투(최종
코어전 문법)를 학습시킨다.
**구현**: `EnemyManager` 스폰 앵커 교체, `BuildingCombat`식 체력 오브젝트, `MissionSpec`에
`kind:"seal-rifts"`, 택티컬 미션 SpawnGroup 앵커.

### 2.5 씨앗 장 시스템 — 🔭 예정

지형 위 저해상도 스칼라 장 그리드(TerrainField 병치, 청크 페이로드 포함).

- 장 강함 = 스폰↑·위상 자유 / 약함 = **실체화 강제**. 균열(2.4) 파괴 시 주변 장 약화 →
  **"균열을 부숴 실체화시킨 뒤 잡는다"** 맵 장악 루프. 미니맵 히트맵.
- **카시미르 안전지대**: 좁은 바위 틈·건물 협곡은 장 모드가 기하학적으로 억제 — 플라즈모이드
  진입 불가/약화 지형. 워커가 골목을 끼고 싸울 이유.
- **구현**: `TerrainField.fieldAt(x,z)` 질의, `EnemyManager` 스폰 가중·위상 게이트, `Minimap`.

### 2.6 기타 후보 — 🔭 아이디어 풀

- **다중 투영 개체**: HP 공유 구체 2~4개의 포위 미니보스(하나의 손이 드리운 여러 그림자 조각). 셸 인스턴스
  N슬롯 매핑으로 구현 호환.
- **쌍생성**: 고준위 사망 시 저준위 2기로 변환 — 서사편 §6.6으로 **승격**.
- **반(反)플라즈모이드**: 어두운 발광 희귀 개체 — 일반 개체와 접촉 시 쌍소멸 광역 폭발(유인
  환경 무기).
- **가상 플라즈모이드**: 진공 요동으로 0.5초 미만 명멸하는 무해 개체(ΔE·Δt) — 서사편 §6.2 열화 지대의
  정보 교란 요소로 **흡수**.
- **결맞음 보강간섭**: 연사 특수의 동일 표적 연속 명중 데미지 증가(위상 누적) — 표적 고정 보상.

### 2.7 중력계 메커닉 — "중력만이 벌크를 건넌다" — 🔭 예정

#### 2.7.1 중력 렌즈 탐지 ⭐추천
위상 이탈 개체도 질량-에너지는 그대로 — 그 위치의 배경이 **중력 렌즈처럼 일렁인다**(화면 왜곡).
미니맵 "빈 원"의 물리 근거 + 렌즈를 읽고 실체화 지점을 선점하는 예측 플레이. §2.1과 세트.
**구현**: 스크린스페이스 왜곡 패스 + [`TargetBrackets`](../../src/fx/TargetBrackets.ts) 변형.

#### 2.7.2 중력 구배 지형 ⭐추천
균열 근처 = 중력이 벌크로 새어 **저중력**(워커 점프 2~3배 — 수직 시가전 아레나; 균열 파괴 시
정상화 → §2.5 루프에 물리 층 추가) / 고준위 보스 = **중력 우물**(지속 인력 — 접근할수록 DPS
기회↑/탈출 비용↑ 리스크-리워드 링). **구현**: `PlayerController` 중력·점프 상수를 스칼라 장
질의로 변조(§2.5 그리드 공유).

#### 2.7.3 브레인 파문(중력파 충격) — 서사편 §6 심판 파문으로 통합
본체의 벌크 운동/준위 붕괴 시 막이 출렁인다 — 지형이 동심원으로 물결치는 광역 패턴(워커 점프
타이밍/플라이어 고도 회피). **처분**: 심판 파문(서사편 §6.1)의 연출·판정 기반으로 **통합**.
**구현**: 지형 버텍스 변위 웨이브 + 시간차 데미지 링.

#### 2.7.4 특이점 유탄(그라비톤 병기)
중력은 인류도 벌크로 쏠 수 있는 유일한 채널 — 착탄점 1~2초 마이크로 중력 우물로 **떼를
끌어모아** 살포/오버드라이브로 일소. 상위 버전 = 이탈 개체 강제 실체화(대위상 옵션). 무기 해금
트리([TODO §7.2](../TODO.md)) 배치. **구현**: `WeaponSpec` 타입 `"well"`, `EnemyManager` 외부
인력 벡터.

### 2.8 시간축 메커닉 — "시간도 막 위의 축이다" — 🔭 예정

#### 2.8.1 벌크 지름길 예지 ⭐추천
중력 신호는 벌크 지름길로 빛보다 먼저 도착 — 적 공격·스폰·파문 0.5~1.5초 전 HUD 예고 마커.
모든 텔레그래프의 디제시스 근거 + **예지 시간 연장** 업그레이드 축. 최저 비용.
**구현**: 적 공격 스케줄의 HUD 경보 레이어 선행 노출.

#### 2.8.2 시간 투영 에코 ⭐추천
본체는 시간축으로도 연장 — 강한 개체가 t−2s/t/t+2s에서 동시에 교차(다중 투영의 시간판).
미니보스 = 본체 1 + 에코 2, **과거 에코**는 2초 전 행동 재연(패턴 학습), **미래 에코**는 2초 후
위치 선표시(선행 조준 스킬), HP 공유. **구현**: 위치 히스토리 링버퍼(과거) + 조향 외삽(미래) +
셸 N슬롯(§2.6 다중 투영과 골격 공유).

#### 2.8.3 링크 리와인드
얽힘 업링크는 벌크 경유라 막의 시간 순서에 엄격히 안 묶임 — 발동 시 3초 전 위치·HP 되감기
(주파수 대량 소모 + 긴 쿨다운). 무회복 게임의 억울사 완충("한 번 무르기"), 로그라이트 아이템
적합. **구현**: 플레이어 상태 링버퍼 + 복원(적 상태는 안 되감음). 서사편 §6.6의 적측 되감기와 **동일 링버퍼
인프라 공유**.

#### 2.8.4 시차 전단(time shear) 지대
에너지 밀도 높은 곳(씨앗 장 밀집·보스 오라)은 고유시간이 느리다 — 지대 안 ×0.7 슬로우, 단
**히트스캔 빔(즉시 작용 §1.6)은 면제** → 원거리 워커 유리 / 파고드는 플라이어는 둔화 감수.
경계 위치 선정 게임. **구현**: 지대 내 개체별 `dt` 스케일(§2.5 그리드 파생).

### 2.9 전역 루프 — 균열 전조와 관측 선택 — 🔭 예정

현행 메타 루프(세계지도 랜덤 2곳 "침공 중" → 선택 출격 → 전투 → 반복, [04](04-controls-gameplay.md#게임-흐름-상태))의
물리 해석 + 전략 층.

#### 루프 4단계의 물리 해석 ✅

| 단계 | 현행 동작 | 물리 해석 |
| :--- | :--- | :--- |
| ① 침공지 변동 | 진입마다 랜덤 2곳 | 코어의 **브레인 파문**이 지구 질량 분포와 간섭해 정상파 무늬를 만들고, 본체는 그 **배(antinode) = 막 장력 최약점**에서만 투영을 밀어 올린다. 무늬는 본체가 움직일 때마다 재배열. 동시 2곳 = 본체의 **투영 예산** |
| ② 사전 탐지 | 지도에 침공 점 | 중력 신호는 벌크 지름길로 먼저 도착 — 세계지도 = **중력파 전조 관측 콘솔**(흰 점 = 안정 권역, 붉은 깜빡임 = 문턱 넘은 균열 후보). 도식 지도 = 관측 재구성(§3 동형) |
| ③ 하나를 고름 | 점 클릭 → 출격 | 전조 단계 침공은 후보들의 **중첩 상태** — 링크 업링크 전개 = 관측 → 출격 순간 균열이 **확정(붕괴)**. 관측망의 결맞음 예산이 유한해 한 번에 한 곳 |
| ④ 반복 | 귀환 → 재선택 | 승리 = 봉합 = 국소 막 장력 회복 — 본체는 다음 배를 찾는다. 전쟁 = **막 장력 관리전**, 매 출격 = 코어 봉합전의 축소 학습 |

#### P1. 전조 콘솔 ⭐추천 (저비용)
붉은 점 호버 시 **중력 전조 판독치**(예상 균열 등급·아키타입 비율·성숙도 ETA) 노출 — "아무거나
고르기"가 "판독하고 고르기"로. **구현**: [`MenuScreen`](../../src/ui/MenuScreen.ts) 팝업에 미션
파라미터를 전조 데이터로 노출(랜덤 값을 보여주기만 해도 전략이 된다).

#### P2. 방치 균열의 성숙 ⭐추천 (전략 층의 핵심)
관측받지 못한 후보 균열은 **성숙한다**(관측되지 않은 계는 결어긋남 없이 진화) — 재등장 시
강해지되 보상도 크다. 성숙 3~4단계 초과 시 **함락 권역**(캠페인 내 자동 해제 없음 — 해제는
고비용 "봉인 해제" 탈환 콘텐츠로만 🔭; 정본 의미와 최종 해제 경로는 서사편 §5 ⚠️). 트리아지 +
"키워서 크게 먹는" 고위험 플레이. **구현**: 지역 성숙도를 진행 저장(`core.progress`)에 영속화,
미션 예산(`totalHp`/`spawnCount`) 배수.

#### P3. 파문 링 시각화
지도에 마리아나발 동심원 파문 링 — 링이 도시 밀집점과 겹치는 곳에서 후보 점화. 숙련자는 다음
침공지를 어림 예측(패턴 있는 랜덤). **구현**: 추첨을 "링 반경 × 도시 가중치"로 교체 +
[`worldMapSvg`](../../src/ui/worldMapSvg.ts) 링 오버레이.

#### P4. 시간차 출격
전조 ETA로 **진입 시점**이 선택지 — 조기(미성숙: 약함·보상 적음) vs 지연(성숙: 강함·보상 큼).
P2의 세션 내 슬라이더판. **구현**: 지역별 난이도 프리셋 태그 선별.

#### P5. 조석 창(tidal window)
본체의 벌크 궤도가 막에 근접하는 주기마다 특수 후보(랜드마크·보스 균열)가 열림 — 라이브
이벤트 문법의 디제시스. **구현**: 로컬 시간 해시 로테이션(서버 불요).

#### P6. 에코 전장 ✅ (설정만, 무비용)
막은 진동의 잔향을 보존한다 — **RETRY = 시간 에코 재진입**(같은 전장 + 새 확정 = 새 랜덤 미션,
현행 동작 그대로), **탐방 모드 = 잔향이 가라앉은 권역의 무관측 정찰**.

## 3. 그래픽 표현의 세계관 근거 — 왜 텍스처가 없고 다면체인가

'어드밴스드 로우 폴리'(overview §1)는 미학이자 **디제시스**다. 두 층위로 정당화된다.

### 3.1 플레이어가 보는 화면 = 관측 재구성 렌더 ✅

화면은 실사가 아니라 드론 센서의 관측 데이터를 **얽힘 업링크로 압축 전송받아 재구성한 것**(§1.5)이다.
씨앗 장이 짙은 전장에서:

- **텍스처·미세 요철 = 고주파(미시) 정보**는 장 요동 잡음에 묻힌다. 렌더러는 통계적으로 확정
  가능한 거시 구조(면·능선·윤곽)만 그린다 — **플랫 셰이딩 다면체는 "단순화한 그림"이 아니라
  관측이 확정한 것의 전부**다.
- 강체(지형·드론·건물) = 플랫 셰이딩(소수의 거시 고유상태로 확정) vs 플라즈모이드 = 스무스
  셰이딩(**확률 밀도 구름 |ψ|²** — 확정 경계 없음). 기존 플랫/스무스 혼용 규칙의 물리 근거.
- **단색 면 팔레트** = 재질 대신 **분류 라벨 색**(전술 정보 우선의 군용 재구성 문법).
- **이미시브+블룸만 사실적**: KK 전이 복사(§1.3)는 좁은 선 스펙트럼의 강한 신호라 잡음 위로
  올라온다 — 발광만은 "실제로 그렇게 보이는" 것.
- 실시간 그림자를 플레이어·적에만 = 재구성 예산의 전술적 우선 배정. HUD 기호(미니맵·브래킷·
  화살표) = 재구성 위의 **관측 메타데이터**(위상 이탈 빈 원 §2.1이 자연 확장).

### 3.2 세계 자체가 디테일을 잃고 있다 ✅

**영점 에너지를 흡수당한 물질은 문자 그대로 미시 자유도를 잃는다.** 표면 질감은 방대한 미시
상태(엔트로피)가 만드는 것 — 바닥상태 에너지를 수확당하면 물질은 **최소 다면체로 주저앉는다**.
침공이 진행된 전장일수록 로우 폴리인 것은 양식이 아니라 **증상**이다.

- 인트로의 집 붕괴 = 이 과정의 극단(결합 자체가 유지되지 않는 순간).
- 건물 점진 적색 → 붕괴 → **검정 잔해**([BuildingCombat](../implements/03-world.md)) = 방출할
  에너지가 남지 않은 종말 상태(§1.7).
- 처치 **디졸브** = 결맞음이 붕괴한 투영이 뜯겨나가며 장이 바닥상태로 이완 — 노이즈 침식
  셰이더는 모드별 소산의 시각화.

> **아트 디렉션 규칙** — ① 텍스처 금지, 면 단위 단색 + 플랫(강체)/스무스(플라즈모이드·에너지).
> ② 발광(이미시브+블룸)만 "사실적" 채널 — KK 색 문법(적=약체, 청백=강체) 준수.
> ③ 파괴·소멸은 "디테일/에너지의 상실"(단순화·흑화·소산)로 표현.
