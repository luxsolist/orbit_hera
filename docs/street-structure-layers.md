# 공통 가로 빌더의 구조물·층위

좌표 예외 대신 OSM 원본 태그와 폴리곤을 사용한다. 플랫폼·쉼터·지붕·요금소는 열린 구조물로, 화장실·매점·창고 등은 각각의 낮은 시설물로 분류한다. 명시된 높이는 보존하고 추정 높이는 출처를 기록한다.

- min_height / building:min_height: 명시된 하부 빈 공간.
- 양수 layer: 층위 순서이며 실제 높이가 아니다. 높이가 없으면 임시 간격을 추정하고 layer-estimate로 표시한다.
- building=bridge: 연결 구조물의 하부 공간 보존.
- 건물 relation inner ring: 안뜰. 화면과 충돌에서 모두 빈 공간 유지.
- 지하 시설은 지상 빌딩으로 올리지 않는다. 제작된 랜드마크를 일반 건물로 덮어쓰지 않는다.

## 설계와 검증

원본 외곽·안뜰 복원 → 지상/상부 점유 분리 → 통행 공간 배분 → 담장 개구부·기둥 배치 → 수로 교차 통과면 생성 → 삼각형 저장 순서다. 게임과 도시 뷰어는 같은 결과를 사용한다.

짧은 수로 교차부는 양안 높이를 잇고 물 원본은 유지한다. 명시적 교량이 없는 교차부는 추정으로 기록한다. 기둥이 차도에 생기지 않도록 최종 충돌 검사에 포함한다.

서울 입력은 1,600개 청크다. 도로 연속성·건물 중첩·청크 경계·기둥 충돌 검사를 통과하기 전에는 전체 결과를 게시하지 않는다. 분류 단위 테스트 통과를 전체 적용 완료로 간주하지 않는다.

공통 실행: node scripts/build-street-regions.mjs seoul city-wide

압축: node scripts/pack-street-region.mjs seoul city-wide

첫 명령은 준비·설계·삼각형 생성·검사·로컬 게시를 수행한다. 두 번째 명령은 검증한 결과를 2×2 묶음에 반영한다. GitHub Releases 발행은 별도다.

입체 교차·장거리 교량·건물 내부 통로에 근거가 부족하면 검토 대상으로 남긴다. 모든 겹침을 임의로 고가화하여 해결하지 않는다.

## 입체 통로와 수역

covered 태그, 주차 통로, 충분한 높이의 건물을 길게 관통하는 서비스 도로는 하부 벽체와 상부 건물 볼륨으로 나눈다. 건물 전체를 띄우지 않고 통로 부분만 개방한다. 명시되지 않은 통행 높이는 access-route-estimate로 기록한다. 이 추정은 실측 복원이 아니다.

외곽 조정으로 건물이 여러 날개로 나뉘어도 원래 질량의 75% 이상과 각 유효 부분을 보존한다. 안뜰도 유지한다.

청크에 잘린 inner ring은 유효화 과정의 채움 규칙에 맡기지 않고 외곽에서 명시적으로 차감한다. 하천 중심선을 건너지 않고 나란히 붙은 제방길은 교량으로 만들지 않는다. 수정된 수역 폴리곤도 도로와 함께 저장한다.

좁은 골목과 공유 통로는 일반 차도의 여유 폭을 강제하지 않는다. 일반 경로가 연결되지 않을 때만 서비스·주거 골목에 한해 더 작은 보행 통로 여유 폭으로 재검사하고 sharedPassages에 기록한다. 건물 점유 영역은 유지한다. 이는 대형 워커가 모든 골목에 들어갈 수 있다는 보장이 아니다.

경로 탐색은 고정 0.5m 격자 대신 실제 자유 공간을 삼각분할한 연결 그래프를 사용한다. 좁지만 유효한 연결부를 격자 정렬 때문에 실패시키지 않는다.

좁은 생활도로는 일반 여유폭으로 연결되지 않을 때만 공유 통로 여유폭과 최대 24m의 국소 우회를 시도한다. 주거/생활도로를 가로막는 80㎡ 이하·높이 3.5~8m의 일반 구조물은 통과 공간을 추정하며 `access-route-estimate`로 남긴다. 랜드마크는 이 추정에서 제외하고, 상부 원형과 하부 잔여 부분을 유지한다. 이 분류는 현장 고증을 확정한 결과가 아니므로 원본 태그와 함께 검토할 수 있어야 한다.

하천 횡단 길이는 주변 8m 검색 띠 전체가 아니라 실제 수면과 도로 중심선의 교집합 각각에서 측정한다. 긴 둑길에 붙어 있는 짧은 암거/교량을 장거리 수면 횡단으로 오분류하지 않는다. 구조물 감사도 정규화된 입력의 SHA-256과 연결하여 이전 입력의 합격 보고서를 재사용한 게시를 차단한다.

## 서울 분류 감사 (2026-09-27)

1,600청크: 요금소 63, 열린 지붕 1,223, 쉼터 436, 화장실 319, 플랫폼 4개 레코드. 하부 공간 있는 레코드 1,899개, 중정 있는 레코드 173개. 청크 경계에서 분할된 레코드를 포함하므로 고유 건물 수가 아니다. 분류 형식 오류 0개; 높이가 통행 높이 이하인 원본 915개는 검토 목록에 남는다. 렌더러는 상부 최소 두께 0.4m를 보장하되 확인되지 않은 높이를 실측값으로 표시하지 않는다.

높이 검토 915건의 상세: 지붕 842, 쉼터 18, 요금소 3, 일반 건물 51, 화장실 1. 모두 `layer-estimate`이며 명시적인 min_height 측량값 오류로 해석하면 안 된다. 기본 시설물 높이와 추정 층위가 충돌하는 경우도 포함한다.

## 상부 도로의 면 소유권

양수 층위 및 교량 도로는 지상 차도와 별도 메시로 저장한다. 건물의 지상 외곽을 상부 도로에서 빼지 않는다. 지상·상부 연속성을 각각 검증하고, 같은 좌표에서도 발 높이와 층위를 구분해 지지면을 조회한다.

명시된 높이가 없는 상부 도로는 층위당 5m를 기본 간격으로 추정한다. 도로와 겹치는 건물 지붕보다 위에 두고 접근부의 높이 영향은 1:6 기울기로 연속 전이한다. 이는 통과 가능한 시각적 초안이며 실측 높이나 실제 진입 램프의 복원을 의미하지 않는다. 지상·상부 메시의 평면 중첩은 허용하지만 같은 층위의 차도/보도 중첩은 허용하지 않는다.
