# 부산 도시 색상 기준

## 대표 이미지 / 출처
- 해운대 전경: https://www.unesco.de/assets/bilder_und_videos/Kultur/02_Welterbe/Fotos/Busan_City_Haeundae_Beach_KOGL.jpg
  - 직접 확인한 사진을 주 기준으로 삼았다. 흰색/은회색 고층 외벽, 청회색 유리, 청록 바다, 밝은 모래, 녹색 해안 구릉.
- 감천문화마을: https://www.visitbusan.net/index.do?lang_cd=ko&menuCd=DOM_000000301001001000&uc_seq=365
  - 공식 관광 소개의 파스텔 마을 색을 소량의 민트·살구·라벤더 포인트로 해석.
- 광안리 야경 참고: https://english.visitkorea.or.kr/svc/contents/infoHtmlView.do?vcontsId=215803
  - 향후 해안 야간 랜드마크 조명 작업의 참고. 이번 작업에서 교량 조명이나 수면 반사는 새로 구현하지 않았다.

## 적용
부산 전용 `src/world/cities/busan.ts`에서 16가지 건물 색상과 가중치, 지붕, 도로/보도, 모래/녹지, 가로시설, 하늘/환경광, 수역 색상을 관리한다. 색상은 원본의 픽셀을 그대로 추출한 값이 아니라 기존의 밝고 선명한 애니메이션 렌더링에 맞춘 시각적 해석이다. 밝은 중성 외벽을 중심으로 청회색과 소량의 파스텔을 섞었다. 도시 전체를 감천마을처럼 알록달록하게 만들지 않는다.

게임과 도시 뷰어는 동일한 cityAppearance → StreamingWorld 경로를 사용한다. 서울의 기존 색상과 하늘 기본값은 유지한다. 기기 시간 기반 아침/저녁·낮·밤 전환도 유지한다. 바다 색은 지도에 수역으로 포함된 표면에 적용되며 수면 시뮬레이션은 아니다. 건물 전용 랜드마크 재질은 일반 건물 팔레트를 따르지 않을 수 있다. 구역별 색상 배정과 새 부산 전용 벽면 텍스처는 이번 범위에 포함하지 않는다.
