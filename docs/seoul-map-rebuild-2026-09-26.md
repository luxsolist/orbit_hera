최종 게임/뷰어 보정과 동일한 높이 계산으로 서울 전체 796,578개 도로 선분, 19,015,434표본을 검사했다. 중심 및 양쪽 폭 40% 위치를 최대 4m 간격으로 읽는다. 내부 비유한/누락 표본은 0개이며 지도 외곽 밖으로 나간 2,000표본은 별도로 기록했다.

| 항목 | 수정 전 | 수정 후 |
|---|---:|---:|
| 18% 초과 경사 후보 선분 | 45,706 | 21,849 |
| 갑작스러운 경사 변화/방향 반전 후보 선분 | 28,731 | 9,232 |

두 범주는 중복되며 정상 산길/교량 또는 추가 보정이 필요한 구간을 포함한다. **전수 품질 판정은 여전히 false다.** 후보 감소·구조 검사 통과를 서울 모든 도로가 자연스럽게 완성됐다는 의미로 사용하지 않는다. 전체 후보의 위경도와 원본 도로 선분은 `build/seoul-road-profile.json`에 저장했다. 수정 전 비교는 `build/seoul-road-profile-baseline.json`, 감소 여부 검사 기록은 `build/seoul-road-profile-final.log`다.

- 제보 지점 60m 내 1,094표본 최대 경사 4.58%. 공통 보정을 끈 원본 지형 비교군은 64.97%다. 실제 아스팔트 메시와 보행 높이 일치, 검사한 도로 지면 관통 없음.
- 지도 구조 오류 0/기존 경고 54. 관련 테스트 50개, 타입 검사 통과. 과거 청계천/종로 제보와 새 제보가 필수 빌드 검사에 포함된다.
- 도시 전체 도로 검사는 원본 빌드 및 압축 생성 전에 자동 실행된다. 내부 데이터 오류는 중단하고, 잔여 품질 후보는 명시 경고/false로 기록한다. `npm run audit:roads -- seoul --strict`는 후보가 남으면 실패한다. `--compare <이전 보고서>`는 동일 검사 기준/선분 수에서 급경사·굴곡 후보 수와 최대 경사가 악화되면 실패한다.
- Releases 게시와 커밋/푸시는 수행하지 않았다. 이전 Releases 원본 압축은 최신 산출물이 아니므로 다음 게시 시 새로 준비한다.
