## 판독 기준과 한계
- 작은 고층 후보: 바닥 면적 200㎡ 미만이면서 높이 45m 초과. 실제 소형 타워/종탑도 포함하므로 오류 확정이 아니다.
- 도로 급경사: 중심선 8m 이하 간격의 지형 고도차가 수평거리의 12% 초과. 산길의 정상 경사도 포함한다. 12%는 탐색 기준이며 법정/설계 기준이 아니다.
- 지붕 보정: 기존 중심지면+높이보다 렌더 지붕을 높인 수. DEM 요철 또는 실제 경사에 대한 기하학 보정이며 실측 건물 높이가 아니다.
- 지형 범위는 500m 원 내부 격자 표본이다. 최대 기울기는 표본 기반이며 실제 도로 종단 측량이 아니다.
- 서로 겹치는 반경의 건물은 중복 집계되므로 행별 수를 서울 고유 건물 수로 합산하지 않는다.
- 런타임 타일은 OSM 원본 ID/높이 추정 여부/층수/수집시각을 보존하지 않아 건물별 정확도 자동 인증이 불가능하다.
- 공통 외벽·창문·평평한 지붕을 쓰므로 궁궐/성문/한옥의 고유 형태와 실제 재질 재현은 미완료다.
- 현재 지형은 1024m당 33점(32m 간격), 교량 층위/도로 종단 측량이 없으며, 잠실은 추정 평탄화이다.

상세 좌표·후보 목록: build/seoul-landmark-audit.json. 재실행: node scripts/audit-seoul-landmarks.mjs.

## 원본 표본 대조 결과
- N서울타워: 수정 전 카탈로그 좌표 37.5349513,126.9870892의 원본 이름이 `Viewpoint of the N Seoul Tower`이다. 타워를 바라보는 장소를 타워로 잘못 선택했다.
- 실제 타워 구조 [OSM way 370286010](https://www.openstreetmap.org/way/370286010)는 약 37.551200,126.988221이며 height=236.7, roof:height=124.7 태그가 있다. 운영사 주소도 [남산공원길 105](https://www.nseoultower.co.kr/global/customer/faq.asp?sch_type=01)다. 등록 지점과 거리 약 1812m로, 수정 전 반경 500m에 실제 타워가 포함되지 않았다. 2026-09-13 타워 외곽선 중심 좌표로 수정했고 위 표를 재집계했다.
- 덕수궁 북쪽: [way 1216351370](https://www.openstreetmap.org/way/1216351370), [way 1216351372](https://www.openstreetmap.org/way/1216351372)는 원본에 building=yes만 있고 높이/층수가 없다. 인접 게임 폴리곤은 각각 약 67㎡/84m, 19㎡/79.5m다. 원본 수치로 검증된 높이가 아니며 실제 저층 여부·정확한 층수는 추가 자료가 필요하다.
- 숭례문 남동쪽: [way 1233842472](https://www.openstreetmap.org/way/1233842472)는 퇴계로8길 49-3, building=yes이고 높이/층수 정보가 없다. 같은 위치 게임 폴리곤은 약 72㎡/103m다. 이 값을 실측 높이로 취급할 수 없다.
- 롯데월드타워 555m는 [롯데CM 공식 자료](https://www.lottecm.com/en/build/lotte-world-tower.html)와 일치하지만 전체 실루엣은 단일 압출이고 주변 도로·3개 시설 높이는 추정 보정이다.
- [경복궁 근정전의 실제 기와 지붕](https://www.korea.kr/news/policyNewsView.do?newsId=148606395)과 달리 현재 스트리밍 건물은 평지붕 압출 방식이다. 궁궐·성문·한옥 구역은 높이만 바꿔도 실제 형태와 같아지지 않는다.

OSM API 지도 응답으로 3개 표본 구역을 읽었다. 전체 37곳의 모든 건물에 대한 원본/사진 대조를 수행한 것은 아니다. 원본 태그 누락은 실제 높이가 낮다는 증거가 아니라 현재 높이를 인증할 근거가 부족하다는 뜻이다.
