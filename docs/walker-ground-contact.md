# 워커 접지 동기화 수정

- DronePresentation은 내부 목표 속도 대신 직전 프레임과 현재 실제 위치 차이로 보행 애니메이션을 진행한다. 충돌/이동 제한으로 실제 이동량이 줄면 발동작에도 반영된다.
- 접지 구간에는 발목 목표를 월드 좌표에 고정하고 관절 IK로 몸체 이동을 상쇄한다. 발을 들거나 대시/점프/리스폰할 때 고정을 해제한다. 관절 도달 범위를 벗어나면 해제하여 다리를 과도하게 늘리지 않는다.
- 보행 중 골반 좌우 회전이 접지 발을 흔들던 부가 동작을 제거하고, 몸통의 시각적 움직임은 유지한다.
- 지형 높이에 발을 두고 이동하던 상태에서는 연속적인 내리막을 따라 접지를 유지한다. 한 프레임 허용 낙차는 수평 이동량×0.8+0.025m, 최대 1.2m. 점프/상승 중, 옥상 가장자리, 큰 절벽 낙하에는 적용하지 않는다.
- 좌우 발 높이 보정은 부드럽게 반영하여 보정값의 갑작스러운 변화를 완화한다.

검증: 전후좌우 접지 발의 월드 목표 오차 <5mm, 30/60/120fps에서 기울기 0.35 내리막 접지 지속·가짜 착지 없음, 점프 이탈 및 10m 절벽 낙하 유지. 보행/모델/컨트롤러/조작 응답/추력 관련 85개 테스트 통과. 이 수치는 자동 테스트 조건의 결과이며 모든 실제 지형에서의 시각 품질을 보장하는 측정값은 아니다.
