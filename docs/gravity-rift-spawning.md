# 중력이상지대 출격 거점

2026-09-19 구현. 밸런스 수치는 초기값이며 실플레이 비교 측정으로 확정해야 한다.

## 실행 경로

실제 Game이 EnemyManager.enableGravityRifts()를 설정한다. 일반 웨이브, 피라미드/물량 증원, 로스터(거머리·모기·소인체·정예), 보스 투영 및 보스 지원병 모두 spawnOne/spawnBossProjections의 공통 출격 경로를 사용한다. 독립 AI 단위 검사·기존 미리보기는 명시적으로 활성화하기 전까지 기존 위치 배치를 유지한다.

GravityRifts가 배치·출격 상태·표현·노출 계산을 소유한다. 설정은 src/enemies/GravityRifts.ts의 RIFT_RULES를 사용한다. 게임/도시뷰어 조명 변경과는 독립이다.

## 초기 규칙

- 기본 2개, 반경 100m, 경고 근접 기준 140m(문구는 그보다 100m 앞에서 안내).
- 전장 중심 주변 350~700m에 배치하되 작전구역 및 월드 경계 안에 구체 전체를 넣는다.
- 낮은 거점은 지면 위 250~400m, 높은 거점은 600~900m. 지형·건물 최대 높이에 구체 반경과 20m 여유를 더해 필요하면 상승한다. 높은 산/건물 때문에 1,000m를 넘을 수 있다.
- 중심 간 최소 수평 거리 300m, 플레이어 초기 위치와 최소 260m 간격. 25m 간격으로 지형/건물 높이를 샘플링한다. 안전하게 2개를 둘 수 없으면 1개. 안전한 거점이 전혀 없으면 배치 오류를 표시하는 예외를 발생시킨다.
- 현재는 로드된 월드의 heightAt/topAt을 참조한다. 아주 얇은 구조물이나 아직 로드되지 않은 데이터까지 완전한 공간 교차를 보증하는 검사는 아니다.

## 출현과 전투

거점 생성 후 4초 활성화 예고 → 구체 내부에서 1.2초 동안 출구로 이동 → 도착 구체 3초 예고 → 동일 개체가 차원도약 → 1초 공격 유예.

출구는 분산하고 3기 단위로 거점을 교대한다. 거점 생성 뒤 첫 출격은 약 8.2초, 이미 활성화된 거점에서는 약 4.2초다. 기존 스폰 수·HP·미션 직무·증원 간격·동시 상한은 보존한다. 기존 위치 계산을 전투 도착 목적지로 사용해 플레이어 고도 대응과 시설/진형 배치를 유지한다. 도착점이 건물 내부이면 윗면 위로 보정한다.

형성/대기 중에도 alive 상태로 예산과 전장 소진 판정에 포함한다. 그동안 공격·피격·자동 조준·수동 락온을 막으며 강제 실체화 사격으로도 출현 보호를 해제하지 않는다. 보스의 분출/회복 대표도 출격 중인 보스를 사용하지 않는다. 대형 개체는 출격 중 크기를 제한하고 도착 시 원래 크기를 복원한다.

## 통과 피해와 안내

기체 기본 최대 HP × 0.12 × 구체 내부 체류시간. 성장 HP에 비례해 피해가 올라가지 않는다. 이동 선분과 구의 교차 구간을 사용하고 겹친 구간은 합집합으로 처리한다. 내부 정지/프레임 사이 완전 관통/활성화가 프레임 도중 발생한 경우를 처리한다.

환경 피해는 일반 타격의 무적시간을 만들거나 소모하지 않으며 리스폰 보호는 존중한다. 리스폰/리와인드는 위치 변경 세대를 증가시켜 순간이동 경로에 잘못 통과 피해를 적용하지 않는다. 피격 음향·흔들림은 0.35초 간격으로 제한한다. 근접 경고 문구·거리·최초 진입 음향을 제공한다.

공유 구형 지오메트리와 투명 경계 셰이더를 사용한다. 기존 중력 렌즈 패스에 가까운 순서로 통합해 기존 6개 상한을 공유한다. 구체 내부 카메라의 왜곡은 약하게 제한한다. 도착 예고 메시의 동시 표시는 12개까지다. 초기화/탐방 전환은 거점·대기 출격·위험 판정·GPU 자원을 제거한다.

## 검증 및 후속 조정

자동 검사: 30/60/120fps 동일 노출, 고속 관통, 겹침/접선/활성화 경계, 리스폰 보호·순간이동 제외, 로스터·보스·후속 증원 출격, 조기 미션 종료 방지, 탐방 초기화, 건물 위 배치, 카메라 내부 왜곡.

첫 적용은 공통 2개 거점이다. 미션별 1~4개 설정 UI, 거점 파괴/봉쇄 목표, 플레이어를 따라 이동하는 거점, 강제 흡인, 별도 신형 보스 공격은 이번 범위에 포함하지 않는다. 전체 신규 공격의 동시 예고 감독과 고도별 승률/정지 사격 효율은 후속 실플레이 조정 대상이다.
