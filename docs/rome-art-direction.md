# 로마 도시 색상 기준

- 직접 확인한 로마 전경: https://www.terraevents.com/destination/organizing-an-event-in-italy/98-rome
- 사진: https://www.terraevents.com/images/country/italy/Roma_Cover.jpg

## 구현 범위
`src/world/cities/rome.ts`의 독립 팔레트를 `rome-stream`에 등록했다. 게임과 도시 뷰어의 공통 StreamingWorld를 통해 적용한다.

16가지 외벽 색에 가중치를 부여하여 밝은 크림/석재가 주를 이루고 살구/분홍/황토를 포인트로 사용한다. 지붕은 6가지 테라코타/석재 계열이다. 도로는 중성 회색, 보도는 밝은 석재색, 수역은 절제된 회녹색, 수목은 짙은 올리브 녹색으로 설정했다. 기존의 선명하고 밝은 애니메이션 렌더링을 유지한다. 사진 픽셀 자동 추출이 아닌 시각적 색채 해석이다.

높이 기반 외벽 유형의 고층 유리창 전환을 75m로 조정했다. 역사 지구 전체를 유리 오피스로 해석하지 않도록 낮은 건물의 창문 간격과 대비도 조정했다. 건물 유형은 높이/면적에 따른 시각적 추정이며 실제 용도 조사는 아니다.

현지 시간은 Europe/Rome과 로마 위경도를 사용하며 기존 일출/일몰 및 서머타임 처리 경로를 그대로 사용한다. 서울/부산 설정은 변경하지 않는다.

이번 작업은 도시 전반의 색상/분위기 단계이다. 기와 지붕/돔의 실제 형태, 석재 포장 형상, 소나무 수형, 개별 랜드마크 정밀 모델, 구역별 역사/현대 건물 분리는 별도 단계이다. 기존 공용 외벽 텍스처를 재사용하며 원본 사진은 배포 에셋에 포함하지 않았다.
