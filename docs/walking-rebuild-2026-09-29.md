# 로마·아테네 보행 연결 재빌드

## 적용 범위

도시별 좌표/OSM ID 예외를 추가하지 않고 공통 빌더에 통로 예약, 수변 횡단, 실내/실외·지상/상부 층위, 저층 구조물 보행면 및 경사 충돌체 처리를 누적한다. 최종 산출물은 기존 지도 청크에 포함한다.

## 검증

- 공통 TypeScript 검사: 148개 파일 / 1,873개 테스트 통과. 대형 지도 검사 간 자원 경합을 피하기 위해 동시 실행 수 2로 검사했다. 타입 검사도 통과했다.
- Python 빌더 검사: 59개 통과.
- 소규모 빌드→메시→실제 충돌 검증: 101개 지점, 누락 0, 건물 충돌 0.
- 로마 앞선 전체 설계 검사: 보행 지점 2,110,752개, 누락 0. 최종 충돌 검사에서 발견한 경사 충돌체/삼각형 외삽/층위 비교 문제를 보완했으며, 아래 최종 전체 검사에서 통과했다.

최종 전체 도시 재빌드·검증·압축 완료 수치는 아래에 기록했다. 초기 중간 결과는 원인 추적 기록으로 유지한다.

## 건물과 상부 통로 접합

외부 계단·관중석 면이 일반 건물의 단일 외피에 묻히는 경우, 최종 보행면 경계에 맞춰 건물 형상과 충돌체 양쪽에 개구부를 만든다. 평평한 옥상 경로는 아래 건물을 비우지 않는다. 개별 제작된 랜드마크 모델은 이 일반 외피 절삭에서 제외한다. 동일 단계는 모든 도시의 메시 생성 진입점에서 실행되며 반복 적용 시 형상을 추가로 깎지 않는다. 기존 로마 상부 경로 충돌 136개 지점의 외피 대조에서 잔여 건물 충돌 0개를 확인했으며, 전체 최종 검증은 별도로 수행한다.

## 최종 배치와 보행면의 일치

관중석 등 보행 가능한 구조물의 계단 면도 차도 확보 후 확정된 건물 외형을 사용한다. 원본 외형으로 만든 계단 면이 최종 차도를 다시 덮지 않도록 메시 생성 전에 같은 경계로 잘라 삼각형을 재생성한다. 상부 보행 경로에도 지지대 여유 폭을 확보한다. 같은 경로의 상부 끝점에 붙은 5cm 미만의 지상 잔여 조각은 접점으로 정리한다. 일반 지상 경로 자체를 길이만으로 삭제하지 않는다.

로마 1차 최종 메시 검사 결과: 1,640개 청크 형상 오류 0, 경로 샘플 7,500,433개 누락 0, 경계 샘플 1,638,126개 단차 오류 0. 남은 충돌 31개는 최종 관중석 외형 불일치 21개, 상부 지지대 9개, 2mm 접점 잔여 조각 1개로 분류하여 위 규칙을 보완했다. 최종 재검사 결과는 별도 기록한다.

## 지상 보도와 계단 면의 높이 접합

18cm 이하의 보행판은 최종 지상 보행면으로 통합하며, 같은 영역의 경로 층위도 지상으로 맞춘다. 명시적 고가/교량 경로는 이 전환 대상에서 제외한다. 일반 건물·수면·다른 상부 보행면의 소유 영역을 침범하지 않는다.

관중석 경계에 실제 보행 경로가 만나는 지점은 진입점으로 저장한다. 그 지점은 18cm의 단차로 시작하고 거리당 최대 0.45m의 상승 한도로 기존 관중석 높이에 연결한다. 진입점을 메시 꼭짓점에 포함하고 가장자리를 세분화하여, 경로가 높은 면에 수직으로 부딪히는 문제를 줄인다. 윗면·측면·충돌체는 같은 높이 규칙을 사용한다. 이 값은 빌드 공통 함수 street-supports.mjs에 있으며 결과 메시/충돌체가 청크에 저장된다.

실제 로마 두 청크 집중 검증: 22,181개 지점, 보행면 누락 0·건물/지지대/경사면 충돌 0. 이 결과는 전체 도시 검사와 별개로 기록한다.

## 재현 및 운영

표준 진입점은 npm run build:city-surfaces -- <city> 이다. 검사 실패 시 새 도시 결과의 게시를 막는다. 입력·설계 코드·중간 산출물 해시가 일치할 때 설계만 재사용하고, 메시와 충돌 판정은 새로 생성한다. 압축은 검증을 통과한 완성 청크에 대해 실행한다.

브라우저의 기존 오류 페이지 새로고침이 보안 정책에 의해 차단되어 이번 실행에서는 자동 화면 확인을 수행하지 못했다. 형상·경계·게임 공용 충돌 판정 검증 결과와 시각 검증은 구분한다.

## 저장 단계 검증 보완

최종 가로 설계가 지형 높이를 교체한 뒤 기존 네트워크/국부 보정 레시피를 원본 대조하면 잘못된 오류가 발생한다. 두 레시피는 최종 streetPlan 적용 전 단계에서 입력·결과·멱등성·경계를 검증하고, 최종 가로는 별도의 전체 메시·충돌·경계 검사로 검증한다. 로마 네트워크 782,798개 값과 국부 보정 13,986개 값이 해당 검사에서 통과했다.

기존 국부 보정으로 129×129가 된 청크에 33×33 최종 높이 배열을 대입할 때 격자 크기를 함께 갱신하지 않던 오류를 수정했다. 최종 지형의 크기는 최종 높이 배열에서 결정하고, 도로 높이 배열이 없으면 같은 최종 지형을 사용한다. 실제 도시 도로 샘플의 내부 비정상 높이 61,269개가 0개로 줄었고, 지도 범위 밖 171개 샘플은 별도로 구분했다. 격자 크기가 다른 입력에 대한 회귀 검사를 추가했다.

기존 도로 원본 중심선/폭에 기반한 경사 검사는 로마에서 급경사 4,118개·굴곡 2,593개 구간을 검토 대상으로 남긴다. 이는 최종 보행면 연결 누락·충돌 검사의 성공과 구분하며, 모든 지형 품질 경고가 해결됐다고 해석하지 않는다.

아테네 첫 전체 실행은 차선 생성 중 메모리 부족으로 운영체제가 종료했다. 입력 해시가 일치하는 중간 설계 단계를 재사용하고, 두 도시의 무거운 생성·검사·압축 작업을 순차 실행한다.
