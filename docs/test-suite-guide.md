# 테스트 실행과 유지 기준

- `npm test`: 전체 자동 테스트. 기존과 같이 모든 회귀 검증을 실행한다.
- `npm run test:fast`: 일반 개발용. 긴 전투 시뮬레이션 및 지도 데이터 검증 묶음을 제외한다.
- `npm run test:extended`: 긴 전투 시뮬레이션, 월드 검증, 서울 랜드마크 전체 연결, 실제 궁궐 타일의 메모리 예산을 검증한다. 일부 관련 단위 사례도 같은 파일에 포함된다.
- `npm run test:watch -- --project fast`: 일반 테스트만 변경 감시한다.
- `npm run test:e2e`: 기존 브라우저 스모크 테스트. 위 자동 테스트와 별도다.

지도·전투·렌더링 변경 마무리와 커밋 전에는 `npm test`와 `npm run typecheck`를 실행한다. 전체 지도 산출물 전수 감사는 기존 `npm run validate:world`로 별도 실행한다. extended는 모든 도시의 모든 타일 전수 감사 명령을 대체하지 않는다.

분류는 vitest.config.ts의 extended 목록 한 곳에서 관리한다. 새로운 테스트는 기본적으로 fast에 포함되며, extended로 지정한 파일은 fast에서 자동 제외된다. 테스트를 비활성화하거나 skip하지 않는다.

## 이번 정리

사용하지 않는 StreetPreparation과 이전 street worker 및 테스트 1개를 함께 제거했다. GameInstance 중복 1개와 동일 HUD 해상도의 중복 6개를 제거했다. 재질 검증은 고정 버전 문자열 대신 원본 재질과의 분리, 셰이더 기능 유지, 낮/밤 값 전달을 확인한다. 음소거 검증은 출력 게인이 0이 되는지와 원래 음량 복원을 확인한다.

도로 높이 회귀, 타일 취소·자원 해제, 충돌 판정 등 실제 오류 재발 방지 검증은 유지한다. 테스트 수를 줄이는 것 자체를 목표로 삼지 않는다.
