# 경복궁 핵심 전각 1차 적용

## 범위
근정전·광화문·경회루의 기존 일반 압출 건물을 전용 전각 모델로 대체한다. 게임과 도시 탐색은 동일한 청크 로더와 메시 생성 코드를 사용한다. 기존 건물의 전투 분류를 유지하고 병합 메시의 정점 범위로 파괴/타깃 등록에 연결한다. 다른 도시에는 적용하지 않는다.

## 배치 근거
2026-09-13 OSM 지도 외곽선에 대응하는 기존 청크 폴리곤을 정확히 지정했다. 이름이나 넓은 반경으로 주변 건물을 제거하지 않는다. 지도 데이터가 재생성되어 외곽선이 달라지면 일반 건물로 남으며 배치 명세를 재검토해야 한다.
- [근정전 way 170199428](https://www.openstreetmap.org/way/170199428)
- [광화문 way 170199440](https://www.openstreetmap.org/way/170199440)
- [경회루 way 170199469](https://www.openstreetmap.org/way/170199469)
- [국가유산포털 경복궁 소개](https://www.heritage.go.kr/heri/html/HtmlPage.do?pg=%2Fpalaces%2FpalacesRoyalInfo.jsp): 중심 전각의 공간 구성 참고.

OpenStreetMap contributors, ODbL. 외곽선은 측량 인증 자료가 아니다. 원본 표본은 build/gyeongbokgung-reference.osm, 배치 명세는 src/world/cities/gyeongbokgung-placement.json이다.

## 구현
기존 레시피를 scripts/build-palace-assets.mjs로 전용 JSON 에셋으로 생성한다. 지붕·기둥·기단의 색을 정점에 저장해 기존 건물 메시와 함께 그리되 일반 건물 창문 무늬는 적용하지 않는다. 가로/세로는 지도 외곽선 방향과 범위에 맞춘다. 경회루 레시피의 가짜 사각 연못/테두리를 제거하고 지도 수역을 사용한다. 세 전각의 잘못된 관리용 탐색 좌표와 원본 설정도 수정했다.

## 검증과 한계
실행 중인 도시 뷰어에서 근정전과 경회루의 전각 모델이 일반 건물 대신 표시되는 것을 확인했다. 정확한 외곽선 매칭, 다른 도시 제외, 원본 불변, 유효한 메시 좌표/색상에 회귀 검사를 추가했다.

현재는 세 전각을 연결한 1차 모델이며 실제와 동일한 복원이 아니다. 세부 높이·지붕 비례는 기존 양식화 모델의 추정이다. 충돌은 기존 건물 외곽선 기반의 단일 체적이라 광화문 홍예 통과 및 경회루 하부 기둥 사이 이동은 아직 지원하지 않는다. 원본 DEM은 유지하며 모델은 외곽선 내 최고 지형에 놓인다. 세부 기단 접지, 월대·회랑·흥례문·근정문·마당 포장 및 궁궐 나머지 전각은 후속 작업이다. 주변의 일반 평지붕/강조색 건물도 이번 세 모델의 대상이 아니다.

## 세부 외형 2차 보완
전용 생성기 `scripts/palace-refined.mjs`로 세 전각을 다시 구성했다. 근정전은 이중 월대·계단·석재 난간·분리된 중층 전각·창살·공포를, 광화문은 세 홍예와 석축 줄눈·중층 문루를, 경회루는 48개 석주(외곽 사각/내부 원형)·열린 상층·난간을 표현한다. 기와지붕은 단일 평면 대신 곡면을 분할하고 낮은 대비의 기와 줄을 정점색으로 표현한다. 정밀 단청 문양, 실제 석재 텍스처, 공포 결구의 실측 복원은 아니다. 배치/충돌 방식은 1차와 같으며 광화문 통과 충돌은 아직 단일 건물 체적이다.

경회루 석주의 형태와 수량 참고: [국사편찬위원회 우리역사넷](https://contents.history.go.kr/data/pdf/eh/eh_r0190_0010.pdf). 광화문 홍예 형식 참고: [정책브리핑 궁궐 정문 설명](https://www.korea.kr/news/issueQAView.do?newsId=148827428). 생성 모델은 자료를 참고한 게임용 해석이며 실측 치수 재현을 인증하지 않는다.

기단 아래는 건물 외곽선의 최저 지형까지 석재 받침을 연장해 떠 보이는 틈을 막는다. 이는 DEM 오차에 대응한 표현 보정이며 실제 기단 높이로 확정한 값이 아니다.

## 한국식 지붕 구분
근정전·경회루에는 합각 박공면이 있는 팔작, 광화문에는 박공면 없이 네 지붕면이 용마루로 이어지는 우진각을 적용한다. [궁능유적본부 지붕 설명](https://royal.khs.go.kr/ROYAL/contents/R311060000.do)을 기준으로 구분했다. 건물별 용마루 비율·처마 들림·곡률을 별도 설정한다. 겹처마의 서까래/부연을 두 줄로, 끝단 수막새를 원형으로, 추녀마루를 곡선을 따라 표현한다. 암키와/수키와의 전체 단면과 문양은 아직 생략됐으며 끝단 간격은 성능을 위해 단순화했다. 잡상은 단순화된 실루엣으로 실제 수량/조각의 복원이 아니다. 중국·일본 전체 건물에 새 양식을 적용한 것은 아니며 이번 수정은 경복궁 세 전각에 한정된다.
