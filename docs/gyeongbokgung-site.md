# 경복궁 전체 구역 표현 — 적용 범위와 정확도 한계

2026-09-13. 현재 남아 있거나 복원된 경복궁을 대상으로 한다. 조선시대 특정 연도의 원형 복원이나 전체 실측 복원을 완료한 결과는 아니다.

## 근거 자료
- [궁능유적본부 경복궁 이야기](https://royal.khs.go.kr/ROYAL/contents/R101020000.do?bdProgramCode=storyCtg3&pageType=story&schBdcode=gbg): 주요 영역과 전각 확인.
- [궁능유적본부 관람코스](https://royal.khs.go.kr/ROYAL/contents/R701000000.do?schGroupCode=gbg): 현행 관람 범위 참고.
- [궁능유적본부 지붕 설명](https://royal.khs.go.kr/ROYAL/contents/R311060000.do): 근정전 팔작, 광화문 우진각, 향원정 육모 구분.
- [OSM 경복궁 경계](https://www.openstreetmap.org/relation/5501517), [경회지](https://www.openstreetmap.org/relation/4005465), [향원지](https://www.openstreetmap.org/relation/13407146): 경계·위치·외곽선.
- OpenStreetMap contributors, ODbL. 배치 스냅샷의 출처와 SHA-256은 `src/world/cities/gyeongbokgung-site.json`에 기록했다. 원본은 `build/gyeongbokgung-complex.osm`이다.

## 적용한 내용
- 원본 전통 건물 후보 160개 중 152개가 기존 타일 외곽선에 대응한다. 근정전·광화문·경회루의 세부 모델을 유지하고 다른 전각·행각·회랑에는 원본 평면을 따르는 벽체와 기와색 지붕을 적용했다. 안뜰 구멍이 있는 원본 관계형 건물은 렌더링에서 구멍을 유지한다.
- 기존 지도와 대응되지 않는 건물은 별도로 분류했다. 기존 건물과 경계 상자가 겹치지 않는 이름 있는 누락 건물 2개만 추가했다. 원본과 대응되지 않는 기존 6개 평면은 현재 타일을 유지하고 일반 궁궐 지붕을 입힌 추정 표현이다.
- 향원정은 지도상의 육각 평면을 사용해 두 층의 열린 정자와 육모지붕으로 표현한다. 높이는 실측값이 아니다.
- 연못 2개는 섬 구멍을 보존하고 수평 수면을 추가했다. 지도 보행로 345개 구간과 그중 교량 태그 10개 구간에 경로/교량 표현을 적용한다. 한 개의 실제 다리가 여러 way로 나뉠 수 있어 10개의 다리라는 뜻은 아니다.
- 담장 63개 원본 선형을 따라 벽체와 어두운 지붕 덮개를 표현했다. 담장 높이 미상은 2.5m 추정이다.
- 지면 분류 면 139개로 흙바닥·녹지·숲을 구분했다. 원본 수목 노드 53개와 숲 영역 안의 절차적 보충 수목을 사용한다. 보충 수목은 건물·연못·보행로를 피하며 위치와 수종은 실제 개별 나무의 복원이 아니다.
- 현대 박물관 면 3개와 복원 공사 면 1개를 전통 전각 일괄 변환에서 제외했다. 궁 안의 현대 건물이 랜드마크라는 이유로 황금색이 되던 표현도 일반 건물 색으로 바꿨다.
- 궁 안 지형은 기존 32m DEM의 남북 150m 구간별 중앙값을 연결해 완화한다. 경계 24m 구간에서 원본으로 연결하며 현대 건물·공사 영역은 원본을 보존한다. 연못 주변은 수평 수면에 맞추는 추정 보정이다. 모든 청크에서 같은 절대 좌표 계산을 사용해 경계 단차를 방지했다.

## 아직 정확히 재현하지 못한 부분
1. 주요 세 전각 외 건물의 개별 지붕, 단청, 창호, 칸수, 높이, 지붕 결구는 공통 추정 표현이다. 건물 전체를 고증 완료로 표시하지 않는다.
2. 흥례문·흥복전 등 원본과 배포 타일이 다른 곳은 중첩 가능성 때문에 새 평면을 무조건 덮어쓰지 않았다. 외곽선 이력과 실제 도면 대조가 필요하다.
3. 문 아래 통과와 회랑 안뜰의 충돌은 기존 건물 전체 체적을 사용하는 부분이 남아 있다. 새 교량도 시각 표현이며 독립적인 교량 보행면 충돌은 아직 없다.
4. 수면 높이, 실제 경사·석축·계단, 포장 재질의 정확한 범위, 개별 나무 위치·수종은 측량/현장 자료로 검증되지 않았다.
5. 섬·숲·행각을 포함한 배치 원본을 사용했으나 공식 도면을 지리 좌표에 정합한 전수 오차 측정은 미완료다. 따라서 “현실과 동일”이나 정확도 백분율을 주장할 수 없다.

## 재현
원본 지도 XML을 위 출처에서 확보한 후 `python3 scripts/build-palace-site.py`로 스냅샷을 만든다. 원본 관계 경계가 불완전하면 실패하며 임의의 사각형 경계를 만들지 않는다. `node scripts/audit-palace-site.mjs`는 4개 청크의 적용 수량을 `build/palace-site-coverage.json`에 기록한다. 게임과 도시 뷰어는 공통 로더를 통해 같은 보정/메시를 사용한다.

## 검증 기록
- 타입 검사 통과.
- 전체 테스트 1,766개 통과 (`--maxWorkers=4 --testTimeout=30000`). 기본 제한 시간에서는 기존 차원도약의 지면 위 착지 시뮬레이션 1건이 실패했고, 해당 파일 단독 재검사와 제한 시간을 늘린 전체 재검사에서 모두 통과했다. 검증 조건을 바꾸었으며 기본 설정 전체 검사가 통과한 것으로 간주하지 않는다.
- 도시 뷰어의 남쪽 전체 조망과 북쪽 향원지 조망에서 건물, 수면, 숲, 회랑 배치를 시각 확인했다. 실측 도면과의 전수 일치 검증은 아니다.
