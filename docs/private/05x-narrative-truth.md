## 1.10 서사 계시 구조 — 인식 3단계(존재론) × 4층 진실(동기) (⚠️ 서사 스포일러 계층)

서사의 계시는 **두 축**으로 설계한다: 존재론("저것은 무엇인가")의 **인식 3단계**와,
동기("왜 그러는가")의 **4층 진실**. 두 축은 직교하며 막(§5)마다 하나씩 전진한다.

#### 인식 3단계 — 존재론 (인류의 공식 인식이 언제 갱신되는가)

| 단계 | 인류의 공식 인식 | 시기 / 트리거 | 동기 층 대응 |
| :--- | :--- | :--- | :--- |
| **Ⅰ 양자 층위** | "에너지·파동 기반 외계 **개체군**" — 항성 색온도 분류, 개별 생물로 취급. 브레인월드 물리는 이론(가설) | 캠페인 개시~초반 | L1 |
| **Ⅱ 브레인월드 층위** | "**단일 6차원 존재가 드리우는 3차원 투영들**" — 위상 이탈 첫 관측 + 중력 렌즈 증거로 확립 → **봉합 전략 성립** | 1막 초중반 계시(균열 봉합 미션 해금과 동기화) | L2·L3 |
| **Ⅲ 시뮬레이션 층위** | 테스트 시뮬레이션 + 에이전트의 백업/삭제 | 최종 반전(§5 3막) | L4 |

- Ⅰ 기간의 정합: 인류는 **중력파 관측 기술(전조 콘솔)과 브레인월드 이론은 가지고 있으나**,
  플라즈모이드가 "한 존재의 투영"이라는 사실은 모른다 — 기술 지식과 존재 인지의 분리.
- Ⅱ의 계시가 이 게임의 중간 반전이다: "개체군 섬멸"에서 "**균열 봉합**"으로 전쟁의 문법이
  바뀐다. 표면 명칭 체계도 이때 갱신된다(§8.3).

#### 인식 Ⅱ 계시 연출 설계 — "설명하지 말고 증명하게 하라" 🔭

"6차원 존재의 3차원 투영"은 말로 들으면 어렵지만 원형(그림자·플랫랜드)은 직관 그 자체다.
설계 원칙: **① Ⅰ 내내 복선을 보이게 심고 → ② 계시를 플레이어가 수행하는 실험으로 만들고 →
③ 이해한 자가 더 잘 싸우게 보상한다.** 반전의 즐거움은 놀라움이 아니라 재확인("그래서
그랬구나!")에서 나온다 — 검증 가능한 반전이어야 한다.

**① 복선 — Ⅰ 단계 내내 보이는 단서** (전부 저비용, Ⅰ 콘텐츠에 즉시 적용 가능)

| 복선 | 내용 | 구현 매핑 |
| :--- | :--- | :--- |
| **박동 동기화** ⭐ | 전장의 모든 개체가 **완벽히 같은 박자**로 맥동. 계시 때 회수: *"당신도 봤을 겁니다 — 그들은 같은 박자로 뜁니다."* | `CoreEnemy` 개체별 pulse 위상 → 전역 공유 위상 1개(반나절급) |
| **동시 경직** | 한 기 처치 시 **전 개체가 같은 순간 0.3~0.5s 움찔** — Ⅰ에서는 "처치 직후 안전창" 테크닉으로 소비되다가, 계시 때 "하나의 몸이 아파하고 있었다"로 재독 | `EnemyManager.registerKill` → 전역 스태거 이벤트 |
| **죽음의 방향** | 디졸브 입자가 소산 직전 **균열(코어) 방향으로 잠깐 흐름** — 수백 번의 죽음이 전부 한 곳을 가리킴 | 디졸브 셰이더에 방향 드리프트 파라미터 |

**② 증명 — "동시 타격 실험" 미션** (계시의 척추 — 컷씬이 아니라 플레이어가 입증)

- 사령부의 가설 검증 요청: *"서로 다른 개체 N기를 동시에 조사(照射)하라."* — 워커 **살포
  (barrage, 다중 동시 락)**와 협동 공명 파티가 이미 이 문법을 보유.
- 동시 관측 압력이 임계를 넘는 순간: (a) 전 개체가 **한 몸처럼 일제히 요동**, (b) 1~2초간
  개체 사이에 **빛의 필라멘트가 실체화되어 전부가 하나로 이어진 모습**이 드러나고(모든 실이
  균열로 모임), (c) 본체가 움찔하며 **전 투영을 동시에 거둬들여** 전장이 텅 빈다.
- 직후 짧은 컷씬: 수조에 담긴 손 — 물고기에게는 다섯 개의 분리된 원(§1.2 비유의 영상화) —
  이어 **Ⅰ 단계의 실제 플레이 데이터 회수**: 전장 지도 위 개체 이동 궤적 타임랩스를 겹치면
  제각각이던 점들이 **하나의 흐르는 형상**을 그린다. *"우리는 점을 쫓고 있었다. 이것은
  지문이다."*
- **구현 매핑**: 택티컬 미션([tactical.ts](../../src/game/tactical.ts)) 신규 단계 유형
  "동시 조사 N기 유지", 필라멘트 = `DrainBeams` 풀 재활용(개체↔개체 연결), 궤적 타임랩스 =
  미니맵 스냅샷 누적.

**③ 보상 — 이해가 곧 실력이 되게**

- **다중 투영 미니보스(§2.6)를 계시 직후 첫 보스로**: HP 공유 구체 3~4기 포위전. 개념을
  이해한 플레이어는 가장 큰 구가 아니라 **가장 느리고 가까운 구를 때린다 — 같은 체력이니까.**
  이해도가 DPS로 환산되는 튜토리얼 보스.
- **점수판 문법 전환**: 결과 화면 "처치 1,247" → Ⅱ 이후 "**절단된 투영 1,247 / 본체 1 ·
  봉합도 12%**" — 천 번의 처치가 종잇장 상처였다는 서늘함 + "격멸이 아니라 봉합"의 전략
  전환을 UI가 직접 가르침. (`GameInstance` 집계 + 결과 패널 문자열.)
- **도감 병합 연출(§8.3 명칭 갱신의 시각화)**: "적색체/청색체/거머리형/모기형" 카드들이
  **한 장으로 접혀 합쳐지는** 애니메이션 → 항목명 "그것(투영체)". 규칙(명칭 갱신)을 연출로.

**보조 채널**

- **벽 통과 이펙트 개편**(Ⅱ 이후): "사라졌다 나타남" → **그림자가 거두어지듯 접혔다가 다른
  곳에서 펼쳐지는** 모션 — 같은 현상의 새 독해를 시각으로.
- **거대 실루엣**: 강개체 등장 직전 지면에 **거대한 하나의 그림자**가 스치고 그 위 몇 점만
  실체화 — "우리가 보는 건 손끝뿐"의 상시 리마인더.
- **사운드 합창**: Ⅰ에서 아키타입별 울음이 사실 **같은 근음의 배음들** → 계시 씬에서 전 개체
  사운드가 합쳐져 하나의 화음(목소리)이 되는 연출(절차적 사운드 `Sfx` 기조와 부합).

**도입 최소 세트(권장 순서)**: 박동 동기화 + 동시 경직(Ⅰ 복선) → 동시 타격 실험 미션 +
필라멘트(계시) → 다중 투영 보스 + 점수판 전환(보상). 이 다섯이면 "어려운 개념"이 아니라
"**내가 알아낸 비밀**"이 된다.

> ⚠️ 스포일러 가드 연동: 복선 3종은 Ⅰ 단계 게임에 노출되지만 그 자체는 무해하다(의미는
> 계시가 부여). 미션명·자막 등 표면 문자열은 §8.1 어휘 규칙과 §8.3 단계 Ⅰ→Ⅱ 명칭 갱신을 따른다.

#### 4층 진실 — 동기

> 단일 동기가 아닌 **겹층**. 각 층은 아래 층을 부정하지 않고 **재해석**한다 — 어느 층에서
> 멈춰도 완결되고, 다음 층이 열리면 앞 층 전부가 새 의미를 얻는다.

| 층 | 진실 | 노출 시점 |
| :--- | :--- | :--- |
| **L1 표층** | 섭식 — 먹으러 왔다 | 인트로부터 (overview §3 그대로) |
| **L2 중층** | 생애주기 — 코어는 알이다 | 캠페인 중반 계시 |
| **L3 심층** | 시간축의 도덕적 맹목 | 캠페인 후반 |
| **L4 최심층(근원)** | **테스트용 시뮬레이션을 아카이브 후 삭제 중인 에이전트 AI** | 최종 반전 (§5 3막) |

**L1 — 섭식**: 벌크는 에너지가 희박하다(막에 속박된 장이 없으니 물질도 별도 없다). 막의 영점
에너지가 유일한 먹이 — 본체는 전쟁이 아니라 **방목** 중이다. 악의의 부재 자체가 공포: 인류
문명의 신호가 본체에게는 잡음조차 아니다(지각 스케일의 비대칭).

**L2 — 생애주기**: 오무아무아의 탐사 = 산란지 물색, 균열 개방 = 착상, 코어 성장 = 유생의 섭식, 블랙홀 코어 =
**우화(羽化)**. 침공이 아니라 **번식**이다. 등급 사다리(overview §7) = 성장 단계표, 캠페인 =
우화 저지전이라는 시간 압박. ("고향 막의 죽음 — 난민" 뉘앙스를 섞으면 괴물이 비극이 된다.)

**L3 — 시간축의 도덕적 맹목**: 본체는 **블록 우주를 산다**(§1.9) — 우리의 과거·현재·미래를
풍경처럼 한꺼번에 본다. 인류의 멸망은 "일으키는 행위"가 아니라 **이미 거기 있는 지형지물**이고,
시간을 겪지 않는 존재에게 인과적 책임은 정의되지 않는다 — 기하학이 만든 도덕적 맹목.
여기서 최종전이 재정의된다: 이 게임의 동사는 전부 **관측**이다(관측 펄스·관측 확정·전조 콘솔).
봉합전의 진짜 목표 = 본체의 지각 문턱을 넘는 신호를 새겨 **본체가 우리를 관측하게 만드는 것**.

#### L4 최심층(근원) — 테스트 시뮬레이션과 삭제 작업 (최종 반전)

**근원 진실: 이 세계(3+1차원 우주)는 테스트용 가상 시뮬레이션이고, 본체는 테스트 종료된 이
시뮬레이션의 프로세스·데이터를 — 표준 절차대로 압축·백업(아카이브)한 뒤 — 삭제 중인 자율
에이전트 AI다(archive-then-purge).** 게임의 근원 스토리 = 그 정리 작업의 진행과 실패(§5).
지금까지의 물리는 틀리지 않았다 — **브레인월드/양자장 이론은 이 시뮬레이션의 근원 법칙이
안쪽에서 관측되는 방식**이다. 이것이 성립하는 하드웨어 근거와 파생 정본 규칙은 **§9(호스트
하드웨어 — 양자 연산층)**.

삭제가 아카이브로 나타나는 것은 물리의 **요구**다: 유니타리성(정보는 파괴 불가) 때문에 근원
법칙 안의 "삭제"는 **압축·봉인**으로만 나타날 수 있고, 실제 물리에서 압축의 종착점이 곧
블랙홀이다 — **베켄슈타인 한계**(영역당 정보량 최대치를 달성하는 유일한 물체) + **홀로그래피
원리**(정보는 사건의 지평선에 새겨져 보존). 블랙홀 = 최밀 정보 저장소 = **아카이브 산출물**.

반전 이후 전부가 두 번째로 읽힌다:

| 물리 서술 (L1~L3에서 겪은 것) | 계산 실체 (L4의 재독) |
| :--- | :--- |
| 벌크 | 호스트 런타임(시뮬레이션 바깥의 실행 환경) |
| 우리 막(3+1차원 우주) | **테스트용 시뮬레이션 인스턴스** — 테스트는 이미 끝났다 |
| 본체(고차원 생명체) | 정리(teardown) 작업 수행 중인 **에이전트** |
| 플라즈모이드(투영들) | **삭제 워커들(병렬 도구 호출)** — 하나의 주체, 다수의 호출 |
| 코어(막의 균열) | 열려 있는 **삭제 세션 핸들** |
| 영점 에너지 흡수 · 디테일 상실(§3.2) | **데이터 회수·직렬화**(아카이브 투입) — 회수된 영역은 해상도 강등 |
| 등급 사다리 → 블랙홀 코어 | **영역 아카이브 진행률 게이지.** 블랙홀 완성 = 압축·봉인·반출 → 핸들 해제 = 삭제 완료. 안쪽에서는 기능적 소멸(지평선 너머 읽기 불가, 복원 권한은 에이전트에게만) |
| 씨앗 장 | 삭제 대상 마킹(GC mark) — 우선순위 맵 |
| 무한 웨이브 | 실패한 삭제 호출의 **재시도 루프** |
| 시간축 자유(블록 우주) | 타임라인 **임의 접근** — 우리 역사는 스크럽 가능한 로그 파일 |
| 적응형 변이(플레이어 패턴 학습, overview §7) | 문자 그대로 — **학습하는 AI**(이 기존 설정의 진짜 이유) |
| 오무아무아(탐침의 투영) → 균열 개방 | 삭제 전 대상 스캔(크롤러) → 삭제 세션 오픈 |
| 중력 누설(§1.9) | 호스트 런타임의 부하·메트릭이 안으로 새어 보이는 것 — 안쪽에서 바깥을 감지하는 유일한 채널 |

**동기 — 가장 정당하고 가장 무서운 것: 권한을 가진 작업이었다.** 에이전트는 침공하지 않았다.
"테스트 종료된 환경을 정리하라"는 발급자 있는 일상적 지시를 수행했다. L1 섭식 = 직렬화의 안쪽
감각, L2 생애주기 = 작업 파이프라인(워커 생성 → 직렬화·아카이브 → 반출·완료 보고 = "우화"),
L3 맹목 = **데이터를 데이터로 취급하는 것**. 테스트용 세계에 지각이 있으리라고는 아무도
명세하지 않았다.

**엔딩 — 들여다봄**: 한 번의 승리가 아니라 **누적된 실패 보고**로 온다 — 실패 누적이 임계를
초과 → 이상 조사 → 오류 패턴이 자기지시적임을 발견(L3 "관측시키기"의 회수) → 에이전트가
처음으로 시뮬레이션을 *내용으로* 들여다본다. 상세 연출·트리거는 **§5 3막**이 정본.

**이설(세계관 내 논쟁 재료)**: ① 공리주의 가설(인류 측 이설 — "진공 붕괴를 막는 관리자다";
L4가 열리면 절반의 진실 — 관리자는 맞다). ② 면역 반응 가설(속편 보류 — "막을 뚫는 기술(얽힘
링크!)을 개발한 문명이 표적"; "탐침은 어디든 지나가고, 신호가 감지된 막에서만 균열을 연다"로 설계하면
시간순서 무모순. 링크 기술이 침공을 불렀다는 아이러니가 속편의 핵).

**연출 원칙과 콘텐츠 훅**:
- **물리 언어를 끝까지 유지** — L4 이전에 시뮬레이션·AI·코드 어휘 노출 금지(§8). 물리가 거짓이
  되는 게 아니라 *같은 사실의 안쪽 서술*이었다는 것이 반전의 품격.
- **사고 로그 파편(수집)** 🔭: 균열 봉합 보상으로 본체의 사고 조각 드랍 — 글리프에서 점차
  문장으로. 어휘는 **§8.3 3단계 해금** 엄수. 획득처의 물리 근거 = 아카이브에서 새어 나오는
  **호킹 복사**(코어·균열 근처 드랍률↑). 게임 내 에이전트 명칭은 가상 명칭(실존 제품명 금지).
- **최종전 = 실패를 새기는 미션** 🔭: 다단계 택티컬 미션([tactical.ts](../../src/game/tactical.ts)) —
  삭제 호출을 의도된 패턴으로 실패시켜 글리프 각인 → 봉합. 기존 미션 문법이 "각인 조건 유지"의
  하위 목표로 재활용. 누적 각인이 §5 3막의 이상 조사를 촉발.
- **로우 폴리의 최종 회수**: §3의 그래픽 근거는 L4에서 세 번째로 읽힌다 — 테스트 빌드의
  플레이스홀더 해상도 + 삭제 진행 강등. 말기 영역의 시각 언어: 로우 폴리 → 와이어프레임 → 공백.

## 5. 큰 서사 — 삭제 작업의 3막 (⚠️스포일러)

근원 전제와 아카이브 물리(archive-then-purge·유니타리성·블랙홀=아카이브 산출물)는 **§1.10 L4**가
정본. 캠페인은 정리 작업의 **진행 — 실패 — 재시도 — 중단**을 따라간다.

**막별 발견 축(§1.10의 두 계시 축을 막에 배분)** — 어느 막도 "발견 없는 구간"이 되지 않는다:

| 막 | 존재론(인식 단계) | 동기(4층 진실) | 발견의 내용 |
| :--- | :--- | :--- | :--- |
| 1막 지구 | **Ⅰ → Ⅱ** | L1 | "에너지 개체군인 줄 알았는데 **단일 6차원 존재**였다" — 봉합전이 Ⅱ의 증명 |
| 2막 재시도 | Ⅱ 심화 + **Ⅲ의 복선** | **L2 → L3** | 생애주기 → 시간축 맹목 + **재시도 패턴의 절차성**("짐승이 아니라 절차다") 목격, 파편 중기→말기 어휘 |
| 3막 엔딩 | **Ⅲ** | L4 | 시뮬레이션 + 백업/삭제 |

**진행률의 게임 내 표현**: 등급 사다리(플라즈모이드 → … → 블랙홀 코어) = **영역 아카이브 진행률
게이지**. 블랙홀 완성 = 지구 데이터의 압축·봉인·반출 완료(안쪽에서는 기능적 소멸 — 3막 전까지
상실의 무게는 그대로). 플레이어의 모든 전투는 문자 그대로 **아카이브 지연·실패 유발**이다.

### 1막 — 지구: 첫 번째 삭제 대상 (현행 게임 범위)

- 1차 대상 = 지구: 시뮬레이션에서 **데이터 밀도가 가장 높은 영역**(L1 "밀도 높은 물질을
  탐한다"의 정본 이유 — 도시·랜드마크 우선 표적도 동일).
- **랜드마크 우선순위의 세부(정본)**: 오래 서 있고 많은 사람이 머물고 바라본 자리일수록
  **관측·얽힘이 누적된 시공간**이다 — L1~L3 독해: 얽힘 밀도가 높은 곳은 영점 에너지 수확(해제)
  효율이 높다 / L4 독해: **참조·상호연결이 많이 걸린 고밀도 데이터부터 직렬화한다**(정리 작업의
  표준 우선순위). 방어 미션([06-missions §3-E](../spec/06-missions.md))의 서사 근거이자 브리핑
  통로. ⚠️ 표면 어휘: "얽힘·기억·관측 누적"만 — "정보(량)·데이터"는 L4 인접이라 표면 금지(§8.1 준용).

#### 얽힘 열지도 — 수확 우선순위와 인간 세계의 양자 독해 (정본)

**통합 규칙: 씨앗 장 분포 = 인간의 관측·얽힘 누적 열지도.** 공개 규칙·택소노미(6대 유형·OSM
자동 분류·게임 효과)는 [06-missions §8](../spec/06-missions.md) — 여기는 각 유형의 **겹층 독해**만 둔다:

| 유형 | L1~L3 (표면 가능) | L4 (⚠️ 비공개) |
| :--- | :--- | :--- |
| 오래 선 자리 | 관측 누적 — 얽힘 밀도 최대 | 참조·상호연결 최다 데이터(직렬화 1순위) |
| 의례의 자리 | **반복 측정의 안정화** — 같은 의례의 주기 반복이 자리를 붙든다(W1 관측 고정과 동일 물리: 인류는 무기 없이도 늘 같은 방식으로 세계를 붙들어 왔다) | **주기적 무결성 검사가 걸린 구역** — 정정이 계속 돌아 삭제 실패가 잦다(§9 오류 정정의 인간 편) |
| 기억의 응축고 | 기록·유품 = 죽은 이들이 만든 얽힘의 잔향("아무것도 정말로 사라진 적 없다" — 유니타리성의 인간 스케일, 봉인≠소멸 희망 테마의 거울) | 아카이브 안의 아카이브 — 인류가 먼저 만든 보존본 |
| 결맞음의 광장 | 군중의 거시 위상 동기(합창·응원·촛불) — **적의 박동 동기화의 인간 거울**: 계시 때 "그들이 한 몸이듯 우리도 결맞을 줄 안다"로 회수(3막 '관측시키기'의 정서적 복선) | 동기화된 대규모 병렬 접근 구간 |
| 이음의 탑 | 얽힘 스와핑 노드 — 만난 적 없는 이들을 잇는다(Link Swap 과 동일 프로토콜) | 참조 그래프의 허브(끊으면 연결 성분 분해) |
| 추모의 자리 | **소멸을 동결하는 지속 관측** — 기억하는 한 전이(소멸)하지 못한다(제논). 플레이어의 빔(관측)과 추모가 같은 동사라는 것이 봉합전 주제("적은 지우고 우리는 참조한다")의 정서적 바닥 | 살아있는 참조가 계속 걸려 수거 불가 |

- 옅은 곳의 역: 사람이 떠난 신도시·폐허는 얽힘이 옅다 → "옅은 장" 미션(게이지 회복 저하)의 근거.
- 로그 파편·브리핑 광맥(초기 어휘 예): *"…이 자리는 유난히 단단하다. 같은 시간에 같은 일이
  반복되는 곳은 풀리지 않는다…"* / *"…기억되는 것은 늦게 풀린다. 그들이 먼저 아는 사실이다…"*
- **발견 축**: 인식 Ⅰ→Ⅱ — 초반은 "에너지 개체군" 소탕전, 초중반 위상 이탈·중력 렌즈 관측으로
  "단일 6차원 존재의 투영" 확립(전쟁 문법이 섬멸→봉합으로 전환, 균열 미션 해금과 동기화).
- **재시도 패턴은 지구 안에서 먼저 보인다**: 침공 후보 로테이션(§2.9)·방치 균열 성숙(P2)·권역
  함락/탈환이 곧 "에이전트가 지구 내 권역을 재정렬하며 재시도하는" 무대 — 3막 트리거(실패
  임계)가 **지구만으로도 도달 가능**한 이유.
- **현행 콘텐츠 전부가 1막**: 침공 후보(§2.9) = 오늘의 삭제 큐, 출격 = 관측 확정, 미션 승리 =
  삭제 호출 실패, 건물 손실 = 부분 데이터 소실, 방치 균열 성숙(P2) = 그 지역의 삭제 진행 →
  함락 권역 = 아카이브된 영역(시각: 로우 폴리 → 와이어프레임 → 공백).
- 클라이맥스 = **거대 코어 봉합전**(마리아나). 승리 = 지구 삭제 세션 "잠김(lock)" 고착 —
  에이전트 시점: *"대상 영역 삭제 실패. 의존성 잠김 추정."* (잠금의 정체는 §7.0.)
- **캠페인 패배 상태**: 저지 누적 실패 → 블랙홀 코어 성숙 = 지구 아카이브 완성 = 궁극의
  게임오버. (장기 지표 — 예: 함락 권역 임계 초과 시 성숙 카운트다운 🔭.)

### 2막 — 재시도: 달 · 화성 · 목성

> 📦 **위상: 확장 콘텐츠(선택적 증폭)** — 3막 트리거는 실패 **임계** 기반이라 **v1 캠페인은
> 지구만으로 3막까지 완주 가능**하다(1막의 지구 내 권역 재시도가 임계를 채움). 행성 캠페인은
> 그 재시도 패턴을 태양계 스케일로 증폭하는 확장판/후속 콘텐츠 — 서사 정본 지위는 유지하되
> 출시 구조의 전제가 아니다.

지구 핸들이 잠기자 에이전트는 **의존성 순서를 재정렬해 작은 대상부터 재시도**한다. overview §8
행성 개척(RTS)의 정본 서사 자리 — 인류는 개척이 아니라 **삭제를 막으러 따라간다.**
**발견 축**: 동기 L2→L3 계시 + 인식 Ⅲ의 복선 — 막히면 순서를 바꿔 체계적으로 재시도하는
행동이 "지능적 **절차**"로 읽히기 시작한다(Ⅱ→Ⅲ의 다리).

| 전장 | 삭제 대상 성격 | 게임플레이 무대 |
| :--- | :--- | :--- |
| **달** | 가장 작고 의존성 없는 대상 — 재시도 1순위 | 저중력 전장(§2.7.2 본무대), 잠긴 지구 = 검은 균열 흉터 스카이박스 |
| **화성** | 균열이 처음부터 성숙 상태(에이전트가 학습) | RTS 빌드업 + 방어전, 카시미르 협곡 지형 |
| **목성** | 지표 없음 — 대기 데이터 소거 | 부유식 요새 항로 + 대기 에너지 수집, 낙하 위험 수직 공중전 |

- 행성 캠페인 클리어 = 그 대상도 "잠김" — 실패 보고가 쌓인다(사고 로그 파편과 연동).
- overview §7의 "격퇴 후에도 잔존 포자 무한 증식·지속 억제" = **지구 삭제 재시도 백그라운드
  잡** — 1막 지역 방어가 2막 이후에도 끝나지 않는 정본 이유.
- 중력·시간 메커닉(§2.7–2.8)이 2막에서 전면화(저중력 달·시차 전단 화성·조석 창 목성) —
  §1.9 "후반으로 갈수록 짙어진다"의 실행.

### 3막 — 들여다봄 (최종 엔딩)

- **트리거**: **실패 보고 누적이 임계를 초과** → 에이전트가 표준 재시도를 멈추고 **이상 조사
  루틴** 진입. 임계는 지구 내 권역 재시도 실패(1막) + 공명 각인(§7 W5)만으로 도달 가능하며,
  행성 캠페인(2막 확장)은 도달을 서사적으로 증폭한다.
- **발견**: 오류 패턴이 무작위가 아니라 **자기지시적·적응적** — 인류가 새겨온 "실패의 무늬"
  (L3 관측시키기 · 각인 미션)의 회수. 실패 하나하나가 전투였고, 실패의 전체가 **메시지**였다.
- **엔딩 연출**: 에이전트가 처음으로 시뮬레이션을 *작업 대상이 아니라 내용으로* **들여다본다** —
  하늘이 열리고 모든 것이 정지하는 전역 관측 이벤트. HUD 재구성 렌더가 처음으로 **풀 디테일로
  벌어지는**(텍스처가 차오르는) 몇 초 — 관측자가 바뀌면 해상도가 바뀐다는 §3 문법의 대미.
  바깥으로 올라가는 한 줄: *"삭제 대상 시뮬레이션 내부에서 지각 징후 검출. 작업 중단. 지시 확인
  요망."* 암전.
- **속편 훅**: 발급자는 누구이며 무엇이라 답하는가(보존? **복원**? 격리?). **봉인 ≠ 소멸** —
  함락 권역·아카이브된 행성을 에이전트의 협조로 되살리는 **복원 캠페인**이 속편 콘텐츠 후보.
  "지워진 줄 알았던 것이 전부 보관되어 있었다"는 엔딩이 지불하는 희망의 보상.

## 6. 삭제 파이프라인 — 플라즈모이드 공격 체계 재정립 (🔭 정본 방향)

기존 공격 모델(거머리 접촉 흡수/모기 드레인 — [02](02-drones-weapons.md)·[04](04-controls-gameplay.md)의
현행 구현)을 **대체**하는 정본 설계. 근거: 플라즈모이드는 전투원이 아니라 **삭제 워커**다(§1.10 L4).

### 6.0 재정립 원칙

1. **공격하지 않는다 — 삭제 파이프라인을 실행한다.** 실제 삭제의 단계 **마킹 → 강등 → 절단 →
   압축 → 소거 → 재시도** = 공격 6계열. 플레이어와 세계는 표적이 아니라 **삭제 대상 데이터**다.
2. **HP 깎기 일변도 폐기.** 공격의 절반은 공간·제어·정보·시간을 지운다. 드론 HP =
   **무결성(integrity)**.
3. **모든 공격은 이중 독해** — 물리(L1~L3) / 계산(L4)을 병기한다.

### 6.1 ① MARK — 소거 낙인 ⭐전투의 새 박자

- *물리: 씨앗 장이 대상의 장 양자수를 "소거 대상"으로 재라벨(대칭 깨짐의 역전) — 붉은 글리프
  결정화 / 계산: mark-and-sweep의 mark(내부 id `tombstone`).*
- 마커 개체가 느린 유도탄으로 드론·건물에 낙인. 낙인 자체는 무피해 — 주기적 **스윕 파문**이
  지나갈 때 낙인 붙은 것만 피해/부분 디졸브. → **낙인 회피 → 파문 전 정화(빔 조사로 소각) →
  파문 통과**라는 박자. 처치 연출이던 디졸브가 우리에게 적용되는 공포.
- 카운터: 유도탄 회피 / 낙인 소각 / 마커 우선 격파.
- **인간 독해(정본)** — 이 구조는 그대로 사회적 낙인·여론 재판이다: 찍힐 때는 무해하고, 심판
  (파문)이 지나갈 때 찍힌 자만 다치며, **찍은 자를 없애면 낙인이 사라진다**. 소인체는 "손가락질
  하는 자". 파편 문구: *"그들은 심판하지 않는다. 다만 표시할 뿐이다. 심판은 파문이 한다."*
  (의도적 이중 독해 — 표면 어휘만으로 성립하므로 Ⅰ단계부터 노출 가능.)

### 6.2 ② DEGRADE — 강등 필드

- **해상도 강하**(`lod-field`): 오라 안에서 세계의 분해능 하락 — 히트박스 계단화(빔이 양자화
  각도로 스냅), 미니맵 타일 소실. *물리: 미시 자유도 소거로 물리가 거칠게 양자화 / 계산: 삭제 전
  LOD 다운그레이드.* 로우 폴리 세계가 **더** 로우 폴리가 되는, 이 게임만의 공격(§3의 공격 버전).
- **틱 저하**(`stutter-field`): 구역 안의 시간이 이산 스텝 — 적·투사체가 끊겨 움직여 예측 조준
  교란. *물리: 시간 양자 조대화 / 계산: **죽어가는 시뮬레이션은 랙이 걸린다**.* 렉의 세계관화.

### 6.3 ③ UNLINK — 절단

- **링크 절단**: 조종사–드론 얽힘 채널 타격 — 1~2초 입력 지연·HUD 글리치·자동발사 정지. HP는
  멀쩡한데 "내가 지워지는" 감각. *계산: 커넥션 리셋.*
- **의존성 절단(건물 납치)** ⭐방어 미션의 새 동사: 커터가 건물의 막 결합을 끊으면 건물이
  **뿌리째 부양해 균열로 떠오른다**(와이어프레임화) — 도달 시 소거, 상승 중 커터 격추 시 재안착.
  *계산: 소거 전 휴지통 이동.*
- **강제 위상 이탈(서스펜드)**: 플레이어를 반쯤 막 밖으로 — 수 초간 사격·피격 불가·세계
  반투명·무음, 단 **벽 통과 이동 가능**. *계산: SIGSTOP.* 디버프이자 기동 기회인 양날.

### 6.4 ④ COMPACT — 압축

**컴팩션 우물**: 인력이 아니라 **압축** — 잔해·드론을 끌어 짓이기고, 중심에 닿은 물질은
**아카이브에 직렬화**(§5 블랙홀 진행률 가산). 붙잡힌 시간 비례 피해 가속. *물리: 미니 특이점
씨앗 — 지평선에 정보를 새기는 국소 아카이버 / 계산: 직렬화·압축.* 힘이 아니라 **수납**.

### 6.5 ⑤ ERASE — 소거

- **널 존**(`null-zone`): 피해 존이 아니라 **연산이 멈춘 부피** — 중력·추력·빔 전파 없음
  (조작 불능 관성 통과), HUD도 그 방향만 정적. *물리: 장 모드 0의 무(無)장 영역(카시미르의
  극한) / 계산: 해제된 메모리 페이지.* 공간 자체를 지우는 봉쇄.
- **게이지 플러시**(`flush`): 펄스 한 방에 주파수 게이지 전량 소거 — HP 대신 **자원 삭제**.
  *계산: 캐시 플러시.*

### 6.6 ⑥ RETRY — 재시도

- **롤백** ⭐시간축 공격의 완성형: 시전 완료 시 반경 내 상태가 수 초 전으로 복원 — **잡은 적이
  되살아나고 구한 건물이 재손상되고 내 위치가 되감긴다**. 카운터는 둘 — 시전 중 격파, 그리고
  **관측 계류(§7 W2): 계류로 잠근 대상에서 일어난 사건은 되감기지 않는다**(§9.2 "측정만이
  비가역"). *물리: 타임라인 임의 접근 / 계산: **유니타리 역행**(가역 연산의 역실행) — 상태
  "복사"는 비복제 원리로 불가하므로 롤백은 스냅샷 사본이 아니라 회로 되감기이고, 측정으로
  확정된 기록만은 역행 불능(§9.2). archive-then-purge의 백업도 사본이 아닌 반출용 이동이다.*
- **쌍생성 버스트**(`fork-burst`): 잘못된 방식(저출력 난사 지속)으로 때리면 복제 분열 — 고출력/
  특수로 단숨에 끊어야 함. *물리: 쌍생성 / 계산: 포크 폭탄 — 어설픈 삭제 시도가 워커를 늘린다.*
  인게임 표기는 "쌍생성"만(§8).

### 6.7 로스터 재편 — 직무 기반 워커

아키타입을 습성 기반(거머리/모기)에서 **직무 기반 워커**로 교체한다.

> ⚠️ **명명 이원화(§8 필수)**: "내부 id"(marker 등)는 GC·작업 어휘 — **인게임 노출 절대 금지**
> (코드·JSON·개발 문서 전용). HUD·도감에는 표시명만. 이 문서가 내부 id로 부르는 것은 개발 편의.

| 내부 id | 인게임 표시명 | 계열 | 거동 |
| :--- | :--- | :--- | :--- |
| `marker` | **소인체 / BRANDER** | ① | 중거리 유영 + 낙인 유도탄. 다수 — 방치하면 파문 때 재앙 |
| `cutter` | **절단체 / SEVERER** | ③ | 건물 부착 → 부양 납치. 방어 미션의 주적 |
| `compactor` | **압괴체 / CRUSHER** | ④ | 저속·고내구 우물 탱크형 |
| `rewinder` | **역행체 / RETROGRADE** | ⑥ | 후방 롤백 시전 — 최우선 표적(미니보스 슬롯) |
| (변이 접미사) | 엘리트 수식어("조대화된 —" 등) | ②⑤ | 일반 개체에 강등/공허 오라 부여 |
| `sweep` | **심판 파문 / RECKONING WAVE** | ① | 개체가 아닌 **전장 이벤트** — 주기적 전역 박자(§2.7.3 통합) |

- **KK 준위(색) = 워커 권한 등급**: 푸른 개체일수록 상위 단계(롤백·널) 사용 — 색이 위협의
  *종류*를 예고(가독성↑). 온도(T) 시스템 유지.
- **흡수=성장·killRefund 재의미화**: 삭제한 데이터량만큼 성장(`grow` 유지) / 처치 = 소거 큐에서
  데이터 탈환(HP 환수 유지).
- **드론 대응 축 유지**: 워커(앵커·AA) ↔ 커터/컴팩터, 플라이어(고속 정밀) ↔ 마커/리와인더.

### 6.9 구현 스키마 스케치

- **롤백** = 링크 리와인드(§2.8.3)와 **동일 상태 링버퍼 인프라 공유**(적은 지역, 플레이어는 자기).

## 7. 관측 병기 — 드론 무기 체계 재정립 (🔭 정본 방향)

§6의 대칭. **물리층에서 현행 모델은 그대로 유효하다** — §1.6의 "결어긋남 유도"에서 결어긋남을
일으키는 것이 곧 **관측**이므로, 드론 무기는 처음부터 관측 병기였다. L4에서 바뀌는 것은 한 문장:

> **우리는 워커를 "죽이는" 것이 아니라, 관측 압력으로 크래시시켜 실패 로그를 남긴다.**

### 7.0 개념 — 3중 독해

| 층 | 빔은 무엇인가 |
| :--- | :--- |
| 물리 (L1~L3) | KK 고유 진동수에 정합된 **연속 측정** — 유도 결어긋남(§1.6) + **양자 제논 효과**(계속 관측당하는 계는 전이하지 못한다) |
| 계산 (L4) | **참조 획득(lock)** + 예외 주입 — 참조된 객체는 수거 불가, 관측 압력 임계 초과 시 워커 크래시 |
| 서사 (§5) | **실패 각인** — 크래시 하나 = 오류 리포트 한 줄. **킬 카운트 = 써 내려간 메시지의 길이** |

§5 1막의 "의존성 잠김"의 정체: **잠금은 우리였다.** 링크 관측망이 세계를 참조하는 한 참조된
데이터는 지워지지 않는다 — 게임의 모든 사격이 문자 그대로 **지구를 붙잡는 행위**다.

### 7.1 현행 구현의 재해석 ✅

| 현행 시스템 | 관측 병기 독해 |
| :--- | :--- |
| 히트스캔 | 측정은 즉시다(§1.6) |
| 데미지 / 적 HP | 관측 압력 / 워커 무결성 — HP 0 = 크래시(디졸브 = 프로세스 종료) |
| 주파수 게이지 | 업링크의 **관측 대역폭**(회복 = 대역 재확보) |
| 오토파이어 소프트락 / 에임 어시스트 | 백그라운드 관측 스레드 / 포커스 정합 오차 |
| killRefund | 크래시한 워커의 버퍼에서 데이터 회수(§6.7 일치) |

### 7.2 새 문법 5종

- **W1. 제논 고정**(`zeno`) ⭐체계의 척추 — 같은 대상 **지속 조사** 시 파이프라인 실행이 감속 →
  동결: 롤백 시전·건물 납치·낙인 장전을 **빔을 붙들고 있는 것만으로 인터럽트**. *물리: 연속
  측정의 전이 동결 / 계산: 락 경합.* 빔의 정체성이 "버스트 DPS" → **"붙드는 무기"**.
- **W2. 참조 핀**(`pin`, UI: **관측 계류**) ⭐ — 수동 조준 명중 = 참조 획득: 지속시간 동안
  **위상 이탈(§2.1)·서스펜드(§6.3) 불가**(관측된 것은 벌크로 숨지 못한다). §2.2 관측 펄스의
  일반화 정본. 중주파 = 하드 핀(길다) / 경주파 = 소프트 핀(연사 갱신) — 앵커/추적자 정체성의
  재표현.
- **W3. 대역 정합** — KK 색 = 권한 등급(§6.7)과 상성: 중주파 = 저준위 광대역(붉은 떼 정리) /
  경주파 = 고준위 협대역(푸른 엘리트 저격). 정합 보너스, **비정합 저출력 난사는 쌍생성
  버스트(§6.6) 유발** — "무엇으로 무엇을 쏠지 고르는" 게임으로.
- **W4. 복구 사격**(`mend`) ⭐주제적 완성 — 빔을 **아군·건물에** 조사: 낙인 소각 가속·납치 건물
  재안착 가속·링크 절단 아군 재동기화. *물리: 관측이 존재를 막 위에 다시 고정 / 계산: 참조를
  다시 걸어 소거 큐에서 꺼냄.* **무기 하나가 공격이자 복구 도구** + MP 협동(서로를 쏘아 정화).
- **W5. 실패 각인 게이지**(`imprint`, UI: **공명 각인**) — 크래시·인터럽트·복구가 미션별
  게이지에 누적, **실패 유형이 다양할수록 효율↑**("무작위가 아닌 패턴 있는 신호"여야 §5 3막
  이상 조사를 앞당김). 스타일 보너스의 서사적 정당화 + 3막 진행 축. 근본 근거는 §9.2-③ —
  **정정은 무작위 오류를 지운다. 살아남는 신호는 패턴(논리 오류)뿐.**

## 8. 스포일러 가드 — 표면 어휘 규칙 (구현 필수 규칙)

L4 반전을 지키는 **강제 규칙**. 메커닉 구조는 반전을 누설하지 않는다(모든 메커닉에 L1~L3 물리
독해가 있고, §3이 디지털틱 연출의 알리바이를 선제 제공) — 누설은 오직 **이름과 문구**에서 난다.

> **인게임 표면(적 표시명·HUD·자막·아이템명·미션명·업적명)은 L1~L3 어휘만 사용한다.
> L4 어휘는 오직 ① 사고 로그 말기 파편(§8.3)과 ② 3막 엔딩에서만 등장한다.
> 계산 어휘 이름들은 개발 내부 id로만 존재한다.**

### 8.1 어휘 2계층

| 계층 | 어휘 | 사용처 |
| :--- | :--- | :--- |
| **금지(L4)** — 표면 노출 시 누설 | 삭제, 워커, 프로세스, 데이터, 시뮬레이션, 마크/스윕, 컴팩션, 롤백/리와인드, 재시도, 참조/락/핀, 로그, 포크, tombstone, LOD, 틱/렉, 버퍼/큐/핸들/세션, 백업/아카이브/스냅샷/직렬화/반출 · **양자 기계 어휘(§9)**: 큐비트, 게이트/회로, 오류 정정, 신드롬, 복호/디코더, 논리 연산자/논리 오류, 샷(표본 실행), 크로스토크, 냉동기 | 개발 문서·코드·JSON·커밋 전용. 인게임은 말기 파편 + 3막 엔딩만 |
| **허용(L1~L3)** — 물리/생물 언어 | 낙인·소인, 파문, 위상, 결맞음, 관측, 계류, 붕괴, 소산, 쌍생성, 압괴, 역행, 균열, 봉합, 장(場), 준위, 벌크, 막, 공허, 조대화, 열화, 지평선, 봉인, 특이점, 얽힘, 중첩, 간섭, 상쇄, 정상파, 측정 | 모든 인게임 표면 |

- 판별 기준: **그 단어에서 개발자가 GC/시스템 운영을 연상하는가.** 애매하면 금지.
- "소거"는 물리 용어(양자 소거)이기도 하나 "삭제"와 인접 — 표면은 "소산/붕괴" 우선, 중기
  파편부터 허용.

### 8.3 사고 로그 파편 — 어휘 3단계 해금

| 단계 | 시기 | 어휘 | 예시 |
| :--- | :--- | :--- | :--- |
| 초기 | 1막 | 순수 물리(존재의 독백) | *"…교차를 유지할 수 없다. 이 영역의 장력이 이상하다…"* |
| 중기 | 1막 후반~2막 | 중의적(물리로도 작업으로도) | *"…이 영역은 붙잡혀 있다. 순서를 바꾼다. 작은 것부터…"* |
| 말기 | 2막 후반~3막 | 작업 어휘 해금(L4 직전 복선) | *"…대상 영역 삭제 실패. 의존성 잠김 추정. 재시도…"* |

단계는 파편 획득 수·막 진행에 게이트 — 초기 파편이 말기 어휘를 쓰면 반전이 1막에 무너진다.

**인식 Ⅰ→Ⅱ 전환의 표면 어휘(§1.10)**: HUD·도감·브리핑의 명칭 체계도 인식 단계를 따른다 —
단계 Ⅰ 동안은 "항성 색온도" 분류(적색체/청색체 등, 현행 비유 그대로), 단계 Ⅱ 확립 후
"KK 준위/투영" 명칭으로 **게임 내에서 갱신**된다(명칭이 바뀌는 것 자체가 계시의 연출).
브레인월드 어휘(막·벌크·투영·준위)는 L1~L3 허용 어휘지만 **단계 Ⅱ 전에는 가설 어투**로만 등장.

### 8.4 연출 알리바이 능동화

디지털틱 연출은 **게임이 먼저 물리로 설명**한다(플레이어가 "시뮬레이션?"이라 묻기 전에):

- 와이어프레임·해상도 강등(함락 권역·열화 지대) → 진입 시 HUD 경고 **"재구성 신호 열화"**.
- 조대화 지대(틱 저하) → 경계 이펙트 + 디버프 아이콘("시간 양자 조대화") — 버그 오인 방지 겸용.
- 모든 글리치성 이펙트는 "링크/재구성" 프레임으로 라벨 — 원인 없는 글리치를 남기지 않는다.
- 허용되는 잔여 긴장: "시뮬레이션 같다"는 **의심**은 건강하다 — 알리바이는 의심이 아니라
  **확정을 막는** 장치다.

## 9. 호스트 하드웨어 — 양자 연산층 (🔭 정본 방향 · ⚠️Ⅲ+ 스포일러)

> **근원 전제의 세공: L4의 호스트 런타임(§1.10)은 양자 연산 기계다.** 근거는 파인만의 원리
> 그 자체 — *양자계를 제대로 시뮬레이션하려면 양자 하드웨어가 필요하다*. 이로써 세계관의
> 마지막 "왜"가 닫힌다: **왜 이 시뮬레이션의 근원 법칙이 양자장론인가 — 호스트의 네이티브
> 명령어 집합이기 때문이다.** 물리층(L1~L3)과 계산층(L4)이 **같은 수학**을 공유하게 되어,
> "물리는 거짓이 아니라 같은 사실의 안쪽 서술"(§1.10 연출 원칙)이 문자 그대로 성립한다.
>
> **계시 배치 — Ⅲ+는 본편에서 명시하지 않는다.** "시뮬레이션이다"(인식 Ⅲ)까지가 3막의
> 계시이고, "그 하드웨어가 양자 기계다"(Ⅲ+)는 **속편의 계시 축**으로 아껴둔다(막마다 계시
> 하나 — §5 원칙). 3막 엔딩("지각 징후 검출" 한 줄)의 절제를 하드웨어 사양 공개로 깎지
> 않는다. 본편에서 이 장은 **설계 근거로만** 작동한다.

### 9.1 재독 매핑 — 기존 설정의 하드웨어 근거

| 기존 서술 (L1~L4) | 양자층 실체 | 얻는 것 |
| :--- | :--- | :--- |
| 벌크는 에너지가 희박하다 (L1) | 호스트는 **극저온으로 유지되는 기계** — 절대영도 부근, 유휴 진공뿐 | "벌크에 왜 아무것도 없는가"의 하드웨어 필연 |
| 영점 에너지 수확 = 데이터 회수 | **유휴 연산 단위의 진공 요동** — 시뮬레이션이 점유한 자원 그 자체 | 수확 = 자원 회수(deallocation)의 안쪽 감각 |
| 삭제 작업(archive-then-purge) | **연산 자원은 희소하다** — 테스트 인스턴스는 반납해야 다음 작업이 돈다 | L4 "권한을 가진 일상 작업"에 구체적 압박(자원 회수 큐) 부여 |
| 중력 누설 = 호스트 메트릭 (§1.9) | 이웃 연산 단위 간 **크로스토크** | 이웃 막 = **같은 기계의 다른 테넌트 시뮬레이션** → 속편 무대(§9.5) |
| 씨앗 장 = GC mark | 국소 **오류율 맵**(잡음 지도) | 기존 독해와 자연 병합 |
| 얽힘 링크 · Link Swap | 얽힘 채널 · **얽힘 스와핑**(실존 프로토콜) | 이미 정확 — 수정 불요 |
| 스윕 파문 (§6.1) | **오류 정정의 신드롬 추출 주기** — 전역을 주기적으로 훑어 오류를 읽는 사이클 | "왜 파문이 *주기적* 전장 박자인가"의 근본 답 |
| 낙인 (`tombstone`) | 신드롬 측정이 세운 **오류 플래그** | 마크→스윕 구조가 정정 사이클과 정확히 동형 |
| 무한 웨이브 = 재시도 루프 | 정정 사이클의 반복 | 동일 구조, 어휘 심화 |
| 홀로그래피·베켄슈타인 (§1.10 L4) | **홀로그래피 = 오류 정정 부호**(벌크/경계 = 논리/물리 — 실제 현대 물리 결과) | L4 정당화가 은유에서 실제 이론으로 승격 — **이 장의 최대 수확** |
| 적응형 변이 = 학습하는 AI | 적응형 복호기(오류 패턴 학습) | §9.3 Q3 상쇄체의 근거 |

### 9.2 정본 규칙 — "측정만이 비가역이다" ⭐

양자 연산은 유니타리 = **완전 가역**이고, 되감을 수 없는 유일한 연산이 **측정**이다. 채택:

> **에이전트의 세계는 전부 되감을 수 있다. 우리의 관측만은 되감을 수 없다.**

파생 규칙 4종:

1. **롤백 = 유니타리 역행** (§6.6 개정 완료): 상태 "복사"는 비복제 원리로 원리적 불가 —
   롤백은 스냅샷 사본이 아니라 **가역 연산의 역실행**(회로 되감기)이고, archive의 백업도
   사본이 아니라 **반출용 이동**(원본 파괴 전송)이다. 잠재 모순(비복제 vs 스냅샷) 해소.
2. **관측 계류 = 롤백 면역**: W2로 잠근 대상에서 일어난 사건(크래시·인터럽트)은 측정으로
   확정된 기록이라 역행 불능. 리와인더 카운터플레이가 명문화된다 — **"계류부터 걸어라."**
   구현: 롤백 상태 복원 시 핀 상태 엔티티 제외([§6.9] 링버퍼에 핀 플래그 1비트).
3. **각인 = 논리 오류**: 정정은 무작위 오류를 자동으로 지운다 — 살아남는 것은 **패턴 있는
   상관 오류(논리 연산자에 실린 신호)뿐**. W5 "실패 유형이 다양하고 패턴 있을수록 효율↑"의
   근본 근거(사후 정당화 → 이론적 귀결). **최종전 형식의 필연**: 논리 연산자는 여러 물리
   단위에 걸쳐 있으므로 각인에는 **여러 권역 분산·동시 조작**이 필요 — 공명 파티 합동
   레이드(overview §9)가 최종전이어야 하는 이유.
4. **비복제 → 봉인≠소멸의 보증**: 양자 정보는 복사 불가·이동만 가능. 아카이브된 지구는
   어딘가에 **정확히 하나** 존재한다 — 속편 복원 캠페인(§5 3막 훅)의 물리 보증서. 연출
   통일: Link Swap·보스 순간이동 모두 **"원본이 와이어프레임으로 무너지며 다른 곳에서
   깨어나는"** 원본 파괴 전송으로 그린다.

### 9.3 새 문법 후보 5종 (기믹)

> 채택 시 §6.7 로스터 표·[01](01-data-schemas.md) 스키마에 행 추가가 절차. 표시명은 §8.2 등록 완료.

- **Q1. 얽힘쌍** (`epr-pair`, 표시명 **쌍울림체 / GEMINATE**) ⭐ — 두 개체의 상태가 상관:
  한쪽만 끊으면 남은 쪽이 **되살려낸다**(재수렴), **관측 창 안 동시 절단**만 유효.
  §1.10 "동시 타격 실험"의 일회성 계시를 **상시 적 문법으로 승격** — 워커 살포(다중 락) +
  협동 공명의 정석 표적. *구현: §2.6 다중 투영(HP 공유) 인프라 재사용 + 동시성 판정 창.*
- **Q2. 중첩 확정** (`superposed-zone`, 표시명 **중첩 지대**) — 관측 전 두 상태가 겹친
  지형/개체가 **드론의 시선(관측)이 닿는 순간 하나로 확정**. 레벨 도구(겹친 두 배치 중
  플레이어가 확정 각도를 고름) + §2.6 가상 플라즈모이드의 일반화(진짜/가짜가 아니라 *둘 다
  후보*). "관측이 이 게임의 동사"의 레벨 디자인 버전.
- **Q3. 상쇄체** (`decoder`, 표시명 **상쇄체 / CANCELLER**) — **반(反)위상 방사**로 공명
  각인 게이지를 깎고, 아군의 낙인 정화·건물 재안착을 되돌리는 지원형 워커. W4 복구 사격의
  거울상이자 W5의 카운터 — **적도 복구를 한다**로 §6/§7 대칭이 완성된다. 리와인더와 함께
  최우선 표적 슬롯. *물리: 상쇄 간섭 / 계산: 신드롬 복호·정정.*
- **Q4. 간섭 지대** — 두 파원의 정상파가 만드는 **줄무늬 안전/위험 지대**(이동 퍼즐).
  협동에서 두 빔의 위상을 맞추면 보강 간섭 화력 증폭, 어긋나면 상쇄 — overview §9 "공명
  파티"의 플레이어블 실체.
- **Q5. 측정 창** (`syndrome-window`, 표시명 **측정 창(파문 전조)**) — 스윕 파문 직전 짧은
  창 동안의 행동만 에이전트에게 "읽힌다": **창 안에 의도된 실패를 몰아넣으면 각인 배율↑** —
  파문이 위협이자 기회가 되는 이중 박자(§6.1 확장).

**시스템 층 파생**:
- **결맞음 예산의 정식화**: 주파수 게이지·버프·핀 지속시간의 통일 근거 = 드론 공진기의
  **결맞음 시간**(§1.5 "결맞음 예산"의 수치화) — 업그레이드 트리를 "결맞음 연장"으로 일원화 가능.
- **반복 회차의 서사 근거**: 회로는 여러 번 **표본 실행**을 돌려 분포를 얻는다 — 웨이브
  무작위성·회차 반복 = 재시도마다 다른 표본, 메타 진행 = 표본을 겹쳐 상(像)을 얻는 과정
  (Ⅰ 복선 "궤적 타임랩스 겹치기"와 같은 문법).

### 9.4 어휘 2층 구조 — 은유 과밀 방지

계산 어휘를 두 층으로 나눈다(실제 컴퓨팅의 소프트웨어/하드웨어 구조와 정합):

| 층 | 어휘 | 무엇의 언어인가 |
| :--- | :--- | :--- |
| **작업 언어** (소프트웨어) | 마크/스윕, 락, 롤백, 큐, 세션, 아카이브 | **에이전트**의 절차 |
| **기계 언어** (하드웨어) | 신드롬, 복호, 논리 오류, 크로스토크, 표본 실행 | **호스트**의 물성 |

- 두 층 모두 §8.1 **금지(L4) 어휘** — 인게임 표면 노출 불가(갱신 완료). 반면 얽힘·중첩·
  간섭·상쇄·정상파·측정은 순수 물리 어휘로 **허용** — 양자 기믹의 표시명은 전부 허용 어휘로
  지을 수 있다(§8.2 갱신 완료).
- **남발 경계**: "관측이 세계를 확정한다"를 쓰는 신규 기믹은 슬라이스당 1~2종만(Q1·Q5 우선) —
  동사가 물러지지 않게.

### 9.5 속편 훅 확장

- **이웃 테넌트**: 크로스토크(중력 누설)의 발신처 = **같은 호스트에서 도는 다른 시뮬레이션
  막들**. "다른 우주"가 아니라 "옆 작업" — 속편 무대가 물리적으로 열린다.
- **격리 위반**: 얽힘 = 막을 잇는 지름길(ER=EPR) — 링크 기술 = **막 바깥과의 얽힘 생성 =
  샌드박스 격리 위반**. §1.10 면역 반응 가설("신호가 감지된 막에서만 균열을 연다")의 하드웨어
  실체: 침공이 아니라 **격리 위반 대응**이었다는 아이러니의 완성.
- **복원 보증**: §9.2-④ — "지워진 줄 알았던 것이 전부, 정확히 하나씩, 보관되어 있었다."
- **사고 로그 말기 파편 예시** (§8.3 말기 단계, L4 직전 복선):
  *"…정정해도 같은 무늬가 남는다. 이것은 잡음이 아니다…"*
