# 광화문 동상 전용 모델

세종대왕 위치의 기존 16.5m 일반 건물(Gwanghwamun Square) footprint를 정확히 일치시켜 제거하고 두 동상 전용 모델을 지도 공통 로드 경로에서 등록한다. 이순신은 위치 목록만 존재하고 모델이 없던 상태였다. 주변 건물은 거리 기준으로 삭제하지 않는다.

- 좌표는 기존 랜드마크 목록 사용. 두 모델은 광장 축을 따라 남쪽을 향한다.
- 세종대왕: 동상 6.2m + 기단 4.2m. 좌상, 익선관, 책, 내민 오른손, 수염, 곤룡포와 의자 표현.
- 이순신: 동상 6.5m + 기단 10.5m. 투구, 갑옷, 검을 짚은 입상, 하단 거북선과 북 두 개 표현.
- 일반 창문 무늬를 적용하지 않으며 기존 건물 전투 병합 메시에 등록해 중복 표적을 만들지 않는다.
- 표정, 옷 주름, 갑옷·용 문양과 받침대 세부 치수는 실측/스캔이 아닌 수작업 근사이다. 사진과 완전히 동일한 조각 재현으로 간주하지 않는다.
- 형태 비교: `/tools/statue-preview.html`.

## 동상 남쪽 교차로 지형 보정
세종대로·종로 교차로 주변의 DEM 높이 급변을 `GwanghwamunRoadGrade.ts`에서 보정한다. 중심에서 260m 이내 주요 도로 축은 완만한 경사면으로 맞추고, 최대 480m까지 기존 지형으로 부드럽게 연결한다. 교차로 기준 높이 41m는 주변 낮은 DEM 표본을 참고한 추정값이며 실측 표고가 아니다. 지도 공통 로드의 마지막 단계에서 적용하여 지형, 도로 Worker, 건물 지면 접촉, 보행 높이가 같은 데이터를 사용한다. 도로 중심선과 폭은 변경하지 않는다. 중앙 교차로의 높이 변화와 인접 타일 경계 연속성을 테스트한다.
