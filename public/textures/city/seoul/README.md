# Seoul surface textures
Original procedural assets generated by scripts/generate-city-textures.mjs; no third-party photographs used.
1024×1024 RGB PNG, repeating. Color: sRGB. Normal: tangent-space +Y (linear). Roughness: linear grayscale.
Tile sizes: concrete 4×4m; brick 1.92×1.76m (4 bricks by 16 courses); roof 4×4m.
